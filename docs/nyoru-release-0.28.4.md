# 0.28.4 · 무림 경지 선택

플러그인만 업데이트. 모듈 v1은 그대로

## 사용 위치

- 새 게임: 무림 선택 → 추가 요청 단계의 **무림 경지** → **룰북 기본 / 커스텀**.
- 진행 중인 게임: **플레이 설정 → 무림 경지**. 전투가 끝난 뒤 적용한다.
- 구축 결과: 경지표를 확인·편집한 뒤 시스템을 적용한다. 기존 무림 게임의 재구축은 현재 경지표를 보존한다. 경지 변경은 먼저 플레이 설정에서 한다.
- 뉴뉴: “이 봇의 경지를 이 목록으로 바꿔줘”라고 요청하면 경지표 편집 제안을 열 수 있다. 최종 적용은 같은 편집 화면에서 한다.

## 경지표

룰북 기본은 기존 범인~우화등선 23단계와 수치·성장 계산을 사용한다. 커스텀은 2~200단계이며 10단계, 40단계도 가능하다. 경지마다 이름, 외공·내공 문턱, 외공·내공 수련 배율, 깨달음 획득 배율, 돌파 성공 성장 배율, 실패 손실률, 실패 시 사망을 설정한다.

개수 또는 한 줄에 하나씩 이름 목록을 넣어 새 경지표를 만든다. 기본 곡선은 외공·내공 20~12,000을 단계 수에 맞게 나누며 위로 갈수록 문턱이 높아진다. 문턱 배율 2는 40~24,000이다. 개수가 많다고 최고 경지의 총 요구량까지 자동으로 여러 배가 되는 방식은 아니다. 생성 후 각 행을 직접 조절할 수 있다.

문턱은 **현재 경지에서 다음 경지에 도전할 때** 필요한 영구 기초 수치다. 마지막 행은 최종 경지에서의 수련 상한이다. 외공형 1.4/0.6, 내공형 0.6/1.4, 균형형 1/1의 수행 방향 보정은 유지한다. 순서 이동 버튼은 이름·성장·실패 설정을 옮기고 각 단계 위치의 문턱은 유지한다.

성장 배율은 1=기본, 0.5=절반, 2=두 배다. 수련 배율은 외공·내공 수련과 의미 있는 전투/행동 성장에 사용한다. 기술 성수의 요구 숙련량은 기존 규칙을 유지한다. 깨달음 배율은 획득량이며 표시 성공률을 다시 곱하지 않는다. 깨달음 30%=성공률30%, 100%=확정, 초과분=추가 한 단계 확률, 최대200%는 그대로다.

기본 경지는 현재 초절정 이상에서 돌파 실패 시 사망한다. 커스텀은 **현재 행의 사망 설정**을 사용한다. 가르침·수련 실패와 조건 미충족 명상은 돌파 실패 사망에 해당하지 않는다. 저장된 죽음 면역도 유지한다.

## 봇·로어북에서 가져오기

0.28.7부터 초기 구축의 **커스텀 · 로어북 자동 구축**을 누르면 자동 생성이 바로 선택된다. 다음 자료 선택에서 경지 정보가 담긴 로어북을 함께 고른다. 0.28.4~0.28.6에서는 직접 편집을 저장하고 나온 화면의 별도 체크 항목으로 선택하던 경로였다. 초기 구축의 선택 자료와 추가 요청에서 이름·순서를 읽는다. 숫자가 명시되어 있으면 사용하고, 없으면 편집 가능한 기본 곡선으로 보완한다. 경지 목록 자체를 찾지 못하면 임의의 목록으로 확정하지 않고 오류와 보관 응답을 남긴다.

이 옵션은 초기 구축에서만 자료 묶음별로 경지 준비 API를 추가로 사용한다. 기본 경지와 직접 입력한 경지표는 추가 추출 호출이 없다. 평소 조회·돌파마다 표를 다시 생성하지 않는다. 실제 모델의 자료 해석은 구축 초안에서 확인해야 한다.

## 저장과 연결

경지표가 없는 기존 백업은 기본 23단계로 읽는다. 커스텀을 껐다 다시 켜도 저장한 커스텀 목록은 남는다. 채팅 간 설정은 공유하지 않는다.

표를 변경할 때 사용 중인 이전 경지의 연결을 보여준다. 같은 고유 ID·이름을 먼저 찾고 없으면 전체 단계에서 가까운 위치를 제안한다. 저장 전에 인물·기술 기준·가르침·아직 열지 않은 비전 장의 연결을 변경할 수 있다. 인물의 능력치·HP·기력·깨달음·천재·숙련은 보존한다. 이미 돌파한 보상이나 지난 주사위를 재실행하지 않는다. 편집 중 관련 경지가 바뀌면 오래된 편집을 덮어쓰지 않는다.

기술 수련 보정, 사소한 무공의 성장 제한, 스승과의 경지 격차, 의미 있는 교전 여부는 커스텀 단계의 상대적인 위치로 비교한다. 기본 표의 계산은 기존과 같다. 기술의 **수련 기준 경지**는 성장 계산 기준이며, 새로운 기술 사용 금지 조건을 추가하는 설정이 아니다.

## 작업 범위

소스 변경과 로컬 배포 생성을 수행했다. 사용자 지시에 따라 별도 최종 검사·테스트·브라우저·가상 전투·실제 RisuAI·모델 호출은 수행하지 않았다. 실제 UI 표시, 모델의 경지 추출, 진행 중 세이브 전환은 실사용 미확인이다. 이 버전은 GitHub에 게시하지 않았다.
