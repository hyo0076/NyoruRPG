# NyoruRPG 0.22.7 · 에렌샤 전투 연결

## 바꾼 내용

- `combat:true`를 전달해도 대상이 아군으로 등록돼 있으면 비전투 판정으로 빠지던 에렌샤 분기를 수정했습니다. 저장된 턴테이블 설정에 따라 기존 전투 엔진이 순서·아군·적 행동을 처리합니다.
- 공격 기술의 종류를 대상 준비에 사용합니다. 인물 종류를 생략했을 때 몬스터까지 일괄 아군으로 등록하지 않습니다.
- 현재 교전의 임시 편을 영구 인물 분류와 분리했습니다. 대련 상대와 기존에 잘못 분류된 적을 이번 전투의 상대편으로 지정할 수 있고, 원래 인물 설정을 덮어쓰지 않습니다.
- 후속 호출에 등장한 참가자는 기존 전투 순서에 합류합니다. 기존 참가자의 선공 주사위를 새로 굴리지 않습니다.
- 전투 중 짧은 관찰 같은 숙련 활동도 선언된 교전의 자기 차례에서 처리합니다. 제작·채집·장시간 작업은 전투 중 진행하지 않습니다.
- 상태 문맥에 실제 `combatOptions`를 포함하고, 도구 지침에 실제 교전의 `combat:true`·양쪽 참가자 전달을 명시했습니다. 턴테이블을 별도로 호출할 필요는 없습니다.

## 놓치지마 검사

켜 둔 검사에서 직전 서술과 실제 전투 상태·하위 행동 기록을 함께 봅니다. 전투 진입 누락, 빠진 적/NPC, 아직 처리할 NPC 차례를 확인합니다. 등록 누락은 기존 등록 도구로, 진행 중인 교전 연결은 기존 `act`의 관전으로 보완해 저장합니다.

이미 판정한 공격·비용·피해를 재실행하지 않습니다. 한 검사에서 전투 이어가기는 최대 한 번이고, 새 사용자 행동을 자동 선택하지 않습니다. 사용자 차례·지휘관 선택·미결 반응은 정상 대기입니다. 끝난 전투나 지나간 반격을 복원하지 않으며, 확정할 수 없는 부분은 검사 보고서에 남깁니다. 턴테이블 OFF도 사용자의 정상 설정으로 존중합니다.

## 진단에서 알 수 있는 범위

제공된 0.22.5 호스트 진단에는 반복된 공격 결과가 있지만 당시 전체 호출 인수·저장된 적 분류·전투 상태는 없습니다. 메인 AI의 자체 설명만으로 정확한 원인을 확정하지 않았습니다. 이번 수정은 소스에서 확인한 전투 진입 우회, 임시 편 미반영, 후속 참가자 누락 경로를 고친 것입니다.

## 설치와 확인 범위

연결 모듈 v1 사용자는 플러그인만 교체하고 Risu를 새로 고침하세요. 기존 세이브를 이어 사용할 수 있으며 게임 재구축·턴테이블 토글 재설정은 필요 없습니다. 원래 아군에게 피해와 강화를 함께 주는 기술, 소환수, 물체 대상 효과, 비전투 사용은 유지합니다.

소스 수정과 배포 파일 생성을 진행했습니다. 사용자 요청에 따라 별도 최종 검사·브라우저·가상 전투·모의 호스트·실제 RisuAI·유료 API 테스트는 하지 않았습니다. 설치 후 실제 모델이 올바르게 호출하고 결과를 서술하는지는 사용자 테스트가 남아 있습니다.
