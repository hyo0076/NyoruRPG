# NyoruRPG 0.22.3 · 업데이트 알림과 변경 내역

- 플러그인 창을 열 때 새 공개 버전을 확인하고 작은 알림을 표시합니다. 자동 확인 간격은 6시간이며, 창을 열지 않은 동안에는 주기적으로 조회하지 않습니다.
- 업데이트 설치 후 처음 창을 열면 내장 변경 내역을 한 번 보여줍니다. 같은 버전은 확인 기록을 저장해 반복하지 않습니다.
- 창 하단 **NyoruRPG · 업데이트 내역**에서 버전별 변경 내용, 현재 버전, 최신 버전과 마지막 확인 시각을 볼 수 있습니다. 자동 확인 끄기와 수동 확인도 이 창에 있습니다.
- 변경 내역은 별도 대화상자에 표시하므로 기술·장비·설정 편집 내용을 다시 렌더링하거나 저장하지 않습니다. 기존 라이트·다크 테마와 모바일 폭을 따릅니다.
- 새 버전 설치는 기존 RisuAI 플러그인 업데이트 기능을 사용합니다. 자동으로 파일을 실행하거나 플러그인을 교체하지 않습니다.

## 설치

`NyoruRPG.js`만 업데이트하면 됩니다. 연결 모듈 v1을 사용 중이면 모듈 교체와 게임 재구축은 필요 없습니다. 이전 모듈 사용자는 [한 번의 연결 모듈 전환](nyoru-release-0.22.0.md)을 이용하세요.

## 저장과 네트워크

확인 기록과 공개 변경 내역 캐시는 `urpg/update-notices/v1`에 별도로 저장합니다. 기존 세이브·사용자 편집·룰북 선택·인증 정보·MCP 식별자는 변경하지 않습니다. 알림은 플러그인 창에서만 표시하고 RP 본문이나 모델 지침에 넣지 않습니다.

자동 확인은 GitHub 공개 `updates.json`에 대한 GET 요청 하나입니다. AI API를 사용하지 않으며 채팅·사용자 설정·인증 키를 전송하지 않습니다. 조회 실패는 버전 확인 화면에만 표시하고, MCP 실행·주사위·카드·저장을 중단하지 않습니다. 네트워크가 없어도 설치된 파일의 변경 내역은 볼 수 있습니다.

## 확인 범위

첨부 Provider Manager의 버전 확인·변경 내역·확인 기록 방식을 읽고 NyoruRPG의 기존 UI와 저장 경로에 맞게 구현했습니다. 소스 수정과 배포 파일 생성만 진행합니다. 별도 최종 검사·브라우저·모의 호스트·실제 RisuAI·유료 API 테스트는 실행하지 않습니다.
