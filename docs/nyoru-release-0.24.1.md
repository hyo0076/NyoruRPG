# NyoruRPG 0.24.1

놓치지마 검사에서 적용하지 못한 내용을 **미해결 목록**에 남기고, 채팅 화면의 알림에서 곧바로 열어 수정합니다. 다음 검사가 실행되어도 이전 미해결 항목은 사라지지 않습니다.

## 사용 방법

- **AI 연결 → 채팅 화면에 검사 시작 알림 표시**를 켜고 연결 설정을 저장하면, 검사 시작 때 `뇨루가 놓친 것이 있나 검사중입니다.`가 약 3초간 표시됩니다. 기본값은 꺼짐입니다.
- 문제가 남으면 이 토글과 관계없이 `쮸인님 이것 좀 도와달라냥!` 버튼을 표시합니다. 플러그인 창이 닫혀 있어도 해당 채팅의 오른쪽 아래, 입력창 위에 나타나며 누를 때까지 유지합니다.
- 알림을 누르면 **미해결 놓치지마 검사**가 열립니다. 사용 인물·대상·물품·수량 등 현재 룰북의 입력을 고르고 **이 항목만 적용**을 누릅니다. 다른 작업과 이미 저장된 판정은 반복하지 않습니다.
- **수정 내용 보관**으로 나중에 이어갈 수 있습니다. 알림을 읽은 뒤에도 목록에는 남습니다. 직접 고쳤거나 적용하지 않을 내용은 이유를 적어 **적용 없이 정리**합니다. 정리만으로 게임 상태나 선행 작업의 성공을 만들지 않습니다.
- 목록은 **저장·복구 → 미해결 항목 열기**, **AI 연결 → 미해결 검사 확인**에서도 열 수 있습니다. 직전 구버전 검사에서 원래 보완 계획이 남아 있으면 함께 이어받습니다.

처음 화면 알림을 사용할 때 Risu의 **메인 화면 접근 권한** 요청이 나타날 수 있습니다. 권한이 거절되거나 해당 호스트가 화면 접근 API를 제공하지 않으면 외부 팝업을 표시할 수 없으며, 플러그인 안의 미해결 목록에서 확인합니다. 입력창 위치를 읽을 수 없으면 화면 오른쪽 아래에 여백을 두어 표시합니다.

## 처리 기준

모든 룰북이 공통 검사·알림 경로를 사용합니다. 수정한 입력은 각 룰북의 기존 준비·계산·저장 경로를 거칩니다. 이미 계산한 주사위 실패, 실제 사용자 선택 대기, 저장 여부가 불확실한 결과는 재굴림하지 않습니다. 선행 작업이 필요한 항목은 순서를 표시합니다. 뒤의 전투·탐험이 진행되어 과거 판정을 끼워 넣을 수 없는 경우에는 임의로 재연하지 않고 이유를 알립니다.

현재 답변을 생성하는 동안에는 편집 내용을 보관할 수 있고, 적용은 답변이 저장된 다음 합니다. 새로고침으로 최신 상태를 읽고 다시 적용하세요. 입력을 고쳤어도 자료가 부족하거나 룰북 조건에 맞지 않으면 해당 이유를 계속 남깁니다. 준비가 필요한 항목은 기존 기본 API를 사용할 수 있습니다. 연결 오류처럼 실행할 보완 계획 자체가 없는 경우에는 AI 연결 설정으로 안내합니다.

문제 알림은 **검사 시작 알림 토글과 독립적**입니다. 채팅의 NyoruRPG 전원·연결 모듈이 꺼져 있거나 다른 채팅으로 이동하면 표시하지 않습니다. 미해결 목록은 채팅별로 저장되며 RPG 전원을 꺼도 삭제되지 않습니다. 게임 백업은 기존 형식을 유지하므로 검사 보고서·미해결 편집 초안을 다른 채팅으로 가져오는 기능은 포함하지 않습니다.

초기 설정의 **추가 인물 · 한 줄에 ID | 이름** 아래에도 ID를 원하는 대로 정할 수 있다는 안내를 추가했습니다. 영문·숫자와 `_ - . :`를 사용하고 인물마다 서로 다른 ID를 적습니다.

## 업데이트와 확인 범위

연결 모듈 v1 사용자는 **플러그인만 업데이트**합니다. 기존 세이브·룰북·편집 내용·MCP 식별자·결과 카드 배치·도구 완료 방식은 유지합니다.

기존 소스의 검사·저장·UI 연결과 공식 Risu V3 화면 API를 읽고 구현했으며 배포 파일을 생성했습니다. 사용자 요청대로 별도 최종 검사, 자동·모의 호스트 검사, 브라우저 실행, 실제 RisuAI 및 유료 API 호출은 하지 않았습니다. 모바일 실제 알림 위치, 권한 요청, 실제 검사 결과의 수정 적용은 아직 실사용으로 확인하지 못했습니다.
