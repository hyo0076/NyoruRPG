# 전통 D&D

**시스템 구축 → 전통 D&D**를 선택합니다. D&D 2024 개정판의 공개 규칙 **SRD 5.2.1**을 사용합니다.

세계관과 인물의 이야기는 가져오고, 능력치·전투·주문·성장은 D&D를 따릅니다. 기존 플레이 토글은 적용하지 않습니다.

## 시작하기

원하는 인물과 설정 자료를 선택하고 구축합니다. 기본은 1레벨이며, 다른 시작 레벨을 원하면 추가 요청에 적습니다. 직업·종족·배경·준비 주문을 확인하고 인물 편집에서 조정한 뒤 적용하세요.

SRD의 12개 직업, 9개 종족, 4개 배경을 사용합니다. 처음 장비는 직업의 기본 꾸러미와 배경의 시작금으로 준비합니다. 진행 중 장비 교체와 물품 사용은 채팅으로 요청하면 됩니다.

## 이런 플레이는 어때요?

- 남은 주문 슬롯을 아끼며 소마법으로 버티다가, 동료가 적을 모은 순간 화염구를 시전합니다.
- 로그가 동료의 협공을 이용해 암습하고, 파이터는 행동 연쇄로 공격을 몰아칩니다.
- 폐허에서 한 시간 쉬며 히트 다이스를 써 회복할지, 적이 돌아오기 전에 더 나아갈지 결정합니다.
- 준비한 주문을 긴 휴식 뒤 바꾸며 내일의 협상·잠입·탐험에 대비합니다.

전투에서는 행동·보너스 행동·반응과 이동 거리를 구분합니다. 능력 판정·내성·명중에는 d20을 사용하며, 이점·불리점과 숙련 보너스를 함께 계산합니다. HP가 0이 되면 사망 내성을 처리합니다.

주문 슬롯과 직업 자원은 사용하면 줄어들고, 해당 규칙의 휴식으로 돌아옵니다. 레벨 상승에 따라 최대 HP·숙련 보너스·주문 슬롯·사용 횟수가 증가하며 새 주문과 특기를 선택합니다.

## 진행 방식

메인 AI가 DM을 맡습니다. 프로그램은 판정과 자원·피해·회복·성장을 저장합니다. 주문과 특성의 세부 효과는 도구가 제공하는 SRD 원문을 읽고 DM이 판정하여 반영합니다. 복잡한 효과까지 모두 자동 판정하는 방식은 아닙니다.

이번 버전의 캐릭터 성장은 단일 직업 기준입니다. 멀티클래스는 지원하지 않습니다.
