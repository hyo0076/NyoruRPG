# NyoruRPG 0.40.0 소개글 · 라이트

게시글의 순서를 **첫 시작 → 새 플레이 예시 → 여덟 룰북 → 계산과 효과 → 뉴뉴 → 화면과 카드 → 설치 → 상세 설정**으로 바꿨습니다. 이전 라이트 테마, 룰북 배너와 카드 스타일 예시를 유지합니다.

## 사용할 파일

- `NyoruRPG-소개글.html`: 브라우저에서 열어 읽는 로컬 소개글. 옆의 `배너`·`카드` 폴더를 함께 보관합니다.
- `NyoruRPG-소개글-HTML붙여넣기.txt`: 아카라이브 HTML 편집 모드에 넣는 본문만의 HTML.
- `NyoruRPG-소개글-원문.md`: 모든 설명을 펼쳐 한 파일로 합친 원문.
- `스크린샷-첨부목록.txt`: 실제 플레이 화면을 추가할 위치와 내용.
- `카드-이미지-첨부목록.txt`: 기존 카드 예시 이미지 목록.

## 게시할 때

1. HTML 편집 모드에 `NyoruRPG-소개글-HTML붙여넣기.txt`의 내용을 붙입니다. 로컬 미리보기의 doctype·head·body까지 붙이는 파일이 아닙니다.
2. 빈 스크린샷 칸은 `스크린샷-첨부목록.txt`를 보고 실제 사용 화면으로 채웁니다. 해당 화면이 없다면 그 칸과 캡션을 삭제해도 됩니다.
3. 게시용 HTML의 배너·카드는 GitHub 공개 이미지 주소를 사용합니다. 게시판 자체 첨부를 원하면 ZIP의 PNG를 업로드하고 해당 이미지 src를 교체합니다. 상대 경로로 된 로컬 파일을 그대로 게시판에 넣지 않습니다.
4. 키·인증 내용은 가리고, 초안·실제 플레이·소개용 예시를 구분해 게시합니다.

룰북 배너는 기존 **1200×300, 4:1** 이미지를 사용하며 비율을 유지해 표시합니다. 카드 PNG는 0.30.0 소개 작업에서 렌더러에 예시 수치를 넣어 만든 자료를 재사용한 것으로, 0.40.0 실사용 캡처로 소개하지 않습니다. 새 화면 캡처는 빈 칸으로 남겨 두었습니다.

HTML은 inline 스타일과 details/summary를 사용하며 iframe·JavaScript·외부 CSS를 넣지 않았습니다. 기존에 제공받은 `docs/references/아카라이브_HTML_GUIDE_v6.7.1.md`의 기본 제약과 밝은 배경의 글자색 보존 처리를 이어 사용합니다. 이번에 게시판·브라우저·실제 Risu 검수나 유료 API 호출은 하지 않았습니다.

## 설치 안내 변경

두 연결 경로를 분리했습니다.

- **Yumi Provider Manager Toolbox:** 플러그인·모듈 → Toolbox 적용 → 도구 호출 활성화 → 사용할 모델에서 NyoruRPG 선택 → 보조 API → 채팅 시작.
- **개인 중계기(추천):** 별도 프로그램 실행 → RPG에 기본 주소·Publisher key 등록 → 첫 화면에 Consumer key를 넣어 도구와 URL 확인 → 프로바이더에 streamable-http·Bearer·600000ms 등록 → 모델별 도구 선택.

사용자가 지정한 중계기 게시글 링크는 `https://arca.live/b/characterai/185746728`입니다. 웹 도구로 이 게시글 본문을 읽지는 못했으므로 연결 절차는 현재 `personal-relay/README.md`와 RPG의 중계기 설정 화면 소스를 기준으로 작성했습니다. 다른 기기·모바일에는 127.0.0.1을 그대로 쓰면 안 되는 점도 안내합니다.

## 설명을 현재 상태에 맞춘 부분

성좌는 빈 비호 목록·간접 반응에서 시작하고 관계를 쌓은 뒤 다섯 도움을 받는 흐름으로 설명합니다. 신앙과 관계를 분리하고 방송 후원은 출금 시 20% 공제를 명시합니다. 새 소환·인물 연결·4칸 스킬 제한·장착 행동·파츠·상자 지급·몬스터와 장소 재사용을 플레이 예시로 소개합니다.

에렌샤의 숨은 5배 시간, 현실 상세값 숨김, 파츠 슬롯을 먼저 만드는 옛 안내를 교체했습니다. 오래된 고정 성좌 목록이나 별도 선택 기능 실행 창을 현재 기능처럼 소개하지 않습니다. JEV의 총비용 절감이나 자동 누락 수정을 보장하지 않으며 JEV·2D 지도·개인 중계기는 실험 기능으로 표시합니다. 전략 룰북과 GM 모드는 구현 기능 목록에 넣지 않았습니다.
