# NyoruRPG 0.40.0

2026년 10월 13일. GitHub 공개판 0.30.5 이후의 기능과 수정 사항을 통합한 업데이트입니다. 버전 숫자 순서와 기존 자동 업데이트를 유지하기 위해 0.40.0을 사용합니다.

**플러그인만 업데이트. 모듈 v1은 그대로**

## 설치와 업데이트

- 기존 사용자는 RisuAI 플러그인 설정에서 NyoruRPG를 업데이트한 뒤 새로 고침합니다. 수동 교체는 [NyoruRPG.js](https://raw.githubusercontent.com/hyo0076/NyoruRPG/main/NyoruRPG.js)를 사용합니다.
- 새 사용자는 플러그인과 연결 모듈 v1을 함께 설치합니다. [전체 배포 ZIP](https://github.com/hyo0076/NyoruRPG/raw/refs/heads/main/NyoruRPG-0.40.0.zip)에 파일과 사용법이 있습니다.
- 기존 채팅의 시스템을 다시 구축할 필요는 없습니다. 선택 기능은 해당 채팅의 플레이 설정에서 켭니다.

## 성좌·스트리밍·퀘스트

성좌는 처음부터 친한 후원자가 등록된 상태로 시작하지 않습니다. 여러 성좌가 관찰·반응하고 행동·교류·부탁 이행으로 관계가 쌓이면 비호와 다섯 도움을 준비합니다. 관계와 소비하는 신앙을 나누며, 전용 성좌 메시지는 카드 테마를 따릅니다. 에렌샤 현실 장면에는 성좌가 개입하지 않습니다.

스트리밍에는 방송 상태·시청자·충성도·후원 기록과 순위를 표시합니다. 후원금은 출금할 때 20%를 공제합니다. 성좌·방송·퀘스트 중 두 기능만 켜도 관련된 목표와 약속한 보상을 연결하고 중복 지급을 막습니다. 실제 대사와 방송 반응은 메인 AI가 서술하고 수치 변화는 도구가 처리합니다.

## 탐험과 전투

- 같은 종류의 몬스터와 방문 지역은 준비한 자료를 재사용합니다. 변종·보스·일시적 지역 사건을 구분합니다.
- 물품·골드 드랍, 돈 보따리·아이템 상자의 사용 효과를 연결했습니다. 새 아이템 정의가 필요하면 기존 자료 생성 경로를 사용합니다.
- 플레이어와 동료의 직접 사용하는 기술을 기본 4칸에 편성하는 스킬 제한을 추가했습니다. 기본 공격·방어·회피도 포함하며 성장 조건을 편집할 수 있습니다.
- 장비에 기본 행동을 저장하고 소유·착용·내구도에 따라 실행 가능 여부를 계산합니다. 기본 위력과 행동 수식은 구분해서 편집합니다.
- 파츠는 장비에서 보유 물품을 골라 붙입니다. 빈 부착 칸을 먼저 만들 필요가 없으며 저장된 명시적 호환 조건은 유지합니다.
- 실험 중인 2D 지도는 저장한 지형·실제 이동·등장 인물·발견 정보를 표시합니다. 지도 방향키나 수색 실행 버튼은 없으며 채팅과 MCP가 실제 행동을 처리합니다.

## 화면과 편집

룰북 공통 파티·장비·소지품 화면을 정리했습니다. 장비 행동이 상태창의 배운 기술에 섞이지 않게 하고, 목록 검색·12개씩 표시·한 물품씩 펼치기를 적용했습니다. 위력·방어·수량과 편집 버튼은 바로 확인할 수 있습니다. 룰북별 경지·직업·현실 생활·피폭·수납 등 고유 정보는 유지합니다.

플레이 설정의 긴 설명을 접어 읽고 저장에 실패해도 고른 값은 남습니다. 채팅 상단 미니 UI는 미리 준비한 상태를 탭으로 보여주며 펼친 만큼 채팅 공간을 확보합니다. 해적리스 상단 탭과의 겹침 및 준비 실패 뒤 복구 경로를 보완했습니다. 삼선 메뉴의 미니 항목과 별도 선택 기능 실행 창은 제거하고 편집 화면을 유지했습니다.

## 초기 구축·JEV·놓치지마 검사

초기 구축 JEV는 자료별 근거와 현재 세계관 관련성을 확인하고 질문·답변·선정 결과를 조회할 수 있게 했습니다. OFF이면 준비·호출·대기를 건너뜁니다. 구축 완료·실패 이후에도 오래된 `요청 전·0회` 화면이 남던 경로를 고쳤습니다. **JEV는 실험 기능이며 속도·정확도·총비용 절감을 보장하지 않습니다.**

놓치지마 검사에는 봇 상태창, 거래의 차감·획득·돈·장비 변경, 활성 기능의 활용 여부를 연결했습니다. 자료 준비와 API 요청·응답 실패를 구분하며 기본 API 공유 시 실제 연결 정보를 안내합니다. 최근 연결 실패 제보의 정확한 원인을 확정한 것은 아닙니다.

신규 인물 등록, 뉴뉴의 장비 질문, 한글 검색, 전투 종료·처치 보완, 내구도 0→1 복구와 완전 수리의 구분, 무림 구축·편집 관련 수정도 포함합니다. 에렌샤에서는 기록된 경과 시간과 욕구 속도를 구분하고 현실 돈·생활비·체납·서비스 제한을 보강했습니다.

## 로딩과 저장

구축이 끝난 채팅은 **구축·카드 설정 열기**를 누르기 전에는 구축 원문·로어북 목록·초안을 읽지 않습니다. 현재 화면에 필요한 목록만 만들고 누적 실행 기록은 묶음으로 나눠 재사용합니다. 판정·중복 보상 확인·되돌리기는 필요한 전체 기록을 복원합니다. JSON 게임 백업의 v1 형식은 유지합니다.

**0.30.11 이하로 되돌릴 때**는 현재 버전의 **저장·복구 → 이전 플러그인으로 돌아가기 → 이 채팅을 이전 저장 형식으로 변환**을 먼저 실행하세요. 새 분할 저장 형식을 이전 플러그인이 직접 읽을 수는 없습니다. 사용하는 채팅마다 변환한 뒤 플러그인을 교체합니다.

## 개인 HTTP MCP 중계기

IPC 연결이 제한된 환경에서는 **AI 연결 → 개인 HTTP 중계기**를 사용할 수 있습니다. 본인 기기에서 별도 Node 프로그램을 실행하는 방식이며 공용 서버 운영이나 프로바이더 헤더 수정은 필요하지 않습니다. 중계기는 0.1.0 실험판으로 RPG와 별도 배포합니다. [중계기 ZIP](https://github.com/hyo0076/NyoruRPG/raw/refs/heads/main/Nyoru-Personal-MCP-Relay-0.1.0.zip).

## 확인 범위

이번 공개 작업에서는 버전·변경 내역·배포 파일을 갱신했습니다. 앞서 승인된 일부 UI 경계의 로컬 자동 테스트 결과는 해당 버전 기록에 남아 있습니다. 이번에 추가 테스트·실제 Risu 실행·유료 API 호출은 하지 않았습니다. 최신 미니창 수정의 실환경 복구, 모바일 뒤로가기, 전체 룰북 플레이, 속도·메모리 개선량을 모두 확인했다는 의미는 아닙니다. JEV·2D 지도·개인 중계기는 계속 실험 기능으로 안내합니다.
