# NyoruRPG 0.25.4 · 서술 분량과 행동 선택 대기

로컬 테스트용입니다. GitHub에는 게시하지 않았습니다. NyoruRPG.js만 교체하고 연결 모듈 v1과 기존 세이브를 그대로 사용합니다. 시스템 재구축은 필요 없습니다.

## 수정

공통 효과 지침의 “전투 종료나 한 호출의 계산 한도에서 멈춘다”, “계산되지 않은 행동을 서술하지 않는다”는 표현이 답변 종료·묘사 제한으로 읽힐 수 있었습니다. 이를 미확정 명중·피해·보상 등 기계적 결과를 지어내지 않는 규칙으로 좁혔습니다.

봇 프롬프트가 정한 분량·문체·상세도는 도구 반환, 턴 경계, 한 번의 탐험 이동 때문에 줄이지 않습니다. 처리된 결과와 현재 장면의 대화·생각·묘사를 그 지침에 맞게 서술할 수 있습니다. 위임된 다음 행동이 실제로 필요하면 같은 답변에서 결과를 읽은 뒤 다음 도구를 호출합니다. 분량을 채우기 위한 불필요한 판정·조회·추가 전투를 요구하지 않습니다.

공통 및 에렌샤 지침, 요청 말미 안내, 도구 결과와 선택 대기, 탐험 설명, 행동 모드 도움말, 뉴뉴의 지식을 같은 의미로 맞췄습니다. 공통 지침은 여섯 룰북에 적용됩니다.

## 행동 모드

행동 모드가 켜져 있다면 다음 사용자 행동은 직접 선택하는 설정입니다. 이 선택 대기는 답변을 짧게 끝내라는 지시가 아닙니다. 유저 행동까지 위임해 계속 진행하려는 경우 행동 모드·지휘관 모드를 끄고 기존 플레이어 행동 위임 설정을 사용합니다. 이번 업데이트가 저장된 설정을 자동으로 끄지는 않습니다.

현재 코드의 행동 모드 기본값은 OFF입니다. 사용자가 전달한 AI 설명만으로 현재 채팅에 action:true가 저장됐다고 확인할 수는 없습니다. 행동 모드는 탐험 한 단계마다 적용되는 종료 스위치도 아닙니다.

## 확인 범위

소스에서 충돌할 수 있는 문구와 선택 대기 계산의 적용 범위를 확인하고 수정했습니다. 판정 계산·선택 권한·저장·IPC·카드 연결은 바꾸지 않았습니다. 별도 최종 검사, 모의 호스트·전투, 실제 Risu·유료 API는 실행하지 않았습니다.

이 변경만으로 실제 모델이 5000단어를 출력한다고 검증한 것은 아닙니다. 현재 모델 출력 한도와 실제 요청 전체는 확인하지 않았으며 모델의 분량 준수는 실사용 확인이 남아 있습니다.
