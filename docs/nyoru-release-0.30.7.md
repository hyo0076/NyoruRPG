## 돈 주머니 만들기

소지품에서 물품을 편집하고 효과에 **골드 보따리 · 돈 지급** 또는 **사용 시 돈 지급**을 추가합니다. 물품 종류는 소모품(택티컬·지르코트는 기타 물품)으로 둡니다. 지급액과 지급 통화를 설정합니다. 기본 통화는 지갑에 통화가 하나 있을 때 사용하며, 여러 통화를 쓰면 직접 선택합니다.

예: 주머니 1개 사용 → 1,000골드 지급 → 주머니 1개 소모. 가격은 매매할 때 사용하는 값이고, 사용 시 지급액과 별개입니다. 뉴뉴에게 “이 주머니를 쓰면 1,000골드를 받고 소모되도록 효과를 붙여 줘”라고 요청할 수도 있습니다. 효과 편집만으로 골드를 지급하지 않으며 실제 사용 도구를 실행해야 합니다.

## 보급 상자와 가챠 상자

효과에서 **아이템 상자 · 내용물 지급** 또는 **가챠 상자 · 무작위 지급**을 선택합니다.

- **목록 모두 지급**: 등록한 내용물을 지정 수량만큼 줍니다.
- **가중치 추첨**: 상자당 뽑기 횟수와 물품별 가중치를 정합니다. 가중치 9 : 1은 90% : 10%이며, 여러 번 뽑으면 중복 당첨될 수 있습니다.
- **저장된 물품**: 정확한 ID를 고르면 그 데이터를 사용합니다. 같은 이름의 서로 다른 물품이 있다면 ID로 구분합니다.
- **새 물품**: 이름과 종류·등급·원하는 효과 등 설명을 적습니다. 처음 사용할 때 플러그인 AI가 필요한 내용물 데이터를 준비합니다. 지급 가능한 후보의 자료를 먼저 준비하고 실제 추첨·지급은 프로그램에서 처리합니다. 그 뒤에는 같은 저장 자료를 재사용합니다.

예: “녹슨 검 80, 은빛 검 19, 유니크 검 1의 가중치로 장비 하나가 나오는 상자.” 장비·탄약·소모품·재료 등 해당 룰북의 물품을 지급할 수 있습니다. 지급 장비는 자동 착용하지 않고, 기존 무기의 파츠나 장전탄 연결을 복제하지 않습니다.

돈·아이템 지급은 사용한 인물에게 적용하는 물품 효과입니다. 소지·착용·공격 명중 때마다 지급하는 패시브나 기술 효과가 아닙니다. 지급 효과 발동 확률의 기본값은 100%입니다. 확률을 낮추면 효과가 발동하지 않아도 사용한 상자는 소모됩니다. 내용물 준비 실패와 확률에 따른 미당첨은 다릅니다.

내용물은 효과당 30종, 추첨은 상자당 100회까지 설정합니다. 너무 많은 상자는 나눠 사용하도록 안내합니다. 실제 지급액·획득 물품·사용 수량은 도구 결과에 표시됩니다.

## 이미 저장된 주머니에 효과가 없는 경우

주머니·보상 상자를 사용했는데 효과가 비어 있으면 저장된 이름·설명으로 내용을 확인합니다. “사용하면 1,000골드 획득”처럼 지급 조건이 명시돼 있으면 플러그인 AI가 빠진 사용 효과를 준비해 같은 사용 요청에서 적용합니다.

판매 가격만 1,000골드라고 적혀 있으면 그 값을 내용물로 바꾸지 않습니다. 필요한 지급액·통화 또는 내용물·추첨 가중치를 안내하고 물품을 보존합니다. 뉴뉴나 물품 편집에서 보완한 뒤 다시 사용하면 됩니다. 무관한 경제 조회를 반복하거나 오류를 “7일 정산 대기” 같은 새 서사 규칙으로 바꾸지 않도록 메인 AI에도 안내합니다.

에렌샤에서 실제 효과가 없는 소모품의 수량만 줄어드는 경로도 차단했습니다. 첨부 제보에는 도구 반환값이 없어 과거 지급·소비 여부를 확정할 수 없으므로 과거 골드를 일괄 소급 지급하지 않습니다. 이미 소모된 주머니는 해당 시점의 영수증·백업으로 지급 여부를 확인한 뒤 누락분만 보완해야 합니다.

## 저장과 기존 기능

새 내용물 자료, 지급 결과, 소비 수량은 같은 게임 상태에 저장됩니다. 데이터 준비 또는 적용에 실패하면 일부만 저장하지 않습니다. 같은 성공 행동 ID를 다시 읽는 경우 기존 영수증을 돌려주며 다시 지급하지 않습니다. 백업과 되돌리기도 기존 게임 상태에 함께 적용됩니다.

방송 미출금 잔액은 기존 **출금 버튼 · 세금 20%** 규칙을 유지합니다. 인벤토리의 물품 사용으로 방송 잔액을 중복 출금하지 않습니다. 방송 지원으로 상자를 지급할 때는 겉의 가격뿐 아니라 지급 가능한 내용물 가치도 예산에 반영합니다.

이번 배포는 로컬 파일입니다. 실제 RisuAI·모델 실행은 확인하지 않았으며 GitHub 게시 보류를 유지합니다.
