# NyoruRPG 0.28.1 · 지르코트 생존 모드

**지르코트에만** 허기·갈증·위생·피로를 추적하는 생존 모드를 추가합니다. 에렌샤 현실모드와 다른 룰북은 변경하지 않습니다. 기존 연결 모듈 v1은 그대로 사용하고 `NyoruRPG.js`만 교체합니다.

## 켜고 끄기

- 초기 구축의 **지르코트 시작 설정 → 생존 모드**에서 선택합니다. 새 게임은 기본 OFF입니다.
- 진행 중에는 **생존·피폭 → 생존 모드**에서 바꿉니다. 토글을 변경하면 해당 채팅에 즉시 저장됩니다. 생성한 구축 초안의 토글은 초안에만 보관합니다.
- 0.28.0의 기존 지르코트 세이브는 종전의 생존 추적 ON을 유지합니다. 끄려면 토글을 해제합니다. 기존 식량·수분·피로·편집은 덮어쓰지 않습니다.
- OFF 동안 네 생활 수치와 기존 부상은 보존합니다. 켜는 순간 지난 시간을 소급 차감하거나 수치를 초기화하지 않습니다. 이미 발생한 피해는 돌려주지 않습니다.
- 지역 방사선·오염·출혈은 생존 토글과 독립적으로 처리합니다. 지역에서 받는 피폭은 별도의 지역 환경 설정을 따르고, 기존 오염의 영향은 남습니다.

## 네 가지 수치

| 항목 | 범위와 의미 | 기본 시간 변화 | 회복 |
|---|---|---|---|
| 허기 | 0이면 배부름, 100이면 굶주림 | 시간당 +3 | 음식 |
| 갈증 | 0이면 충분, 100이면 탈수 | 시간당 +5, 환경 ON의 더위 보정 | 식수 |
| 위생 | 100이면 깨끗함, 0이면 불결함 | 시간당 −2 | 씻기·위생용품 |
| 피로 | 0이면 충분히 쉼, 100이면 탈진 | 시간당 +2, 환경 ON의 추위·보온 보정 | 휴식·수면·피로 회복 물품 |

휴식의 기본 피로 회복은 시간당 12입니다. 씻기는 시간당 위생 120을 회복하며 그동안의 일반 위생 감소도 함께 계산합니다. 예를 들어 다른 변화 없이 10분간 씻으면 위생은 약 19.67 증가하며 최대 100입니다. 휴식 중에도 허기·갈증·위생 변화는 계속됩니다.

모두 편집 가능한 게임 기본값입니다. 실제 게임에서 경과한 시간만 사용하며 화면 열기·조회·API 대기·현실의 앱 종료 시간은 포함하지 않습니다. 전투·이동처럼 이미 시간을 계산한 행동 뒤에 생존용 호출을 하나 더 하지 않습니다.

허기·갈증·피로 75 이상, 위생 25 이하에서는 경고를 표시합니다. 생존 ON일 때 굶주림·탈수·탈진의 기존 부위 HP 소모를 적용하며 고갈되기 전 시간까지 소급해 피해를 주지 않습니다. 위생 저하에는 경고를 제공하고 자동 감염이나 사망 규칙은 추가하지 않았습니다.

## 식사·휴식·씻기

- `rpg_inventory use`는 실제 가진 음식·식수·회복제·위생용품 1개를 소모하고 그 물품의 효과를 적용합니다. OFF라도 명시적으로 사용한 물품은 소모하지만 네 생활 수치는 유지합니다.
- `rpg_play record`의 `eventType: rest`는 실제 휴식·수면 시간, `eventType: wash`는 실제 씻은 시간을 처리합니다. 씻기는 교전 밖에서 사용하며 양수의 `seconds`와 실제 사용한 물·시설 등의 근거 `reason`이 필요합니다.
- 같은 `eventId`로 기록을 다시 요청해도 경과 시간과 회복을 반복하지 않습니다. 이미 행동에 포함된 시간은 다시 기록하지 않습니다.
- 씻기나 물티슈 사용은 방사선 제염이 아닙니다. 표면 오염 제거·피폭 완화는 기존 의료 효과로 처리합니다.
- 시설·식수·회복 물품을 자동으로 지급하거나 휴식·씻기를 강제하지 않습니다. 이야기 속 실제 행동은 봇과 메인 AI가 정합니다.

## 표시·편집·뉴뉴

상태창·미니보드와 도구 상태 조회에서 네 항목을 확인합니다. 생존 ON이면 상태 카드에도 포함합니다. **생존·피폭 → 인물·신체·생존 편집**에서 현재 수치를, **생존 계산 설정**에서 시간당 변화량과 모드를 바꿉니다. 뉴뉴에게 같은 항목의 편집을 제안받을 수 있습니다.

기존 저장과의 호환을 위해 내부 `food`와 `water`는 남은 영양·수분입니다. 화면의 **허기 = 100 − food**, **갈증 = 100 − water**입니다. 따라서 허기를 30으로 고치려면 인물 편집의 포만도를 70으로 입력합니다. 위생·피로는 표시값과 저장값이 같습니다. 별도의 허기·갈증 저장 필드를 중복 생성하지 않습니다.

물품의 `food`, `water`, `energy`는 각각 허기·갈증·피로를 줄이는 양이며 `hygiene`는 위생 회복량입니다. `20`은 20점 회복이며 20배가 아닙니다. 예를 들어 위생용품은 `type: material`, `zirkott.kind: hygiene`, `zirkott.hygiene: 20`으로 만들 수 있습니다.

백업의 기존 구조와 인물·물품 ID를 유지합니다. 위생이 없는 이전 인물은 100, 위생 효과가 없는 이전 물품은 회복량 0으로 읽습니다. 조회만으로 원본 저장을 변경하지 않습니다. 같은 룰북 재구축으로 현재 생존 설정을 초기화하지 않습니다.
