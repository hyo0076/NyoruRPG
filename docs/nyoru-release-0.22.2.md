# NyoruRPG 0.22.2 · Vertex 서비스 계정 JSON

사용자의 게시 승인에 따라 GitHub에 배포하는 0.22.2입니다. **플러그인 `NyoruRPG.js`를 업데이트**하세요. 0.22.0 이전 사용자라면 기존 모듈을 지우지 말고 [연결 전용 전환](nyoru-release-0.22.0.md)을 한 번 실행한 뒤 Risu를 새로 고침하세요. 이미 전환했다면 플러그인만 교체하면 됩니다. 게임 재구축은 필요 없습니다. 0.22.1의 뉴뉴 퍼센트·배율 지침도 포함합니다.

## 한 번 등록하기

1. **AI 연결 → API 형식 → Gemini Vertex AI**를 선택합니다.
2. **Vertex 인증 → 서비스 계정 JSON · 자동 갱신**을 선택합니다.
3. Google Cloud에서 받은 `type: service_account`인 JSON 키 파일을 고릅니다.
4. 프로젝트 ID는 파일에서 자동 입력합니다. 사용할 모델 ID와 리전을 입력합니다. 다른 프로젝트에 권한이 있는 계정이라면 프로젝트 ID를 직접 바꿀 수 있습니다.
5. **연결 설정 저장**을 누릅니다. 이후 재시작해도 이 기기에서 등록한 키를 불러옵니다. 필요할 때 **연결 확인 · API 사용**을 눌러 실제 접속을 확인할 수 있습니다.

기본 API, 정밀 구축용 API, 검사용 API 모두 지원합니다. 나머지 연결에서 **기본 API 사용**을 켜면 JSON 인증도 공유하므로 파일을 다시 등록하지 않습니다. 별도 계정이 필요하면 해당 체크를 끄고 그 연결에 파일을 등록합니다.

JSON 파일을 새로 선택하면 키를 교체할 수 있습니다. **JSON 등록 해제 → 연결 설정 저장**으로 기기의 등록 키를 제거합니다. Google Cloud에서 키 자체를 폐기하는 작업과는 별개입니다.

## 자동으로 처리하는 인증

처음 요청할 때 서명한 인증 요청으로 액세스 토큰을 발급하고 만료 전까지 재사용합니다. 만료 60초 전부터는 다음 요청에서 새 토큰을 발급합니다. 같은 키로 동시에 요청하면 진행 중인 토큰 발급을 공유합니다. 입력한 OAuth 액세스 토큰을 쓰는 기존 방식은 계속 수동 교체 방식입니다. [Google 서비스 계정 인증 규약](https://developers.google.com/identity/protocols/oauth2/service-account)

키는 기기별 LocalPluginStorage에 보관합니다. 비밀 키를 일반 플러그인 설정·게임 백업·모듈·모델 프롬프트에 넣지 않으며, 발급 토큰은 실행 중 메모리에만 둡니다. 인증 요청의 원문을 오류 문장에 출력하지 않습니다. JSON 안의 주소를 임의 인증 서버로 사용하지 않고 Google 토큰 서버를 사용합니다. JSON 인증의 모델 요청은 Google Vertex 공식 API 주소로 제한합니다.

키 파일을 고르는 것은 로컬 읽기입니다. 실제 Google 연결·서비스 계정 권한·사용 가능한 모델 확인은 API 요청 때 이뤄집니다. 일반 JSON 설정이나 API 응답 파일은 인증 키로 등록할 수 없습니다. **JSON 모드 / 추가 본문 JSON**은 이 등록 기능과 별개입니다.

## 확인 범위

관련 소스와 Google 인증 규약을 읽고 구현했으며 로컬 배포 파일을 생성했습니다. 별도 최종 검사, 브라우저·모의 호스트·실제 RisuAI·실제 Google 인증·유료 API 요청은 실행하지 않았습니다. 사용자 환경의 파일 선택·기기 저장·토큰 발급과 실제 모델 응답은 아직 실사용 확인이 필요합니다.
