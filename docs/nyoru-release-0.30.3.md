# NyoruRPG 0.30.3 · 소환수 플레이

**플러그인만 업데이트. 모듈 v1은 그대로**

## 소환수를 미리 등록하기

**등록 인물 → 인물 추가 → 분류: 소환수 · 미리 등록**을 선택합니다. 소환자와 이름을 고르고 인물 설명에 원하는 체력·능력·기술·외형·장비를 적습니다. 새 자료는 해당 룰북의 인물 생성 경로와 관련 로어북을 이용해 준비합니다.

예: “뇨미의 사역마인 작은 얼음 늑대. 직접 싸울 수 있고 냄새를 추적한다. 물기와 얼음 숨결 기술을 사용한다.”

등록 직후에는 소환 대기 상태입니다. 같은 개체를 다시 부를 때는 저장한 ID와 자료를 재사용합니다. 새 인물을 만들기 위한 API 호출을 반복하지 않습니다. 같은 종을 여러 마리 만들려면 등록 화면의 **같은 이름의 서로 다른 개체**에서 서로 다른 고정 개체 ID를 지정하세요.

각 소환수 아래에서 다음 버튼을 사용합니다.

- **유지·성장 설정**: 소환자, 유지 방식, 성장, 경험치 공유, 직접 소환 비용, 소환자 능력 보정.
- **능력·기술**: 기존 룰북의 인물 편집 화면. 체력·기술·효과·장비도 해당 인물의 자료로 관리합니다.
- **뉴뉴에게 묻기**: 해당 소환수를 선택해 수정 제안을 요청합니다. 제안을 편집한 뒤 저장합니다.
- **소환 / 해제**: 등록 자료로 등장시키거나 대기 상태로 돌립니다. 전투 중 소환에는 소환자의 실제 행동 차례와 행동 비용이 필요합니다.

지원 룰북은 공통 D100·얼터네이티브 헌터·에렌샤·무림·택티컬·지르코트입니다. 로맨스 판타지·미연시에는 이번 소환 편집 기능을 추가하지 않습니다.

## 유지 방식

| 설정 | 종료 기준 |
| --- | --- |
| 소환자의 행동 횟수 | 소환자의 행동 차례를 마칠 때 감소. 비전투에서는 처리된 판정·기술·조사 등의 행동에서 감소 |
| 이번 전투 동안 | 소환한 전투가 끝나면 자동 해제. 전투 밖에서는 이 방식으로 소환하지 않음 |
| 계속 유지 | 수동 해제 또는 전투불능까지 유지 |
| 이야기 시간(분) | 게임에 실제로 기록된 이야기 시간 경과만큼 감소 |
| 소환수의 전투 차례(기존 방식) | 소환수 자신의 전투 차례를 완료할 때 감소. 구형 소환 설정과 호환 |

신규 기본값은 **소환자의 행동 5회 / 고정형 / 경험치 공유 참여 OFF / 직접 소환 비용 0**입니다. 유지 횟수·시간은 직접 바꿀 수 있습니다. 유지 규칙과 길이의 편집은 다음 소환부터 적용하며, 이미 진행 중인 남은 시간을 몰래 초기화하지 않습니다.

소환한 바로 그 행동에서는 새 소환수의 횟수를 차감하지 않습니다. 한 차례의 연속 타격·광역 대상 수를 여러 차례로 세지 않습니다. 자동 진행과 결과만 모드에서도 엔진이 실제로 완료한 차례를 따라갑니다. 상태 조회·화면 새로 고침·AI 응답 대기는 시간을 소비하지 않습니다.

이야기 시간에는 공통 행동 게이지의 논리 시간을 임의로 분 단위로 환산하지 않습니다. 휴식·이동·시간 기록으로 실제 이야기 시계가 진행돼야 합니다. 택티컬·지르코트는 기존 초 단위 시계의 경과를 분으로 환산합니다.

## 소환 기술에 연결하기

공통 D100·얼터네이티브 헌터·에렌샤·무림에서는 소환자의 기술 효과 편집에 있는 **소환수**에서 등록한 소환수 ID를 지정합니다. **유지 기준 → 소환수의 저장 설정 사용**을 고르면 인물 쪽 설정을 사용합니다. 특정 기술에서만 다른 유지 기준을 쓰고 싶으면 그 기술에 별도 기준을 설정합니다.

기술의 동시 소환 한도 **0**은 소환수 설정의 한도를 사용한다는 뜻입니다. 직접 소환은 유지·성장 설정의 비용을 지불하고, 기술로 소환할 때는 그 기술의 비용만 지불합니다.

택티컬·지르코트의 기술 연결은 기존 **기술 확장** 선택 기능의 **summons**에 저장된 소환수 ID를 넣습니다. 해당 선택 기능을 켜야 기술 연결이 실행됩니다. 등록 인물의 소환·해제 버튼과 유지 설정은 이 선택 기능과 별개로 사용할 수 있습니다.

이미 나온 같은 소환수를 다시 호출해도 개체를 중복 생성하거나 남은 시간을 새로 채우지 않습니다. 기술 자체를 다시 사용했다면 그 기술의 원래 행동·자원·재사용 제한은 그대로 적용됩니다.

## 비전투에서도 사용

까마귀의 정찰, 골렘의 장애물 돌파, 사역마의 기술 사용처럼 실제 행동의 사용 인물을 소환수로 지정합니다. 소환수 자신의 능력·기술과 해당 룰북 판정으로 처리합니다. 소환되어 있다는 사실만으로 주인의 모든 판정에 보너스를 주지는 않습니다. 도움 효과는 실제 도움 기술이나 효과로 등록합니다.

도구를 사용하는 메인 AI에는 다음 경로가 제공됩니다. 별도 MCP 도구 이름이나 연결 모듈을 추가하지 않습니다.

- `rpg_registry register_summon`: 자료를 한 번 준비해 소환 대기로 등록.
- `rpg_registry summon / dismiss_summon`: 등록한 ID를 호출·해제.
- `rpg_state summons`: 남은 유지 시간·상태·성장 설정 조회.
- 기존 `rpg_play act / check / explore`: 소환수를 사용 인물로 지정해 행동.

미리 등록된 소환수는 첫 조회를 강제하지 않으며 이미 ID를 알면 바로 소환할 수 있습니다. 해제된 소환수는 먼저 불러야 행동할 수 있습니다.

## 성장과 소환자 보정

**고정형**은 자동 경험치·숙련·수련 성장을 멈춥니다. 직접 편집은 가능합니다. **독립 성장**은 해당 룰북의 기존 성장 체계를 사용합니다. 공통 D100·얼터네이티브 헌터는 경험치, 에렌샤는 경험치·숙련도, 무림은 수련·기술 성장, 택티컬·지르코트는 무기 등 분야별 숙련을 사용합니다. 없는 레벨 체계를 새로 만들지는 않습니다.

경험치가 있는 룰북에서 **경험치 공유 참여**를 켜고 플레이 설정의 **경험치 공유**도 켜면 같은 파티의 분배·동일 지급 방식에 참여합니다. 해제된 소환수와 고정형은 분배 인원에 넣지 않습니다. 공유하지 않는 독립 성장형이 직접 처치하면 자신의 성장에 반영합니다.

**소환자 능력 보정**은 별도로 켭니다. 예를 들어 소환자의 저장된 능력치 40에 계수 0.5를 지정하면 소환수의 지정한 수치에 20을 더합니다. 독립 성장과 함께 사용할 수도 있습니다.

- 읽는 값: 소환자의 기본 능력치와 배분, 레벨, 저장된 최대 자원, 보유 숙련도 중 실제로 있는 값.
- 더하는 값: 해당 룰북이 지원하는 능력치·위력·명중·최대 자원·행동 속도.
- 택티컬·지르코트: 명중·위력·행동 속도(%) 보정. 해당 룰북의 부상 체계를 HP로 바꾸지 않습니다.

보정 때문에 원래 인물 수치를 덮어쓰지 않으며 다시 소환할 때마다 같은 보정을 누적하지 않습니다. 최대 자원이 늘어도 재소환만으로 현재 자원을 무료 회복시키지 않습니다. 주인과 소환수가 HP를 공유하거나 주인의 MP로 소환수의 모든 기술 비용을 대신 내는 일반 인물 연결 기능은 이번 범위에 포함하지 않습니다.

## 저장과 기존 게임

해제는 인물 삭제가 아닙니다. 체력·부상·기술·소지품·성장을 보관하고 현재 장면과 전투 참가, 대기 중인 시전·반응 연결을 정리합니다. 쓰러진 소환수는 재소환만으로 부활하지 않습니다. 기존 인물의 치료·회복 또는 명시적인 편집을 사용하세요.

소환 설정과 남은 시간은 같은 게임 저장에 포함되므로 기존 백업·복구·롤백 경로를 사용합니다. 구형 소환수에 새 고정형 기본값을 일괄 덮어쓰지 않습니다.
