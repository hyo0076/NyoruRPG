# NyoruRPG 0.28.11 · 기술 자체의 재사용 대기

플러그인만 업데이트. 모듈 v1은 그대로

## 설정 위치

초기 구축 6단계의 기술 편집, 또는 플레이의 능력·기술 → 기술 편집 → **비용·사용 조건**에서 **재사용 대기 턴**을 입력합니다. 효과를 하나도 추가하지 않은 기술에도 설정할 수 있습니다. 뉴뉴에게 “이 기술 자체에 재사용 대기 1턴을 설정해 줘. 효과 지속 시간이 아니야.”라고 요청할 수도 있습니다.

- 0: 재사용 제한 없음.
- 1: 사용한 차례에는 대기를 차감하지 않고, 다음 자기 차례 한 번 동안 같은 기술을 사용할 수 없습니다. 그 차례가 끝나면 다시 사용할 수 있습니다.
- 2 이상: 이후 자기 차례 종료마다 1씩 감소합니다.

같은 기술에만 적용하므로 다른 사용 가능한 기술·기본 공격·이동·방어 등은 선택할 수 있습니다. 적도 동일한 설정을 사용합니다. 연속 타격은 원래 한 번 사용한 기술의 일부이고, 별도 후속 기술 사용은 재사용 조건을 따릅니다. 턴테이블·행동 게이지·자유 진행 모두 자기 차례 종료에서 감소합니다. 다른 인물의 차례, 실제 시간, API 응답 대기에는 감소하지 않습니다.

공격의 **시전 대기 턴**도 비용·사용 조건에 있습니다. 시전 대기는 발동 전, 재사용 대기는 발동 후입니다. 효과 목록의 지속 기간은 버프·디버프 등이 대상에게 남는 시간이며 이 둘과 별개입니다. 상시 패시브는 직접 사용하지 않으므로 재사용 대기로 효과가 꺼지지 않습니다.

## 적용 범위와 저장 호환

D100·얼터네이티브 헌터·무림에 적용합니다. 에렌샤는 기존 재사용 대기 계산을 유지하며 시전 설정 위치를 맞췄습니다. 택티컬·지르코트의 논리 초 단위 재사용 대기는 그대로입니다.

초기 구축·새 기술 준비는 원문 또는 추가 요청에 재사용 제한이 있으면 저장하고, 제한이 없으면 0을 사용합니다. 기존 세이브의 과거 무시되던 cooldown 값은 업데이트만으로 활성화하지 않습니다. 해당 기술을 편집해 값을 지정하면 적용됩니다. 재사용 설정을 직접 변경하면 진행 중인 해당 기술의 남은 대기를 초기화하고 다음 사용부터 새 설정을 따릅니다. 전투 종료 시 남은 대기를 초기화하고 사용 횟수는 복구하지 않습니다. 전투 밖의 사용은 새로운 전투 재사용 대기를 쌓지 않습니다.

## 확인 범위

관련 생성·초안·편집·뉴뉴·전투·저장·표시 소스를 연결하고 배포 파일을 생성했습니다. 사용자의 기존 지시에 따라 별도 최종 검사, 브라우저·모의 전투·실제 RisuAI·모델/API 실행은 하지 않았습니다. 배포 생성은 실사용 검증과 구분합니다.
