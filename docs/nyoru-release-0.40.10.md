# NyoruRPG 0.40.10

- AI 프록시에서 반복되는 도구 결과를 줄여 입력량을 절약합니다.
- 판정 카드가 늦게 나타나거나 표시되지 않던 문제를 개선했습니다.
- 성좌 메시지에 영어 태그를 적용하고 방송 메시지도 카드로 표시합니다.
- 방송 후원의 중복 검사 알림과 전투 결산의 중복 표시를 줄였습니다.
- 결과만 전투에서 이동할 수 없는 기술 때문에 중단되던 상황을 개선했습니다.
- 에렌샤 장비 강화의 위력 반영과 착용·사용 편집 오류를 수정했습니다.

**플러그인만 업데이트. 모듈 v1은 그대로**

AI 프록시 사용자는 함께 첨부된 **개인 중계기 0.1.1**도 업데이트하세요. 실행창을 닫고 기존 폴더에 새 파일을 덮어쓴 뒤 다시 실행하면 됩니다. 기존 `data` 폴더는 유지합니다.
