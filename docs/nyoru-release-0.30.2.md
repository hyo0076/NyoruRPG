# NyoruRPG 0.30.2 · 숙련도 연결과 무림 구축 수정

**플러그인만 업데이트. 모듈 v1은 그대로**

## 에렌샤 숙련도

숙련도를 **이름 | 등급 | 레벨 | 경험치 바** 한 줄로 표시합니다. 경험치 숫자는 일반 목록에서 숨기고, 행을 누르면 작은 숙련 효과와 성장 연결·편집 버튼을 펼칩니다. 경험치 직접 편집은 유지합니다.

성장 누락을 줄이기 위해 숙련도를 실제 행동에 연결합니다. 탐험 조사에는 저장된 탐색·탐지 분야, 전투 중 거리 이동에는 보법·스텝 분야를 사용할 수 있습니다. 조회나 평범한 이동으로 모든 숙련도를 올리지는 않습니다.

**능력·기술 → 숙련도 행 펼치기 → 편집 → 실제 행동과 숙련도 연결**에서 조사·전투 이동·회피·방어·탈출·거래를 선택합니다. 함께 성장할 기술·생활 활동을 한 줄에 이름 또는 ID로 추가할 수 있습니다.

예를 들어 보법에 `퇴보 견제베기`를 연결하면 기술의 기본 숙련도와 보법을 함께 올립니다. 기본 숙련도와 연결된 숙련도가 같으면 한 번만 지급합니다. 연속 타격 수나 광역 대상 수만큼 같은 기술의 숙련도를 중복 지급하지 않습니다.

기존 자료에 별도 연결 설정이 없으면 알려진 분야 이름을 기준으로 기본 연결을 사용합니다. 같은 계열이 여러 개면 임의로 합치지 않습니다. 편집에서 활동 연결을 해제하면 그 선택을 따릅니다. 기존 등급·레벨·경험치를 초기화하거나 과거 활동을 소급 지급하지 않습니다.

## 기술의 기본 대상

새로 작성하는 기술의 기본 허용 대상에 자신·아군·적·중립 인물, 소환수·물체를 포함합니다. 아군에게 공격해서 효과를 주거나 물건을 대상으로 쓰는 콘셉트를 관계만으로 막지 않도록 합니다.

실제 실행에는 지정한 대상을 사용합니다. 기본 허용 대상이 넓어졌다고 자동 공격이 아군을 함께 때리지는 않습니다. 사거리·사용 조건·실제 대상 수 제한은 그대로 적용합니다.

이미 저장된 명시적 대상 조건은 보존합니다. 기존 기술의 제한을 바꾸려면 해당 기술의 효과 편집에서 **허용 대상**을 변경하세요. `대상 수 0`은 명시한 복수 대상 수를 제한하지 않는 설정입니다. 자동 광역 공격의 기본 선택은 적입니다.

## 무림 초기 구축과 경지 편집

새 무림 구축은 커스텀·로어북 자동 구축을 먼저 선택합니다. 사용자가 입력한 경지 설정을 우선하고 로어북에서 전체 순서와 단계명을 준비한 뒤 인물을 작성합니다. 명시적으로 고른 룰북 기본이나 이미 저장한 경지표는 유지합니다.

인물에게 경지가 없거나 현재 표에 없는 값을 받으면 관련 원문과 사용자 요청을 포함해 기존 보완 경로로 처리합니다. 끝내 누락된 값은 임의로 첫 경지를 넣어 통과시키지 않고 수정 가능한 오류로 남깁니다.

경지 직접 편집은 행의 고유 ID로 입력을 연결합니다. 빈 이름·너무 긴 이름·중복 이름을 구분하고 해당 행에 안내합니다. 하위 단계 이름도 `삼류 초입`, `이류 초입`처럼 구분하여 입력하세요.

내용이 같아도 저장 전후 인물·기술의 나열 순서가 달라 `EDIT_CHANGED`가 발생하던 비교를 수정했습니다. 실제 경지·기술·가르침 변경은 계속 감지합니다. 편집 중에는 단계 이동과 초안 재생성 버튼이 섞이지 않도록 하고 **경지표 저장 · 초안에 적용** 버튼을 고정했습니다.

경지표를 수정한 뒤 초안에 다른 오류가 남아 있어도 수정한 경지표는 보관합니다. 남은 오류를 이어서 수정하거나 기존 재시도 경로를 사용할 수 있습니다.
