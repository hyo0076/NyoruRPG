# NyoruRPG 0.25.0

전투 거리, 소지·착용 효과, 장비 강화와 놓치지마 검사 전용 화면을 추가합니다. 연결 모듈 v1 사용자는 플러그인만 업데이트하며 게임을 재구축하지 않습니다.

## 전투 거리와 편집

공통 d100·얼터네이티브 헌터·에렌샤·무림에서 **1 근접 / 2 가까움 / 3 멀리 / 4 아주 멀리**를 사용합니다. 새 전투의 시작 거리는 실제 장면에 따라 지정하고, 이미 진행 중인 전투에서 시작 거리를 다시 덮어쓰지 않습니다. 거리 기록이 없는 기존 전투는 근접에서 이어갑니다. 원거리 무기를 착용했다고 적을 자동으로 멀리 보내지는 않습니다.

**기술·장비 편집 → 효과 → 사거리·거리별 명중**에서 최대 사거리와 네 구간의 명중 보정을 직접 설정합니다. 기술에 별도로 지정하면 무기와 다른 사거리를 사용할 수 있습니다. 적·아군·소환수에도 같은 설정과 계산을 적용합니다. 현재 최대 사거리 밖의 보정도 입력할 수 있으며 사거리 확장 효과를 받으면 사용합니다.

| 예시 | 최대 사거리 | 근접 | 가까움 | 멀리 | 아주 멀리 |
| --- | --- | --- | --- | --- | --- |
| 근접 무기 | 1 | 0 | 0 | 0 | 0 |
| 권총 | 2 | 0 | 0 | 0 | 0 |
| 단궁 | 3 | -10 | 0 | -10 | 0 |
| 장궁 | 4 | -25 | -10 | 0 | 0 |
| 저격총 | 4 | -30 | -15 | 0 | 0 |

직접 설정하지 않은 무기는 이름·기술 종류를 바탕으로 위 기본값을 사용합니다. 판타지 무기나 특수 기술은 직접 설정으로 확정하세요. 적도 사거리 밖에서는 접근한 뒤 공격하며, 이동 자체가 일반 행동 한 번을 사용합니다. 사거리 밖 공격은 피해·명중·탄약 소비를 만들지 않습니다. 반격·연속 공격·투척도 현재 거리를 사용합니다.

**전투 옵션 → 인물 이동력**에서 한 행동에 이동할 칸을 정합니다. 기본 1, 범위 0~3이며 소수도 가능합니다. 0이면 이동하지 못합니다. 에렌샤 인물 편집과 공통 현재 상태 편집에서도 이동력을 다룹니다. 뉴뉴는 동일한 편집 항목으로 제안합니다. 전투 중에는 전투 옵션의 기본 이동력 변경을 막고, 기술·장비의 이동력 효과로 증감합니다.

추가 효과는 **최대 사거리**, **거리별 명중**, **거리 패널티**, **이동력**입니다. 예를 들어 기본 거리 패널티 반감은 `거리 패널티 / 곱하기 / 0.5`, 명중 +5는 `거리별 명중 / 더하기 / 5`입니다. 거리별 효과는 전체 또는 1~4 구간을 고릅니다. 최대 사거리는 효과 적용 후에도 1~4입니다.

이번 구현은 미터 좌표 대신 길이 3칸의 공통 전투 선 위에서 상대 거리를 계산합니다. 여러 대상 사이의 거리는 각 위치에 따라 함께 바뀌며, 뒤쪽 경계에서는 더 후퇴할 수 없습니다. 지형 크기·무한 후퇴·높낮이를 계산하는 시스템은 아닙니다. 전체 화면과 미니보드에 인물 기준 거리를 표시합니다.

## 소지 효과와 착용 추가 효과

장비의 각 효과에서 **소지 시 적용** 또는 **착용 시 적용**을 고릅니다. 기존 장비 효과의 기본값은 착용 시입니다.

화살통에 소지 시 명중 +2와 착용 시 명중 +3을 각각 넣으면 가방에 있을 때 +2, 착용하면 합계 +5입니다. 같은 이름의 같은 소지 효과를 여러 개 보유했다고 수량만큼 증폭하지 않습니다. 내구도가 소진된 장비는 효과가 중단됩니다. 기술·일반 효과 편집 및 시스템 구축의 같은 효과 모델을 사용합니다.

## 장비 강화와 가치

장비·소지품의 강화 메뉴에서 비용·성공률·실패 조건을 보고 한 번씩 시도합니다. MCP와 놓치지마 검사도 같은 `rpg_inventory enhance` 실행 경로를 사용합니다. 기존 에렌샤 강화 규칙을 공통 장비에 연결했습니다.

- 최대 +30. 비용은 +0 기준 가격의 10% × 다음 단계이며 최소 10입니다.
- 성공률은 95 − 현재 단계 × 8%, 최소 5%입니다.
- 성공하면 양수 위력·피해·방어 보너스와 장비 가치가 단계당 1.1배로 증가합니다. 없는 보너스를 임의로 생성하지 않습니다.
- 현재 +7 이상에서 실패하면 장비가 파괴됩니다. 보유한 보호재를 사용하면 파괴 대신 +0으로 돌아갑니다.
- 강화한 현재 가치를 판매·경매·수리 비용에 연결합니다. 편집창 가격은 +0 기준 가격으로 유지하고 현재 가치는 따로 표시합니다.

실제 강화 결과와 비용은 한 번만 저장합니다. 검사 AI가 서술의 강화 성공에 맞추어 실패한 강화를 재시도하지 않습니다.

## 놓치지마 검사

검사 설정·미해결 항목·검사 기록을 **놓치지마 검사** 카테고리에 모았습니다. 성공한 작업과 단순 처리 방침은 도움 요청에서 제외하고 원래 보고서에 보존합니다. 구버전에서 남은 명백한 완료 안내와 '지난 전투를 재연하지 않는다', '저장된 레벨 계산을 따른다' 같은 처리 방침도 목록에서 정리합니다. 실제 실패한 작업·입력 초안·사용자가 정리한 내역은 유지합니다.

인물 등록의 선택 항목에 빈 닉네임·본명·소유자 또는 null이 들어오면 없는 항목으로 처리합니다. 비어 있는 별칭도 제외합니다. 잘못된 객체·배열을 닉네임으로 받아들이거나 실제 이름을 만들어 합치지는 않습니다. 미해결 편집창에도 선택 항목은 비워도 된다고 안내하고, 탐험 이동 입력에서는 현재 열린 출구를 선택할 수 있습니다.

탐험 이동 코드에는 장애물이 없는 길에서도 장애물 설명을 읽어 오류가 나는 결함이 있어 수정했습니다. 앞으로 검사 실행 중 오류가 나면 실패 단계·오류 코드·민감 정보를 가린 원인 문구를 항목에 보관합니다. 과거 보고서에 없는 상세 원인을 소급 생성하지 않습니다.

채팅 화면 팝업은 유미 프로바이더의 플로팅 표시 방식을 참고해 메인 화면에 독립 컨테이너를 붙이도록 정리했습니다. 생성 중 실패한 요소는 버리고 다음 표시 때 다시 만들며, 입력창 위치 측정이 실패해도 기본 오른쪽 아래 위치로 표시합니다. 플러그인 전체 창을 닫으면 채팅 알림을 다시 표시합니다. **검사 설정 저장** 때 화면 접근 권한을 준비하며 **채팅 알림 미리보기**에서 실제 채팅 화면의 위치를 직접 볼 수 있습니다. 미리보기는 약 3초이며 API 호출·게임 수정·미해결 항목 정리를 하지 않습니다. 문제 알림은 검사 시작 알림 토글과 관계없이 누를 때까지 남습니다. 실제 Risu에서 표시됐는지는 아직 확인하지 않았습니다.

미해결 항목을 고쳐 적용할 때는 해당 작업만 실행합니다. 이미 저장한 주사위·거래·보상은 반복하지 않습니다. 이후 전투나 탐험이 진행돼 과거 작업을 끼워 넣을 수 없는 경우 현재 상태를 직접 편집한 뒤 정리해야 합니다. 답변 생성 중에는 초안 보관만 가능하고 실제 적용은 저장 후 가능합니다.

## 이번 확인 범위

기존 소스의 관련 입력·계산·저장·편집 연결을 읽고 수정했으며 배포 파일을 생성했습니다. 사용자 요청에 따라 별도 최종 검사, 브라우저·가상 전투·모의 호스트·실제 RisuAI·유료 API 호출은 하지 않았습니다. 실제 채팅에서 거리 전투, 강화, 이전 미해결 항목의 수정 적용은 실사용 확인이 필요합니다.

제공된 화면만으로 해당 탐험 실패가 발견한 코드 결함과 동일한 사건인지 확정하지 않았습니다. 외부 호스트 타임아웃 해결을 주장하지 않으며 MCP 이름·도구 완료 방식·카드 연결은 유지합니다. 사용자 세이브와 진단·채팅은 배포에 포함하지 않습니다.
