# NyoruRPG 0.30.0

**플러그인만 업데이트. 모듈 v1은 그대로**

## 메인 AI 과거 대화 PDF · 유미 연동

AI 연결 → **메인 AI · 과거 대화 PDF**에서 켭니다. 기본 OFF이며 최근 대화 블록은 기본 4개를 텍스트로 유지합니다. 설정은 즉시 저장됩니다.

먼저 유미에서 사용할 Gemini 모델의 **텍스트 변환 → Gemini PDF**와 PDF 설정의 **수동 지정 기능 사용**을 켜세요. 시스템/유저/모델 역할을 표시하는 템플릿도 유지합니다. NyoruRPG 토글만으로 유미의 모델 설정은 변경되지 않습니다.

변환할 과거 대화가 없으면 수동 지정 모드에서 텍스트를 유지합니다. Nyoru 토글을 끄면 범위 지정만 중단하므로 PDF 전송 자체를 끄려면 유미 모델의 PDF 변환도 꺼주세요.

NyoruRPG는 시스템 지침·현재 상태·도구 기록·서명·첨부를 제외한 긴 과거 대화에 유미의 PDF 범위를 지정합니다. 실제 PDF 생성과 도구 후속 요청의 PDF 전송은 유미가 담당합니다. 원문 채팅과 게임 저장은 바뀌지 않습니다. 기존 프리셋의 PDF 범위가 있으면 그 선택을 유지합니다.

최근 지정 분량은 같은 화면과 호스트 진단의 `mainContextPdfPrepared`에서 볼 수 있습니다. 문자 수이며 실제 토큰이나 절감액이 아닙니다. 실제 PDF 첨부·도구 후속 요청·사용량은 유미 및 프로바이더 로그에서 확인하세요. 최대 컨텍스트 설정이나 누적 캐시 사용량을 매 요청의 실제 입력으로 간주하지 않습니다.

참고한 것은 제공된 Yumi Provider Manager 1.16.3의 수동 PDF 범위와 NyoruMemory의 PDF 입력 구조입니다. 두 참고 프로젝트·플러그인 원본은 수정하지 않았습니다. 이번 후속 변경은 소스 연결과 로컬 배포 생성 범위이며 설치된 Risu·유미·실 API 확인은 포함하지 않습니다.

## Jev 빠른 판단

같은 0.30.0 후속 배포에 자료 준비와 중복 해석 축소를 적용했습니다.

- 로어북은 확정한 원문을 유지하고 모호한 후보만 기존 API로 넘깁니다. 발췌·미검토 자료는 무관하다고 단정하지 않습니다.
- 새 물품은 명시된 이름, 분류, 가격/단위 근거와 부족한 필드를 나눠 생성 AI에 전달합니다. 코드는 부분 응답을 조립하고 기존 룰북이 검증합니다.
- 에렌샤의 확장 기능이 꺼져 있고, 설명과 가격이 명시된 일반 재료로 확정되면 생성 API를 생략합니다. 고유 장비·기술·인물·지도는 필요한 작성을 유지합니다.
- 에렌샤와 택티컬의 단일 물품에 불필요한 인물 구축 지침을 보내지 않도록 줄였습니다. 지르코트 고유 물품 규칙은 유지합니다.
- 초간단 질문은 알려진 대상 ID와 `field`를 함께 보내면 유일한 저장값을 AI 없이 조회합니다.
- 로그에 생성 API 생략, 후속 생성 요청, 준비 전후 입력 증감과 후속 API가 보고한 사용량을 추가했습니다. 실제 절감액은 다음 플레이 자료와 청구 내역으로 비교합니다.

AI 연결 → Jev 빠른 판단에서 Jev 사용을 켜고 설정을 저장합니다. 기본 OFF이며 이전에 저장한 영역별 설정을 유지합니다.

- 직접 연결: System One을 지원하는 주소와 키, 모델을 입력합니다. TypeSafe 직접 연결은 `https://api.typesafe.ai/v1/systemone`, 모델은 `jev-1.13.0`입니다.
- 기본 API 사용: 기본 주소의 `/v1/chat/completions` 같은 생성 경로를 `/v1/systemone`으로 바꾸고 기본 인증과 모델 `jev`를 사용합니다. 해당 프로바이더가 System One과 이 모델 이름을 지원해야 합니다.
- 로어북 검색, 데이터 준비, 뉴뉴 주제 분류, 놓치지마 검사 보조, 초간단 질문을 따로 켜고 끌 수 있습니다.
- 초간단 질문은 저장된 가격·수량·상태 등을 읽습니다. 새로운 값을 작성하거나 공격·구매를 실행하지 않습니다. 모호하면 기본 API가 대상을 해석합니다.

Jev가 받은 질문과 선택 기준은 영어이며 로어북·이름·채팅은 원문을 유지합니다. 새 설명과 고유 데이터는 기존 생성 API가 작성합니다. 불확실한 판단이나 연결 실패는 기존 처리로 이어집니다.

## 이번 점검에서 수정한 내용

- 공통 물품의 초간단 질문이 실제 instanceId와 장착 슬롯을 연결하도록 수정했습니다.
- 강화 정보가 있는 거래 견적·물품 상태가 저장 스키마에서 거부되는 문제를 수정했습니다. 강화 정보가 없는 기존 자료도 읽습니다.
- 무림의 구형 스탯 참조가 편집 미리보기와 적용 사이에 변환되면서 잘못 변경 충돌로 판단되는 문제를 수정했습니다.
- 명시적인 새 몬스터 개체에는 기존 인물 정체성 후보를 추천하지 않도록 했습니다.
- 현실 수면은 입력 분 그대로 계산하고 같은 시각 갱신에서 중복 경과하지 않습니다. 접속 중 생활 부담 배율, 현실 사망·자리 비움의 게임 행동 제한과 공개 경고를 유지합니다.

## 확인 범위

제공된 채팅의 Chatindex 42~53에서 호스트 진단과 연결되는 게임 호출 21건은 모두 완료됐습니다. 새 Jev 요청 14건은 모두 HTTP 200이며, 중앙값은 약 0.69초입니다. 새 장소·조우 준비에는 여전히 긴 생성 시간이 남아 있습니다.

101건의 로컬 자동 검사는 이번 후속 변경 전 기록입니다. 후속 배포의 확인 범위는 소스 수정과 배포 생성입니다.

실제 자료를 정리한 [Jev 사용기](NyoruRPG-Jev-사용기.md)에서 시간·응답 품질·가격 계산과 측정의 한계를 확인할 수 있습니다.
