# NyoruRPG 0.23.0 · 행동 게이지

공통 d100·얼터네이티브 헌터·에렌샤 온라인·무림에 행동 게이지 전투를 추가합니다. 기존 턴테이블과 자유 진행도 계속 선택할 수 있습니다. 로맨스 판타지·미연시의 사회 판정은 변경하지 않습니다.

## 켜는 위치

전투 밖에서 플러그인의 **현재 상태 → 전투 방식 → 진행 방식 → 행동 게이지 → 설정 저장**을 선택합니다. 에렌샤에서는 **아바타 → 전투 방식**입니다. 전투 중에는 진행 방식을 바꿀 수 없습니다.

연결 모듈 v1 사용자는 **NyoruRPG.js만 업데이트**합니다. 게임 재구축이나 모듈 재설치는 필요 없습니다. 기존 세이브는 원래 턴테이블 또는 자유 진행을 유지하며 행동 게이지는 직접 선택했을 때 사용합니다.

## 진행 원리

- 각 인물은 게이지100에 도달하면 행동합니다. 일반 행동을 마친 뒤100을 소비하고 다시 충전합니다.
- 속도가 두 배인 인물은 같은 전투 시간 동안 대략 두 배 자주 행동합니다. 한쪽이 연속으로 행동할 수 있습니다.
- 동시에 준비되면 현재 전투에 저장된 참가 순서로 처리합니다. 새 참가자·소환수는0부터 충전합니다. 기습은 기존대로 지정된 공격자가 먼저 행동합니다.
- 메인 AI 응답 시간, 유저가 생각하는 시간, 창을 열고 닫는 시간은 전투 시간을 흐르게 하지 않습니다. 엔진이 다음 행동자 또는 시간 효과 시점까지만 계산합니다.
- 연속 타격·명중 후 연계·반격은 기존 처리 방식을 사용하며 일반 행동 게이지를 추가 소비하지 않습니다. 각 기술의 기존 비용·명중 판정은 적용합니다.

**행동자를 보여주는 것과 서술을 멈추는 것은 별개입니다.** 상위 RP에서 사용자 행동이 위임되어 있고 지휘관·행동 모드가 꺼져 있으면 자동으로 이어갈 수 있습니다. 메인 AI도 같은 답변에서 실제 필요한 다음 행동을 호출할 수 있습니다. 위임되지 않은 사용자 선택, 직접 조작 옵션, 미결 반응, 전투 종료는 지킵니다.

한 호출의 자동 진행은 제한된 행동 묶음입니다. **전투가 길어**를 함께 켜면 기존 수치로 최대60회 일반 행동까지 계산합니다. 승리를 보장하거나 실제2~3라운드로 수치를 줄이는 기능은 아닙니다. 아직 전투가 끝나지 않았다면 다음 호출에서 저장된 게이지를 이어갑니다.

## 기본 속도와 편집

기본 충전 속도10이면100까지10 논리 시간이 필요합니다. 화면에서는 이 시간을 **기준 차례분1**로 표시합니다. 능력 차이는 제곱근 비율로 반영해 수치가 큰 캐릭터의 속도가 그대로 수백 배가 되지 않게 합니다.

| 룰북 | 기본 속도 BASE |
| --- | --- |
| 공통 d100 | `10 × √(max(1, DEX) / 10)` |
| 얼터네이티브 헌터 | `10 × √(max(1, AGI) / 10)` |
| 무림 | `10 × √(max(1, SENSE + OUTER / 20) / 10)` |
| 에렌샤 | `10 × √(1 + 이동 숙련 점수 / 50)` |

에렌샤의 이동 숙련 점수는 기존 `80 × Grade + 5 × Grade × (Grade − 1) + Lv`를 사용합니다. 기본 이동 숙련도 이름은 **스텝**이며 전투 방식에서 다른 숙련도 이름을 지정할 수 있습니다. 해당 숙련도가 없으면 Grade0·Lv0 기준입니다. 캐릭터 레벨을 이동 숙련도로 대신하지 않습니다.

**행동 게이지 속도 설정**에서 `BASE`, `BASE * 1.2`, `max(1, AGI)` 같은 수식으로 편집합니다. 해당 룰북의 저장된 능력치 키를 사용하며 에렌샤는 `GRADE`·`MASTERY`를 사용할 수 있습니다. 이 수식은 전투의 행동 순서에만 적용합니다. 피해·명중·자원·성장 수식을 바꾸지 않습니다.

속도 배율은 현재 적용된 능력치와 효과를 반영합니다. 뉴뉴에게 진행 방식이나 수식의 편집 제안을 요청할 수도 있습니다. 제안은 기존처럼 사용자가 저장한 뒤 적용됩니다.

## 게이지 효과와 지속 기준

기술·장비·소모품의 기존 **효과 추가**에서 다음 항목을 사용합니다.

- **행동 게이지 충전 속도**: 더하기는 속도 수치, 곱하기1.5는 충전 속도50% 증가입니다. 상시 장비·패시브도 사용할 수 있습니다.
- **현재 행동 게이지 증감**: 더하기30은 게이지30포인트 증가입니다. 사용·명중·자동 조건 발동 시 즉시 적용하며, 진행 중인 게이지 전투에서만 작동합니다. 일반 행동 중 자기 게이지를 올리면 행동 소비 후 남은 부분을 보존합니다.
- 준비된 세팅: **게이지 가속 / 게이지 둔화 / 행동 촉진 / 행동 지연**.

기존 **선공 보정**은 게이지 모드에서 첫 충전량에 반영합니다(−75~75). 지속적인 빠르기는 새 충전 속도 효과로 설정합니다. 기존 턴테이블의 선공 계산은 유지합니다.

효과의 **중첩·성장·상세 조건 → 지속 기준**에서 선택합니다.

| 기준 | 적용 |
| --- | --- |
| 대상의 자기 차례 | 대상이 자기 행동 턴을 마칠 때 감소. 기존 효과의 기본값 |
| 전투 시간 | 게이지 모드에서 기본 속도로 한 차례 걸리는 시간마다 감소. 지속3이면 기준 차례분3 |

전투 시간 기준의 지속 피해·회복도 같은 간격으로 적용합니다. ‘행동할 때’ 발동은 실제 행동마다 적용합니다. 시간 기준의 일시적인 기절·동결은 그 기간 동안 충전을 멈추며 시간이 지나면 풀립니다. 자기 차례 기준은 준비된 행동을 넘기며 만료됩니다. 게이지 모드 밖에서는 자기 차례 기준으로 처리합니다.

재사용 대기, 소환 유지 횟수와 구형 상태 효과는 기존 자기 차례 기준을 유지합니다. 새 기준은 효과 편집에서 명시적으로 선택한 항목에 적용됩니다.

## 저장과 결과 표시

현재 게이지·논리 시간·속도 수식·완료 행동 번호를 전투와 함께 저장합니다. 화면과 미니보드는 현재 값을 읽고, 과거 결과 카드는 당시 저장한 값을 표시합니다. 같은 도구 호출을 재전송했다고 게이지를 다시 충전하거나 피해를 다시 계산하지 않습니다.

에렌샤의 PvE·PvP·대련 규칙은 별도로 유지합니다. 새 진행 방식은 다른 게임의 세이브나 룰북을 자동 전환하지 않습니다. MCP 식별자, 연결 모듈, 기존 카드 표식·배치와 호출 완료 경로는 유지합니다.

## 이번 작업의 확인 범위

소스의 두 전투 엔진, 저장 형식, 소환·효과·결과 표시·편집·AI 안내 연결을 수정하고 플러그인·배포 파일을 생성했습니다. 별도 최종 검사, 가상 전투, 모의 호스트, 브라우저, 실제 RisuAI, 모바일 및 유료 API 호출은 실행하지 않았습니다. **설치 후 실제 호출과 표시 동작은 아직 확인하지 못했습니다.** 기존 외부 콜백 시간 초과를 해결하는 패치는 아닙니다.
