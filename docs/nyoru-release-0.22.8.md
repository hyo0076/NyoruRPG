# NyoruRPG 0.22.8

에렌샤의 방어와 퀘스트 누락을 포함해 실제 엔진·편집·저장 사이의 연결을 수정했습니다. 연결 모듈 v1 사용자는 플러그인만 교체하고 Risu를 새로 고침하세요. 기존 게임을 새로 구축할 필요는 없습니다.

## 에렌샤

**숙련도·기술 → 기본 방어 / 기본 회피**가 추가됩니다. 이전에는 태세 처리와 달리 등록 기술의 종류·편집·기본 등록이 연결되지 않았습니다. 이제 해당 기술의 위력·MP·사용 횟수·숙련도·효과를 사용합니다. 기본 방어는 다음 자기 차례까지 피해를 경감하고, 기본 회피는 단일 공격의 명중 난이도를 높입니다. 위력은 편집할 수 있습니다. 기존에 같은 종류/이름으로 만든 기술은 보존하고 없는 기본 기술만 보완합니다.

퀘스트를 수락한 뒤의 진행 기록과 완료 사실을 분리했습니다. 같은 장면에 여러 퀘스트가 생기거나 여러 번 진행해도 첫 기록 때문에 나머지를 무시하지 않습니다. 완료 여부를 밝힌 기록만 보상을 지급하며, 처음 약속한 경험치·돈·명성·숙련도·물품·전직을 한 번만 반영합니다. 없는 보상을 기본값으로 만들어 지급하지 않습니다. 퀘스트 화면과 메인 AI용 현재 상태에 진행 내용과 보상을 함께 표시합니다. 퀘스트 편집은 뉴뉴를 켜지 않아도 사용할 수 있습니다.

몬스터에게 플레이어의 직업·숙련도·지갑·장비 묶음을 새로 생성하지 않고, 다른 인물의 기술 ID를 사용하면 거절합니다. 생활 기술도 사용 횟수와 MP를 소모하며, 실제 사용 뒤 같은 사실을 기록해 숙련 경험치가 두 번 지급되는 경로를 막았습니다. 이미 잘못 생성된 모든 과거 기술을 추정해서 일괄 삭제하지는 않습니다.

## 뉴뉴 편집

각 룰북의 실제 편집 스키마를 뉴뉴에게 전달합니다. 기술의 현재 숙련도·경험치·성장 구간·최대 단계·등급 변화, 무림 기술의 성수와 성장, 에렌샤 숙련도와 생활 기술, 장비·효과를 제안부터 저장까지 연결합니다. 새 기술의 초기 숙련도도 보존합니다.

인물 자원·성장·소지금, 날짜, 관계, 미연시 성향·약속, 로판 설계의 준비, 에렌샤 퀘스트·채집 자원, 무림 가르침·비전, 탐험 장소·지점·장치·보상도 해당 룰북에 맞는 항목별 폼에서 고칠 수 있습니다. 제안만으로 변경하지 않고 저장을 눌러 반영합니다. 모르는 필드는 조용히 버리지 않고 오류를 보여 줍니다. 과거 주사위·지급 이력·인증키·전체 룰북 교체는 제안 편집 대상이 아닙니다.

## 내구도·효과·연계

- 장비 칸에 다른 인물 소유의 ID가 남아 있어도 그 장비를 마모시키지 않습니다. 내구도 변화에 실제 소유자를 표시합니다. 무기는 가한 실제 피해, 방어구는 받은 실제 피해에 따라 닳는 기존 규칙을 유지합니다.
- 자기 HP 비용으로 무기가 닳지 않고, 내구도 0인 장비의 명중 시 효과도 중단됩니다.
- 이름이 같아도 효과·회복량·품질이 다른 제작품/탐험 보상을 합치지 않습니다.
- 명령 연계는 동료의 소유 기술만 사용하고 지휘자의 명중 주사위와 동료의 일반 턴을 소비하지 않습니다.
- 구형 공통 인물의 회피 수식과 사회 룰북의 저장 행동 분류 재사용을 보완했습니다. 검사 보완이 실패하면 그 성공에 의존하는 후속 보완을 계속 실행하지 않습니다.

## API 설정

기본·정밀 구축·검사용 API 각각에서 형식별 주소·모델·키를 보관합니다. 형식을 바꾸면 저장한 설정을 불러오며, 처음 사용하는 형식은 그 형식의 기본 주소와 빈 키를 보여 줍니다. 저장하려는 설정을 입력한 뒤 **연결 설정 저장**을 누르세요. 기존 단일 인증 저장도 읽습니다.

**Gemini Vertex AI → 서비스 계정 JSON**에서 JSON 전체를 입력칸에 붙여넣고 저장합니다. 프로젝트 ID는 JSON에서 읽습니다. 이미 등록되어 있으면 빈 입력칸은 기존 JSON을 유지하며, 지우려면 **JSON 등록 해제 → 연결 설정 저장**을 사용합니다. JSON과 API 키는 기기별 저장소에만 보관하고 게임 백업이나 뉴뉴 문맥에 넣지 않습니다.

## 확인한 범위

현재 출시 엔진·편집 저장·Repository·API 설정의 로컬 검사 **93개 통과**. 구형 검사 전체를 통과한 것은 아닙니다. 이전 테스트의 실패와 이번 검사 범위는 [전체 검사 기록](full-audit-0.22.8.md)에 남겼습니다.

실제 RisuAI, 실제 모바일 화면, 메인/보조 AI 호출, Google 인증 서버는 테스트하지 않았습니다. 퀘스트는 메인 AI가 기록 도구를 호출하거나 사용자가 켠 검사가 누락을 보완해야 하며, 모든 자연어 목표의 달성을 자동 추론하는 기능은 아닙니다. 외부 콜백 시간 초과가 해결됐다고 주장하지 않습니다.
