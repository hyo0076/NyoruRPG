# 에렌샤 온라인 구현 규칙 · 0.22.8 보완

0.22.8은 기본 방어·회피를 실제 기술 목록과 편집에 연결합니다. 다음 자기 차례까지 저장된 기술 위력과 숙련 보너스로 태세를 계산합니다. 기본 위력은 방어 50%, 회피 난이도 +20이며 편집 가능합니다. 상한은 각각 90%와 +80입니다. 회피 태세의 추가 난이도는 단일 공격에만 적용되며 기존 광역 피해 +20% 규칙은 유지합니다. 기존 사용자 기술은 보존하고 없는 기본 기술만 보완합니다.

퀘스트는 수락 때 조건·보상을 저장하고 진행 내용을 따로 갱신합니다. 실제 완료 사실이 전달되어야 저장한 보상을 한 번 지급합니다. 약속하지 않은 경험치/돈을 기본값으로 만들지 않습니다. 같은 사건의 다른 퀘스트와 진행 기록은 서로 중복으로 보지 않습니다. 기술 사용 결과 뒤에 숙련 사실을 다시 기록해도 같은 행동의 숙련 경험치를 두 번 지급하지 않습니다.

사용자가 제공한 `Erencha Online.charx`와 원문 검토 기록을 기준으로 합니다. 아래에서 **보완**으로 표시한 값은 원문 확정 수치가 아닙니다. 원문에 없는 수치를 요청마다 다시 만들지 않도록 프로그램에 고정했습니다.

## 원문 구조

- 캐릭터 레벨과 숙련도 레벨은 별개입니다. 표시 능력치는 없으며 HP·MP를 사용합니다.
- 숙련도 Lv.100에서 승급하면 Grade가 오르고 Lv.0부터 다시 성장합니다. 승급 여부는 RP에서 정하고 MCP에 기록합니다. 플러그인 화면에서 다시 승인하지 않습니다.
- 숙련도 Lv.5에서 첫 전직 퀘스트를 받을 수 있습니다. 직업 관련 숙련도 경험치 1.5배를 적용합니다.
- 기술은 액티브·패시브가 있으며 MP·쿨다운을 보관합니다. 특정 기술의 쿨다운 무시는 그 기술에만 적용합니다. 봄비의 인피니티 드로우를 모든 기술의 무제한 사용으로 확대하지 않습니다.
- 장비 등급 순서는 Common → Rare → Unique → Legendary → Epic입니다.
- +7까지 파괴 없이 강화하고 +8 시도부터 실패 시 파괴될 수 있습니다. 파멸의 잔재를 사용하면 파괴 대신 +0이 됩니다.
- 경매 판매 수수료는 10%입니다. Lv.20 미만 사망 손실은 없습니다. 이후 소지품·장비·골드 중 하나만 잃습니다. 아바타는 전투 종료 후 가까운 마을 병원으로 돌아갑니다. 합의 결투에는 손실·PK를 적용하지 않습니다.
- 명성 500에서 길드 창설이 가능합니다. 서버 전체 경제·길드 운영·원화 환전은 구현 범위가 아닙니다.

## 고정한 보완 계산

| 항목 | 보완 규칙 |
|---|---|
| 원문에 최대 자원이 없을 때 | 최대 HP = 80 + 20×캐릭터 레벨, 최대 MP = 40 + 10×레벨. 보조 AI가 설정에 맞춘 초기값을 제안할 수 있습니다. 이후 레벨마다 HP +20, MP +10 |
| 다음 캐릭터 레벨 경험치 | 올림(100×레벨^1.2). 초과분 이월 |
| 숙련도 다음 레벨 경험치 | 10 + 2×floor(숙련도 Lv/20). 기존 레벨 내 진행 비율 환산 |
| 의미 있는 시도 | 숙련도 경험치 4, 직업 관련 분야는 1.5배. 소수분 이월. 호흡·걷기·단순 달리기는 제외 |
| 기본 명중 | d100 > 저장된 기술 난이도 + 상대 숙련 회피 보정 + 상대 회피 효과 − 사용 분야 숙련 명중 보정 − 명중 효과. 최종 난이도 5–95 |

| 생산·생활 활동 승급 보너스 | 성공한 활동의 캐릭터 경험치 ×1.2^Grade. 기술의 MP 절약도 적용 |
| MP | 올림(기본 MP×절약 배율×(1−숙련 MP 절약률)). 절약 배율 최소 5% |
| 장비 강화 효과 | 기본 위력·방어×1.1^강화 |

| 일반 상점 판매 | 등록 가격의 50%를 기준으로 장비·숙련 판매 보너스 적용. 경매는 등록 가격에서 수수료 10% |
| 명성 할인 | 명성 100마다 구매가 1%, 최대 10%. 숙련 할인을 합한 최종 상한 20% |
| PK 단계 | 비합의 아바타 처치 1회 주황, 3회 빨강, 10회 진홍. 마지막 PK 후 각각 7/30/60 게임 일 경과 시 해제. 횟수 경계는 보완값 |

현재 승급은 Grade 20까지 보관합니다. 전투 쿨다운·강화 지속은 **자기 턴 단위**로 환산합니다. 실패한 호출·상태 조회·같은 사건의 재호출로 쿨다운이 줄지 않습니다. 전투 밖의 실제 활동은 재사용 대기를 진행시키며, 휴식 중 흐른 시간은 RP에서 정합니다. 대기 시간을 넘기려고 상태 조회를 반복하는 방식은 통하지 않습니다.

방어는 다음 자기 턴까지 피해를 50% 줄입니다. 회피 태세는 상대 명중 난이도를 20 높이고, 광역 공격에 맞으면 피해가 20% 증가합니다. 이 계수는 에렌샤용 보완 규칙입니다.

새 물건·기술의 비용·위력·가격은 원문이나 설명을 바탕으로 한 번 작성하고 저장합니다. 다시 사용할 때 보조 AI가 수치를 재작성하지 않습니다. 개별 기술·물건 값은 화면의 편집으로 바꿀 수 있습니다.

성장 점수와 생활 효과의 정확한 계수·환산은 [0.15.0 변경 안내](nyoru-release-0.15.0.md)를 따릅니다. Grade 번호는 0부터 유지합니다.

## 데이터와 도구

`meta.rulebook.id = erencha`로 기존 공통·헌터·사회 엔진과 구분합니다. 인물에 `level/xp`, `proficiencies`, HP/MP, 기술 목록·쿨다운·사용 횟수, 직업·적성·명성·PK를 저장합니다. 소지품, 지갑, 퀘스트, 전투 턴, 사건 중복 방지 기록은 같은 채팅별 저장과 답변별 되돌리기에 포함합니다.

- `rpg_registry`: 첫 등장 인물 준비와 이름 재사용.
- `rpg_play act`: 기술·공격·회피·방어·도주·숙련 활동·휴식·관전.
- `rpg_play explore`: 입장·이동·관찰·조사·조작·종료. 최초 지도와 단서·자원·보상 기록을 재사용합니다.
- `rpg_play record`: 이야기에서 정한 닉네임·적성·숙련도 승급, 수락/완료한 퀘스트, 전직 완료, 실제 시간/장소/현실 전환, 길드 창설.
- `rpg_inventory`: 실제 획득·사용·분실·전달·착용·강화.
- `rpg_economy trade`: 저장된 가격으로 구매·판매·경매 정산.
- `rpg_state`: 현재 상태와 지난 실제 결과 조회.

상태창은 `<Consol>` 한 줄에 레벨·경험치·HP·MP·숙련도·직업·골드·장비·물건·기술·퀘스트·명성·길드를 모두 표시합니다. 처리 결과 카드에는 명중 주사위, 피해, HP 변화, MP 소비, 숙련도 경험치를 담습니다. 최종 답변의 마지막 정상 `<Consol>`에서 레벨·EXP·HP·MP·숙련도·골드·명성 수치만 실제 저장 상태와 맞춥니다. 날짜·시간·장소·닉네임과 다른 서술 필드는 건드리지 않습니다. 상태창 전체를 교체하거나 없던 상태창을 추가하지 않습니다.

적성은 패시브 기술로 한 번만 계산합니다. 초기 구축에서 이미 준비한 적성도 적용된 기술이며 별도 수락·거절 창을 만들지 않습니다. 기존 저장의 같은 이름 적성·패시브는 같은 기술에 연결합니다. 새 적성과 숙련도 승급은 RP에서 결정된 사건을 `record`로 반영합니다.
