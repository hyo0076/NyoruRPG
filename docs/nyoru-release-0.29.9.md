# NyoruRPG 0.29.9 · 전투 결산·파티 경험치·현실 생활

**플러그인만 업데이트. 모듈 v1은 그대로**

## 결과만

**플레이 설정 → 전투 진행 → 결과만**을 켭니다. 초기 구축의 **시작할 때 사용할 플레이 설정**에서도 선택할 수 있습니다. 기존 채팅에서는 기본 OFF입니다.

- D100·얼터네이티브 헌터·무림·에렌샤·택티컬·지르코트에서 위임된 전투를 내부 계산하고 **전투 결산** 카드로 표시합니다. 턴테이블·행동 게이지·자유 진행의 현재 규칙을 사용합니다.
- **전투가 길어**와 함께 켜면 **결과만**을 우선합니다. 명중·피해·방어·이동·탄약·비용·보상 수치를 단축용으로 바꾸지 않습니다.
- 결산에는 실제 승패, 참가자 상태와 자원, 경험치·성장·돈·물품 변화가 나옵니다. 상세에서 부상·효과·장전량·내구도·주요 판정도 확인합니다. 이미 일부 진행한 전투라면 이번 호출에서 발생한 변화만 집계합니다.
- 별도의 획득 처리가 필요한 전리품·탐험 보상을 결산만으로 새로 지급하지 않습니다. 지급된 결과를 다시 지급하지 마세요.
- 지휘관·행동 모드, 위임되지 않은 사용자 선택, 반응·구조 요청은 그대로 우선합니다. 진행 불가나 계산 한도로 중단하면 **진행 중**과 이유를 표시합니다. 패배나 무승부로 처리하지 않습니다.
- 한 호출의 긴 반복은 최대 200라운드·1,000행동·2,000처리 단계 또는 약 8초의 계산 경계에서 끊습니다. 행동 하나의 실제 처리 시간이 포함되므로 8초의 응답시간 보장은 아닙니다. 저장한 현재 전투에서 후속 행동으로 이어갈 수 있습니다. 새 processing/재호출 프로토콜이나 보조 AI 호출은 추가하지 않습니다.
- 메인 AI에는 턴별 steps 대신 결산을 전달합니다. 기존 세부 영수증과 롤백 자료는 보관하며 결과 조회로 확인할 수 있습니다. 봇의 서술 길이·문체는 제한하지 않습니다.

## 경험치 공유

**플레이 설정 → 처치 경험치 → 경험치 공유**에서 켭니다. 초기 구축에서도 같은 옵션을 제공합니다. 인물 레벨용 처치 경험치가 있는 **D100·얼터네이티브 헌터·에렌샤**에 적용합니다. 기본 OFF이며 끄면 이전 지급 방식을 사용합니다.

| 공유 방식 | 기본 처치 경험치 100, 참가 파티원 2명일 때 |
| --- | --- |
| 인원수로 나누기 | 각자 50 |
| 각자 원래 경험치 받기 | 각자 100 |

같은 전투에 참가한 같은 편의 사용자·동료가 대상입니다. 동료가 처치해도 같은 방식으로 나눕니다. 등록만 된 인물·관전자·반대편·소환수는 받는 인원에 넣지 않습니다. 에렌샤에서 소환수가 처치했다면 전투에 참가한 소유자의 편을 기준으로 나눕니다. 전투 참가 정보가 없는 처치에 등록 동료 전체를 임의로 끌어들이지 않습니다.

나누고 남은 정수 1점씩은 참가 순서대로 배분합니다. 배분한 기본 경험치에 개인 장비·효과의 경험치 보정을 적용하고, 헌터는 기존 5배 규칙을 한 번 적용합니다. 보정이 다르면 최종 경험치는 서로 다를 수 있습니다. 퀘스트·개별 사건 보상과 기술/분야 숙련도는 공유하지 않습니다. 무림의 깨달음이나 택티컬·지르코트의 분야 숙련도에 인물 경험치를 새로 만들지 않습니다.

실제 지급은 기존 처치 완료 식별자를 사용하므로 같은 처치의 재시도·검사 보완에서 보상을 중복 지급하지 않습니다. 이미 받은 과거 경험치는 소급 재배분하지 않습니다.

## 에렌샤 현실 생활

현실모드를 켜면 **이야기 속 현실 경과 시간**으로 별도의 생활 시계가 진행합니다. 기본 배율은 **5배**입니다. 게임 안의 날짜·시각이나 실제 PC/API 대기 시간을 생활 시간으로 사용하지 않습니다.

- 새로 기록한 현실 45분은 생활 시계 225분으로 계산합니다. 회복 행동이 없었다면 허기 +15, 갈증 +22.5, 피로 +15, 화장실 부담 +26.25입니다.
- 욕구·건강·시간에 따른 회복과 월세/이용료의 주기는 같은 생활 시계를 따릅니다. 시간과 시간당 증가량을 각각 5배로 곱하지 않습니다. 금액·식자재 수량·한 번의 식사 효과는 5배로 바꾸지 않습니다.
- 이미 저장된 45분이나 기존 욕구값을 소급해서 5배로 만들지 않습니다. 업데이트 이후 새로 기록한 경과 시간부터 적용합니다. 뉴뉴에게 **현실모드 진행 배율을 3배로 바꿔 줘**처럼 요청할 수 있습니다. 허용 범위는 0.1~20배입니다.
- 메인 AI는 배율을 적용하기 전 현실 경과 분을 clock 또는 real_life에 한 번 기록합니다. 게임 시계만 바꾸거나 이미 처리한 시간을 표시할 때는 minutes:0입니다. 현실 경과가 기록되지 않았다면 이 기능이 임의로 누락된 시간을 만들어 내지는 않습니다.

**현재 장면에 있는 다른 실제 온라인 이용자(entity:avatar)**도 인물별로 욕구와 건강을 보관합니다. 게임 NPC·몬스터·소환수는 제외합니다. 등록만 하고 현재 장면에 없는 인물의 오프라인 생활 전체를 자동 계산하지 않습니다. 다른 이용자에게 사용자 원화·식자재·정기 비용을 적용하지 않습니다.

메인 AI에는 **인물 이름 + 식사 필요 / 수분 필요 / 화장실 필요 / 수면 부족**처럼 경고를 전달합니다. 따라서 그 인물이 “밥 좀 먹고 올게”, “잠시 화장실”처럼 반응하는 데 사용할 수 있습니다. 실제 대사와 퇴장 여부는 원래 봇이 판단하며 플러그인이 정해진 대사를 강요하지 않습니다. 일반 상태창에는 숨겨진 욕구 수치를 늘어놓지 않습니다.

실제로 자리 비움이 발생하면 그 인물의 real_life leave_game, 돌아오면 return_game을 기록합니다. eat/drink/toilet/sleep은 해당 인물만 회복하며 식사·수면 중에는 자리 비움으로 보관합니다. 다른 인물 때문에 사용자의 게임/현실 접속 상태를 바꾸지 않습니다. 동료의 sleep minutes:0은 수면 시작이고, 이후 공유 현실 시간이 지나면 그 인물의 피로가 회복합니다. 같은 시간 구간을 여러 인물에게 반복 입력하지 않습니다. 자리 비운 아바타는 게임의 자동 공격·연계 행동을 하지 않으며, 복귀 사실이 기록되면 행동할 수 있습니다. 자리 비움이 곧 무적이나 전투 이탈을 뜻하지는 않습니다.

뉴뉴에서 해당 인물을 선택하면 그 인물의 욕구·건강·자리 비움·수면을 편집할 수 있습니다. 새 등장인물의 알려지지 않은 과거 생활 수치를 임의로 추측하지 않고 기본값으로 시작합니다.

관련 소스를 수정하고 로컬 배포를 생성했습니다. 요청한 범위에 따라 별도 최종 검사·모의 전투·실제 RisuAI·API 실행은 하지 않았으며 GitHub에는 게시하지 않았습니다.
