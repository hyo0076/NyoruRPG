# NyoruRPG 0.29.8 · 등록 인물 정리

**플러그인만 업데이트. 모듈 v1은 그대로**

등록 인물에서 동료·NPC와 현재 장면에 선택한 적·전투 참가자를 먼저 표시합니다. 그 밖의 적은 아래 **적·몬스터 기록**에 접어 둡니다. 에렌샤를 포함한 모든 룰북의 공통 등록 인물 화면에 적용됩니다.

- **적·몬스터 기록**을 누르면 저장된 적을 확인하고 기존 편집창을 열 수 있습니다.
- **인물·적 찾기**에 이름·닉네임·별칭·ID를 입력하면 접힌 기록도 함께 검색하며 결과를 펼쳐 줍니다.
- **현재 장면에 표시**를 체크한 적은 일반 목록으로 올라옵니다. 전투 참가자도 전투 중에는 일반 목록에 표시됩니다.
- 목록을 접고 펴는 동작은 게임 데이터를 바꾸지 않습니다. 인물 ID·수치·보상·전투·탐험 기록과 세이브·롤백을 보존하며, 기존 비활성/퇴역 적의 제외 기준도 유지합니다.

관련 소스를 수정하고 로컬 배포를 생성했습니다. 실제 RisuAI·모바일 화면과 별도 최종 검사는 실행하지 않았습니다. GitHub에는 게시하지 않았습니다.
