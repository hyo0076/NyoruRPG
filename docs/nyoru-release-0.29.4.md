# NyoruRPG 0.29.4 · 테마별 결과 카드

**플러그인만 업데이트. 모듈 v1은 그대로**

획득·회복·거래·성장·퀘스트·탐험·효과·강화 결과를 각각의 카드로 표시합니다. 저장된 수량과 회복 전후 수치, 정산액·성장·보상·강화 단계 등을 읽기 쉽게 배치하고, 원래 판정과 비용·변경 내역은 **상세**에서 확인합니다.

- **카툰**: 각진 도형과 큰 기울임 숫자.
- **밤빛 마도서**: 남색 표지, 금속 모서리와 룬 장식.
- **로맨스**: 꽃 장식과 부드러운 편지 색상.
- **사이버**: 청록빛 회로와 보색인 주황빛 제목·숫자.

현재 선택한 카드 테마로 적용됩니다. 카드 호환 표시에도 배치와 색상을 연결하며, 환경에 따라 장식이 단순해질 수 있습니다. 실제 결과에 최대 자원과 전후 수치가 저장된 경우에만 회복 막대를 표시합니다. 기록에 없는 과거 잔액이나 보상을 임의로 만들지 않습니다.
