# NyoruRPG 0.30.5 · 인물 간 능력치·자원 연결

**플러그인만 업데이트. 모듈 v1은 그대로**

소환수 전용 보정과 별도로 일반 인물끼리도 연결합니다. 계약자와 사역마, 같은 생명력을 쓰는 쌍둥이, 동료의 마력을 빌려 사용하는 기술처럼 저장된 규칙으로 계산하는 기능입니다. 처음에는 연결이 없으며 직접 추가한 연결만 적용합니다.

## 설정하기

1. **등록 인물**에서 보정을 받거나 자원을 빌리는 인물을 찾습니다.
2. **능력치·자원 연결**을 누릅니다.
3. **수치 보정** 또는 **자원 연결**을 펼쳐 항목을 추가합니다.
4. 이름·원본 인물·사용할 값과 계산 방식을 설정합니다. **입력한 보정 계산해 보기**로 숫자를 확인합니다.
5. **변경 저장**을 눌러 현재 게임에 적용합니다. 계산해 보기만 누르면 저장하지 않습니다. 기존 인물의 원본 능력치는 유지합니다.

각 연결의 **사용**을 끄거나 해당 행을 삭제한 뒤 저장하면 해제됩니다. 연결 이름과 현재 계산은 등록 인물에서 다시 펼쳐 볼 수 있습니다. 자원 공유/대납의 대상이나 방식은 전투가 끝난 뒤 변경합니다. 단순 이름 수정이나 수치 보정은 전투 중에도 편집할 수 있습니다.

## 수치 보정

계산 순서는 **원본 값 ÷ 기준 단위 → 내림/반올림/올림 → × 계수 + 고정값 → 보정 하한·상한**입니다. 한 인물이 받는 여러 행은 합산합니다. 음수 보정도 허용합니다.

| 원하는 연결 | 편집할 인물 | 원본과 계산 | 더할 항목 |
| --- | --- | --- | --- |
| A의 공격에 B의 힘 절반 추가 | A | B 능력치 STR, 기준 1, 그대로, 계수 0.5 | 기술 위력 |
| A의 최대 마력에 따라 B의 힘 증가 | B | A 최대 자원 mp, 기준 1, 그대로, 계수 0.1 | 능력치 STR |
| A의 레벨마다 B의 힘 +2 | B | A 레벨, 기준 1, 그대로, 계수 2 | 능력치 STR |
| A의 레벨 5마다 B의 힘 +2 | B | A 레벨, 기준 5, 내림, 계수 2 | 능력치 STR |
| A의 체력이 낮아질수록 B의 위력 증가 | B | A 남은 자원 비율 hp, 기준 1, 계수 -0.2, 고정값 20, 하한 0 | 기술 위력 |

`STR`, `mp`, `hp`는 예시입니다. 헌터의 실제 능력치, 무림의 `OUTER`·`INNER`·`qi` 등 **해당 인물에게 저장된 ID**를 고릅니다. 레벨과 경지는 원본 키를 비워 둡니다. 숙련도는 저장된 숙련 ID를 사용하며 에렌샤는 Grade/Lv의 기존 숙련 수치, 공통 기술은 숙련 단계, 택티컬은 숙련 rating을 읽습니다.

현재 자원/비율은 실제 잔량을 읽습니다. 능력치·최대 자원은 장비와 상태를 반영하되 **다른 인물 연결과 소환자 보정으로 증가하기 전** 값을 읽습니다. A와 B가 서로 보정하더라도 증가한 결과를 끝없이 다시 가져오지 않습니다. 연결만 추가해서 현재 HP·MP를 충전하지 않습니다.

기술 위력·명중은 특정 보유 기술 ID로 한정하거나 대상 키를 비워 전체에 적용합니다. 능력치와 최대 자원에는 실제 대상 ID가 필요합니다. 다른 보정은 대상 키를 비웁니다. 유지 조건은 **원본 인물이 활동 가능 / 같은 장면에서 활동 가능 / 등록되어 있으면 유지** 중 선택합니다. 조건이 맞지 않거나 원본 항목을 찾지 못하면 수치 보정은 적용되지 않습니다.

## 자원 공유와 비용 대납

**잔량·최대치 공유**는 이 인물의 자원을 원본 인물의 자원에 연결합니다. 한쪽이 피해·회복·비용으로 바뀌면 같은 실제 잔량을 봅니다. 최대치를 더하지 않으며 원본 최대치를 그대로 씁니다. 공유받는 인물에게 최대치 보정을 추가하려 하면 원본 인물에 설정하도록 안내합니다.

HP와 HP처럼 역할이 같은 수치 자원을 연결합니다. 공유 HP가 0이면 연결된 인물도 해당 룰북의 전투불능 규칙을 따릅니다. 한 번의 자원 변경을 표시 인물 수만큼 반복하지 않습니다. 광역 공격이 두 인물에게 각각 명중한 경우에는 별개의 실제 피격입니다. 공유는 원본의 활동 여부에 따라 임의로 끊기지 않으며 명시적으로 해제할 때까지 유지됩니다.

연결 시 기존 양쪽의 남은 비율 중 낮은 쪽에 맞춰 공유 원본을 제한합니다. 원래 최대치가 0인 자원은 원본 풀을 줄이지 않습니다. 해제 시 공유 전 잔량과 공유 풀의 남은 비율을 기준으로 제한해 복구합니다. 반복 연결·해제로 무료 회복하지 않습니다. 연결 이름만 바꾸거나 순서를 정리할 때에는 잔량을 다시 제한하지 않습니다.

**기술·활동 비용만 대신 지불**은 자신이 쓰는 자원의 비용을 지정한 다른 인물의 자원에서 차감합니다. 피격·회복이나 자원 최대치를 공유하지 않습니다. 공통 기술·반응·자동 발동, 에렌샤 전투·생활, 직접 소환, 선택 기능의 수련 비용에 적용합니다. 지불자가 없거나 조건이 맞지 않거나 잔량이 부족하면 행동을 실행하지 않습니다. 원래 사용자의 자원으로 몰래 바꾸어 차감하지 않습니다. 최대/현재 자원의 비율 비용도 실제 지불 자원을 기준으로 계산합니다.

같은 실제 풀로 합쳐지는 비용은 합산한 뒤 부족 여부를 확인합니다. 연결한 생명력을 비용으로 0까지 소비하지 않습니다. 피해·출혈·부상·무림 수련의 신체 부담·생활 욕구를 비용 대납으로 바꾸지는 않습니다.

## 룰북 범위

- **D100·얼터네이티브 헌터·무림**: 해당 룰북 능력치, 위력·피해·명중·방어·최대 자원·행동 속도·이동력과 수치 자원 연결.
- **에렌샤**: 존재하는 레벨·숙련·자원을 기준으로 위력·명중·방어·최대 HP/MP·게이지·이동력 등을 연결. 없는 STR 같은 능력치를 새로 만들지 않습니다.
- **택티컬·지르코트**: 능력치·무기 위력·무기 명중·행동 속도 보정. 부위별 부상/HP를 통합 HP로 바꾸어 공유하지 않습니다.
- **로맨스 판타지·미연시**: 해당 룰북 능력치 보정. 기존 성장 수치는 별도로 보존합니다. 실제 등록된 수치 자원이 있을 때만 자원 연결이 가능합니다.

기존 소환수의 **유지·성장 설정 → 소환자 보정**도 유지합니다. 같은 보정을 두 화면에서 동시에 켜면 합산되므로 원하는 한쪽에만 설정하세요.

## 뉴뉴와 도구

뉴뉴에게 “A의 최대 MP의 10%만큼 B의 힘을 더해 줘. A가 활동 중일 때만” 또는 “B의 MP 비용을 A의 MP에서 쓰도록 연결해 줘”처럼 요청합니다. 뉴뉴가 **actor_links** 제안을 만들면 편집창에서 확인하고 저장합니다. 제안 문장만으로 실제 저장되지는 않습니다.

메인 AI는 기존 `rpg_state`의 `actor_links`로 필요한 경우 연결만 조회할 수 있습니다. 각 행동에는 코드가 자동으로 연결을 적용하므로 사전 조회나 별도 AI 요청이 필수인 기능이 아닙니다. 원본 수치에 연결 보정을 다시 저장하거나 이미 낸 비용을 다시 차감하지 않습니다.

설정과 공유 전 기록은 같은 게임 저장·백업·되돌리기에 포함됩니다. 이번 배포는 소스 수정과 배포 생성 범위이며 실제 RisuAI·모델 실행 및 별도 최종 검사는 수행하지 않았습니다.
