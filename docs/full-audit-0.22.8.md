# NyoruRPG 전체 구조 검사 · 0.22.8 작업 기록

2026-10-01. 사용자가 전체 검사를 명시적으로 요청했다. 이전의 별도 최종 검사 생략을 이번 전체 소스·로컬 자동 검사에 적용하지 않는다. 실제 RisuAI, 유료 API, 실제 모바일 화면은 실행하지 않는다. 하위 에이전트는 사용하지 않는다.

## 기존 검사 결과

기본 `npm test`는 numeric 계열과 repository만 대상으로 하고 있었다. 에렌샤/사회/무림의 현행 엔진을 직접 실행하는 전용 검사가 없었다. 전체 기존 테스트 28개 파일을 제한 시간과 함께 실행한 결과: 380개, 통과 212, 실패 166, 취소 2. 원시 로그: `artifacts/full-audit-0.22.8/baseline-bounded.tap`.

166개를 모두 제품 버그로 세지 않는다. 삭제된 편집 API, 이전 구축 응답 구조, 변경 전 MCP 이름/지침, 소지품 0개 보관을 기대하는 테스트가 포함된다. 동시에 회피 수식 오류처럼 실제 호환성 결함도 발견되었다. 기존 테스트 전체가 통과했다고 보고하지 않는다.

## 현재 실행한 로컬 검사

`current-engine`, `current-editing`, `current-quests-defense`, `current-connections`, `current-api-settings`, `repository`의 **93개 검사 통과, 실패 0**. 로그는 `artifacts/full-audit-0.22.8/current-links.tap`에 보관한다. 실제 사용자 세이브 대신 별도 작은 입력 자료로 엔진과 편집 저장 경계를 호출했다. 인공 입력에서 해당 결과가 재현됐다는 의미이며 전체 플레이 완성 판정이 아니다.

현재 출시 빌드는 numeric-* 파일을 제외한다. 기본 검사 명령을 실제 출시되는 룰북/편집/저장 검사로 바꾸고, 이전 전체 검사는 `test:legacy`로 남겼다. 이전 실패를 삭제하거나 모두 성공 처리하지 않았다. 예전 구축 응답·MCP 이름·삭제된 편집 API를 가정하는 검사와 아직 재확인하지 않은 실패가 남아 있으므로 이전 380개 전체가 정상이라고 말할 수 없다. 필요 근거가 없는 반복 검사·브라우저·모의 호스트 검사를 최종 단계에 추가하지 않았다.

API 연결/인증, 모듈 활성 채팅 격리, UI 바인더와 소유자 선택, 진단·설정·저장 분리도 소스에서 읽었다. 외부 서버 인증·실제 주입 순서·모바일 동작은 실행 검증하지 않았다. 소스에서 읽었다는 것만으로 해당 영역을 통과로 분류하지 않는다.

## 한계

사용자 스크린샷의 원본 세이브·실제 호출 인수가 없어 그 세이브에서 왜 슬라임에게 해당 기술/장비가 들어갔는지까지 확정하지 않는다. 합성 데이터로 재현한 결함과 실제 사용자 세이브의 원인은 구분한다. 실제 Risu의 표시, 메인/보조 모델의 장기 사용, 네트워크 응답과 외부 콜백 제한은 로컬 검사 통과로 보증할 수 없다.
