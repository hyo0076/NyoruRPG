# NyoruRPG 0.30.8 · 몬스터 원형과 장소 재방문

**플러그인만 업데이트. 모듈 v1은 그대로**

에렌샤 숙련도 목록은 표시 공간이 충분한 PC 화면에서 두 열로 배치합니다. 이름과 수치 사이의 빈 공간을 줄이고 등급·레벨 글씨와 경험치 바를 키웠습니다. 창을 좁히거나 모바일로 보면 기존 한 열로 표시합니다. 숙련도를 눌러 효과·편집을 펼치는 방식과 경험치 숫자 숨김은 유지합니다.

같은 종류의 몬스터를 준비할 때 첫 기본 자료를 게임 안에 보관하고 다음 개체에 재사용합니다. HP 30·기본 공격·마법 면역으로 만든 슬라임이라면 같은 원형의 다음 슬라임도 그 자료를 사용합니다. 공격 기술뿐 아니라 패시브·면역·이동·속도·장비와 효과를 함께 복사합니다. 세 마리의 ID와 남은 HP, 사용 횟수, 재사용 대기는 각각 독립합니다. 기존 개체의 부상·버프·피해를 새 개체에 옮기거나, 새 개체를 만들면서 기존 적을 회복시키지 않습니다.

기존 원형이 있으면 그 원형을 위해 로어북 검색이나 생성 AI를 다시 호출하지 않습니다. 서로 다른 새 종류가 처음 등장할 때는 각각의 자료 준비가 필요합니다. 같은 호출에 동종 여러 마리가 있어도 첫 개체를 준비한 다음에는 같은 원형을 사용합니다. 실제 시간 단축량은 실사용으로 확인해야 합니다.

화염슬라임·대왕슬라임은 일반 슬라임과 별개입니다. 이름의 일부나 넓은 별칭으로 원형을 합치지 않습니다. `monsterType`에는 번호를 뺀 전체 종류 이름을, 같은 이름으로 구분되지 않는 실제 형태·등급에는 `variant`를 사용합니다. 플레이어 레벨이나 새 개체 번호는 변종이 아닙니다. 기존 고유 보스·NPC는 `unique` 또는 지르코트의 기존 보스 식별자를 통해 동일 인물로 유지합니다.

일반 탐험 장소는 종료해도 지도·방문·기믹·채집·보상·처치 기록이 남습니다. `start`에 저장된 장소 ID(`placeId`) 또는 같은 이름을 전달하면 기존 지도를 사용합니다. 이미 방문한 구역 이름을 장소 이름으로 전달한 경우에도 해당 구역을 찾아 연결하며, 활성 장소 안에서 이동할 때는 기존 `move`를 사용합니다. 도구에 최근 저장 장소 목록도 짧게 반환합니다. 이름이 같은 장소가 여러 개라면 ID로 구분합니다.

얼터네이티브 헌터의 게이트는 별도 인스턴스입니다. 퇴장한 게이트는 기록으로 남고 실제 새 게이트에는 새 `instanceKey`를 사용합니다. 같은 게이트의 반복 호출은 기존 인스턴스를 사용합니다. 새 게이트에서도 이미 알려진 같은 몬스터 종류의 기본 자료는 재사용합니다. 구형 공통 탐험 중 원본 방 자료가 있는 저장은 기존 지도와 사건 상태를 이어받습니다.

출현 목록은 **어떤 종류가 사는지**를 저장합니다. 자동 개체 수 조절이나 주기적 리젠 시뮬레이션은 추가하지 않습니다. 실제로 새로운 무리가 등장했을 때만 새 개체를 연결합니다. 재방문 자체로 처치한 보스·보상·채집원을 초기화하지 않습니다.

메인 AI가 사용하는 기존 `rpg_play`의 `explore`에 다음 자료를 함께 전달할 수 있습니다. 공격마다 추가 조회를 요구하지 않습니다.

- 새로 등장한 무리: `action: encounter`, `eventId`, `enemies: [{name, monsterType, variant, count}]`. 실제 입장·이동 호출에 `enemies`를 함께 넣을 수도 있습니다. 수량은 장면에서 정한 실제 등장 수이며, 호출 하나당 처리 한도와 생태계 개체 수는 별개입니다.
- 실제 지역 사건: `action: population`, `eventId`, `population: {mode: replace, scope: place, reason, species: [{name}]}`. 한 구역만 바꾸려면 `scope: room`을 사용합니다. 입장·이동과 같은 호출에서도 처리할 수 있습니다.
- 사건 종료: 새로운 사건 ID로 `population.mode: restore`를 전달합니다. 원래 출현 종류를 다시 사용하되 옛 적을 회복·부활시키거나 보상을 다시 지급하지 않습니다.

예를 들어 과수원 길에 마왕 군단이 침공하면 지도는 그대로 두고 출현 목록을 실제 침공군 종류로 바꿉니다. 기존 두더지 조우는 과거 기록으로 보관하며 침공 이후의 기본 적으로 다시 내보내지 않습니다. 물러난 기존 적은 처치로 계산하지 않습니다. 사건 교체만으로 새 적을 소환하거나 전투를 시작하지도 않습니다. 현재 출현 목록과 다른 적은 실제 지역 변화부터 기록하도록 안내합니다. 같은 사건 ID는 반복 적용하지 않습니다.

이미 저장된 서로 다른 적의 HP를 일괄 덮어쓰지 않습니다. 구형 d100·헌터·무림·에렌샤 저장은 같은 전체 이름의 기본 정의를 처음 재사용할 때 원형으로 보관하고, 이미 존재하는 개체 상태는 유지합니다. 원형 저장 이후의 개체 편집은 다른 개체를 자동으로 바꾸지 않습니다. 원형과 지역 사건 기록은 게임 백업·되돌리기에 함께 포함됩니다.

소스 수정과 로컬 배포를 생성했습니다. 별도 최종 검사·실제 RisuAI·유료 API 실행은 하지 않았으며, GitHub 게시 보류를 유지합니다.
