# NyoruRPG 0.27.0 · 택티컬 첫 구현 · 로컬 배포

시스템 구축의 룰북 선택에 **택티컬**을 추가했습니다. 연결 모듈 v1은 그대로 사용하고 플러그인 `NyoruRPG.js`를 교체합니다. 기존 여섯 룰북의 세이브를 택티컬로 자동 변환하지 않습니다. 택티컬을 선택해 새 구축을 적용하면 별도 초기 세계가 만들어지고 이전 게임은 버전 기록에 남습니다. 같은 택티컬 게임을 다시 구축하면 기존 인물·장비·숙련·부상·전투 진행값을 보존합니다.

이번에는 사용자 요청에 따라 구현과 배포 생성까지만 진행했습니다. **별도 테스트·가상 전투·브라우저·실제 RisuAI·유료 API를 실행하지 않았습니다.** 실제 모델의 도구 선택, 모바일 표시, 장시간 저장과 전투 밸런스는 아직 실사용으로 확인하지 않았습니다. GitHub에 게시하지 않았습니다.

## 시작

1. 새 채팅에서 NyoruRPG 시작 안내를 열고 택티컬을 선택합니다.
2. 사용자 페르소나와 세계관·장비·능력 자료가 있는 로어북을 선택합니다. 추가 요청에 특수 장비나 시작 조건을 적을 수 있습니다.
3. 구축 초안에서 대원·숙련·기술·장비를 확인하고 편집합니다. 기본 진행은 행동 게이지이며 턴테이블·자유 진행도 고를 수 있습니다.
4. 적용한 뒤 **대원 상태 / 등록 인물 / 숙련도·기술 / 장비·파츠 / 분대·카르마 / 작전 지역**을 사용합니다.

초기 구축에는 보조 AI가 필요합니다. 이미 저장한 대원과 기술·무기로 행동을 계산할 때에는 새 정의 준비를 위해 보조 AI를 다시 부르지 않습니다. 새 인물·기술·구매 품목·지역을 처음 만드는 경우에는 준비 요청이 발생할 수 있습니다.

## 무기·장비·파츠

기본 계열은 권총, 리볼버, 기관단총, PDW, 카빈, 돌격소총, 전투소총, 지정사수소총, 볼트액션 정밀소총, 대구경 정밀소총, 샷건, 경기관총, 기관총, 활, 석궁, 단검, 도검, 둔기, 장병기, 맨손입니다. 각 계열의 기본값을 준비한 뒤 개별 장비를 편집할 수 있습니다.

| 설정 | 동작 |
|---|---|
| 탄창·탄약 규격 | 같은 ammoType의 소지 탄약만 장전합니다. 연사와 산탄은 실제 발사 수만큼 탄창에서 차감합니다. 산탄 알갱이마다 탄약 한 발을 추가 소모하지 않습니다. |
| 장전 행동 | 기본 1회. 다단계 장전 중 무기를 바꿔도 남은 단계가 유지됩니다. |
| 매 발 준비 | 일반 볼트액션 기본 1회, 대구경 정밀소총 기본 2회. 탄피 배출·다음 탄 준비를 행동으로 처리합니다. 재장전으로 남은 준비를 더 짧게 우회하지 않습니다. |
| 주무기·스위칭 | 둘을 동시에 장비해 두고 행동마다 사용할 무기를 고릅니다. 빠른 교체 보너스가 아니며, 다른 무기의 조준경·탄약 효과를 합치지 않습니다. 한 호출로 두 무기를 동시에 발사하는 기능은 포함하지 않습니다. |
| 방패 | 방호 부위·정면 각도·방호력·필요한 손·무게·내구도를 가집니다. 두 손이 필요한 무기는 방패로 손을 점유한 동안 사용할 수 없습니다. |
| 등급 | 보급·개선·정예·특수·실험. 새 정의의 내구도·기본 보정·방호 기본값에 영향을 줍니다. 이미 편집된 개별 수치를 등급 변경만으로 덮어쓰지 않습니다. |
| 파츠 | 옵틱·총구·그립·개머리판·탄창 위치·양각대 등 무기의 장착 위치를 사용합니다. 계열·규격 태그·다른 파츠와의 충돌을 확인합니다. |

파츠의 실제 지원 보정은 명중, 반동, 사거리 증감 %, 제압, 소음, 행동 시간입니다. 탄창 파츠 등 그 밖의 특성은 장착 무기의 해당 값을 직접 편집할 수 있습니다. 파츠 자체의 무게는 휴대 무게에 한 번만 합산합니다. 장비 형태·호환 규격·보정 수치는 장비 편집에서 고칠 수 있습니다.

## 거리·엄폐·진행

전투의 위치는 `(x, y)` 미터 좌표이며 두 인물 사이 실제 거리를 계산합니다. 사거리, 거리별 명중 불이익, 5m 미만의 긴 무기 불이익이 각각 적용됩니다. 이동 거리는 기본 m/s, 이동에 쓰는 논리 초, 짐 무게, 다리 부상에 영향을 받습니다.

직사각형 장애물의 사선을 판정합니다. 기본 엄폐 1은 명중 −15, 엄폐 2는 −30, 엄폐 3은 직접 사격을 차단합니다. 통과 불가 지형은 이동 경로도 막습니다. 이는 첫 버전의 2차원 규칙이며 높이·관통 가능한 벽·탄도 낙차·정교한 우회 경로 탐색은 구현 범위가 아닙니다.

행동 게이지는 다음 준비 시각과 소수점을 저장합니다. 일반 행동의 논리 시간이 흐를 때 대기자의 준비도 함께 진행됩니다. 화면 새로 고침과 API 대기 시간에는 전투 시간이 흐르지 않습니다. 턴테이블은 d100 선공과 작은 민첩·무게 보정으로 순서를 정합니다. 자유 진행은 다음 행동자의 선택을 강제하지 않습니다.

일반 호출은 선언한 행동과 주변 NPC 행동을 처리한 뒤 다음 사용자 행동을 고르게 합니다. 위임된 다음 행동은 같은 AI 답변에서 새로 호출할 수 있습니다. **전투가 길어**는 위임된 사용자 판단 최대 6회, 전체 행동 최대 60회를 묶어 처리합니다. 선택 대기·전투 종료·실행할 수 없는 행동은 우선합니다. 승리를 보장하거나 서술 분량을 제한하지 않습니다. HP가 없는 룰북이므로 적 HP 절반·치료소 자동 부활 같은 HP용 옵션은 사용하지 않습니다.

## 부상·숙련·정신

- HP와 부위 HP를 사용하지 않습니다. 머리·몸통·좌우 팔·다리·손에 부상 1~4단계와 출혈·안정화·치료 완료·영구 손실을 저장합니다.
- 위력·관통·방호·치명타·같은 부위의 산탄 집중을 함께 계산합니다. 관통한 머리 명중은 치명적일 수 있습니다. 기본 조준 불이익은 몸통 0, 팔·다리 15, 머리 30, 손 40입니다.
- 심한 팔·손 부상은 사용 가능한 손을 줄이고, 다리 부상은 이동을 늦춥니다. 영구 손실은 일반 치료로 복구되지 않습니다.
- 의료 물품은 지혈·안정화·재활로 구분합니다. 치료하려면 실제 물품과 가까운 대상이 필요하고 재활은 전투 밖에서 합니다. 치료되지 않은 출혈은 기록된 경과 시간에 따라 의식 상실·사망으로 이어질 수 있습니다.
- 샷건의 산탄과 연사 명중은 한 공격 호출 안에서 계산합니다. 산탄 한 알마다 숙련 경험치를 지급하지 않습니다. 무기 계열 숙련과 개별 무기 친숙도는 별도입니다.
- 스트레스·정신 체크·패닉·NPC 항복을 사용합니다. 패닉 중에는 방어·이동·대기·항복을 선택하며 지휘·격려는 동요를 줄일 수 있습니다.
- 기본 스탯은 STR·DEX·CON·INT·WIS·CHA입니다. 명중 보정은 작게 제한하고 휴대 부담·이동·정신·지휘에 연결합니다.

시간·수치·확률은 첫 게임 밸런스 값입니다. 부상·장비·능력치·숙련·카르마·관계·지역을 직접 편집할 수 있습니다. 범위를 벗어나는 입력과 끊어진 소유·파츠·지도 연결은 오류로 표시합니다.

## 카르마와 분대

구조·보호·자비·도움은 카르마를 올리고, 항복자 살해·고문·학대는 낮춥니다. 실제 사건 ID와 근거를 기록하며 같은 사건을 다시 지급하지 않습니다. 호출한 공격으로 항복자가 죽으면 해당 윤리 사건을 함께 기록합니다.

사건을 목격하거나 전달받았다고 지정한 인물만 반응합니다. 성향 차이와 신뢰·충성도에 따라 불만, 명령 거부, 파티 이탈, 적대가 달라집니다. 카르마 수치 하나가 바뀌었다는 이유로 모르는 NPC까지 일괄 적대시키지 않습니다.

## 편집·뉴뉴·저장

구축 초안과 현재 게임 편집을 분리했습니다. 편집기에서 부상, 탄창, 장전 단계, 무기 수치, 호환 파츠, 숙련, 기술, 정신, 크레딧, 카르마·관계, 전장, 지역·출구를 다룹니다. 동적 항목과 전체 구조는 펼친 JSON 편집에서도 수정할 수 있습니다. 저장 중 다른 행동으로 관련 값이 바뀌면 덮어쓰지 않고 다시 열도록 안내합니다.

뉴뉴에게 같은 항목의 생성·수정 제안을 요청할 수 있습니다. 제안만 받았을 때는 저장되지 않으며 편집창에서 확인해 저장합니다. 구축 초안을 보면서 뉴뉴에게 물은 내용은 초안에 적용합니다. 놓치지마 검사는 택티컬 도구 형식으로 누락을 보완하고 기존 감소 확인·미해결 보관·중복 실행 방지 흐름을 유지합니다.

MCP 이름, IPC 연결, 채팅 전원, 기존 데이터 식별자와 카드 배치 경로는 유지합니다. 새 룰북은 전용 전투·저장 검증·편집 계산을 선택합니다. 택티컬의 미터 거리와 부상 규칙은 기존 룰북의 네 거리 구간·HP 계산에 적용하지 않습니다.

기술은 공격·방어·이동·조준·치료·지휘의 저장 보정과 비용·시간·선행 기술을 지원합니다. 공용 룰북의 모든 마법 효과·소환·비전 콤보를 자동으로 변환하는 기능은 포함하지 않습니다. 원문에 실행할 수 없는 능력이 있으면 설명으로 남기고 실제 효과가 적용된 것처럼 보고하지 않도록 지침을 넣었습니다.

실사용에서는 초기 구축부터 교전, 빈 탄창과 대구경 준비, 방패·파츠, 부상 치료, 동료 반응, 편집 후 재개·백업 복구까지 차례로 확인할 필요가 있습니다. 이 목록은 앞으로 확인할 범위이며 테스트 완료 기록이 아닙니다.
