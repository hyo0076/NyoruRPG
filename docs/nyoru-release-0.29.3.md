# NyoruRPG 0.29.3 · 카툰과 밤빛 마도서

**플러그인만 업데이트. 모듈 v1은 그대로**

- **기본 · 카툰**: 큰 기울임 숫자와 결과, 각진 도형으로 원래 카툰의 인상을 되살렸습니다.
- **판타지 · 밤빛 마도서**: 남색 표지, 금속 모서리, 룬 마법진과 보석 잠금장식을 적용했습니다.
- **판정별 장식**: 성공은 청록빛, 실패는 흐려진 자줏빛 룬, 대성공은 금빛 별과 빛나는 보석, 대실패는 붉은 균열입니다.
- **로맨스·사이버와 전투 카드**: 승인한 디자인과 간결형 게이지·턴테이블을 유지하며 판타지 전투 카드도 남색으로 표시합니다.

기존에 고른 카드 테마로 바로 적용됩니다. 다른 테마는 **시스템 구축 → 이 채팅의 카드 테마**에서 선택합니다. 카드 호환 표시도 같은 색상을 사용하며 환경에 따라 장식이 단순해질 수 있습니다.
