# NyoruRPG 0.22.5 · 채팅별 저장소 정리

**저장·복구 → 저장소 관리 → 채팅별 저장 내용 보기**에서 사용합니다. 여러 채팅에서 쌓인 NyoruRPG 저장을 봇·채팅 이름으로 찾고, 하나씩 또는 여러 개를 골라 정리합니다. 저장 버전 수·초안 수·최근 저장 시각·룰북을 함께 표시합니다.

## 버튼별 범위

| 버튼 | 삭제하거나 저장하는 내용 |
| --- | --- |
| 게임 백업 | 선택한 채팅의 게임 버전·거래·카드 연결을 기존 백업 형식으로 내려받습니다. |
| 초안 삭제 | 완료·실패·중단된 시스템 구축 초안과 초안에 보관된 자료를 삭제합니다. 적용된 게임·기술·장비·진행 기록은 유지합니다. |
| 채팅 데이터 삭제 | 해당 채팅의 게임 상태·이전 버전·플레이 편집·임시 저장·구축 초안·준비 캐시·카드 기록·테마·저장 자료와 연결된 진단을 삭제합니다. |
| 진단 기록 전체 삭제 | 누적된 호스트 호출 진단만 정리합니다. 게임·카드 기록을 지우지 않으며 이후 진단은 새로 기록됩니다. |

삭제 전에 대상 채팅과 범위를 보여주고 **삭제하기 / 취소**를 선택합니다. 자동 삭제나 휴지통 보관은 없습니다. 채팅의 RPG 데이터를 삭제하면 과거 결과 카드도 표시할 수 없고 다시 플레이할 때 시스템 구축이 필요합니다. 내려받아 둔 백업 파일은 유지합니다.

## 함께 지워지지 않는 것

Risu의 채팅 원문·캐릭터·모듈, API 설정·인증 키·Vertex JSON, 공용 효과 세팅·규칙 라이브러리·모듈 전환 원본은 삭제하지 않습니다. 다른 채팅의 게임이나 관계없는 플러그인 저장에도 접근해 삭제하지 않습니다.

Risu에서 없어진 채팅의 플러그인 저장도 목록에 표시합니다. 이미 이름 정보까지 사라진 과거 저장은 남은 게임 인물명·채팅 ID로 표시할 수 있습니다. 플러그인 화면에서 읽은 게임/초안의 봇·채팅 이름은 이후 구분을 위해 저장합니다. 전체 저장 목록은 사용자가 관리 목록을 열 때만 읽습니다.

## 저장 중 삭제

시스템 구축·뉴뉴 답변 중에는 정리를 기다리도록 안내합니다. 같은 채팅의 RPG 답변이 아직 임시 저장 중이면 먼저 완료하거나 기존 저장·복구 화면에서 폐기해야 합니다. 확인 화면을 연 뒤 저장 내용이 바뀌면 다시 선택하도록 안내합니다. 저장소 I/O 오류로 일부만 삭제된 경우 완료로 표시하지 않습니다.

진단은 디스크에 해당하는 저장 페이지뿐 아니라 메모리에 남은 페이지도 정리하므로 다음 진단 저장에서 예전 기록이 다시 들어가지 않습니다. 특정 채팅과 연결되지 않은 전역 진단은 채팅별 삭제 대신 진단 기록 전체 삭제에서 지웁니다.

## 설치와 작업 범위

연결 모듈 v1 사용자는 **NyoruRPG.js만 업데이트**하세요. 게임 재구축은 필요 없습니다. 이번 작업에서는 삭제 기능의 소스 수정과 배포 파일 생성만 진행했고 실제 사용자 저장을 삭제하지 않았습니다. 별도 최종 검사·브라우저·모의 호스트·실제 RisuAI·유료 API 검사는 실행하지 않았습니다.
