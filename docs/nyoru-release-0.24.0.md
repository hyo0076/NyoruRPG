# NyoruRPG 0.24.0

채팅별 전원과 처음 시작하는 안내를 추가합니다. 연결 모듈 v1과 기존 세이브를 그대로 사용하며 플러그인만 업데이트합니다.

## 전원

- 새 채팅은 OFF입니다. 모듈이 연결된 새 채팅을 열면 “안녕하세냥! 뇨루 RPG를 가동하시겠냥?” 안내를 표시합니다. 닫은 안내는 채팅 메뉴의 NyoruRPG에서 다시 열 수 있습니다.
- OFF와 준비 중에는 NyoruRPG MCP 목록을 비우고, 이 플러그인의 진행 지침·상태 문맥을 요청에서 제외합니다. 놓치지마 검사, 자동 판정과 답변에 따른 게임 저장도 실행하지 않습니다. 호스트가 보관한 도구를 호출하더라도 실행 경로에서 전원을 확인합니다.
- 기존 게임이 저장된 채팅은 ON으로 이어받습니다. 전체 창 위쪽 전원 버튼으로 끄고 다시 켤 수 있습니다. 세이브·편집 내용·룰북·작성 중 초안을 삭제하지 않습니다.
- 전원은 게임 버전과 별도로 저장하므로 롤백이나 백업을 가져왔다고 저절로 켜지지 않습니다. 꺼 둔 동안의 서술을 다시 켠 직후 놓치지마 검사로 소급 반영하지 않습니다.
- 이미 저장된 과거 결과 카드는 계속 볼 수 있습니다. OFF로 전환하기 전에 메인 AI로 이미 전송된 요청 자체를 되돌리는 기능은 아닙니다.

## 처음 시작하기

1. **네**를 누릅니다. 아직 게임 도구는 활성화되지 않습니다.
2. **백업이 있느냥?**에서 게임 백업 JSON을 첨부하거나 새로 시작을 선택합니다. 백업은 요약을 확인하고 가동할 수 있습니다.
3. 새 게임은 공통 d100·헌터·로맨스 판타지·미연시·에렌샤·무림 중 룰북을 선택합니다.
4. **추가하고 싶은 내용이 있냥?**에서 해석 요청을 적습니다. 에렌샤는 게임 닉네임을 별도로 입력합니다. 카드 테마와 예시도 이 단계에서 고릅니다.
5. 구축에 사용할 로어북 자료를 선택합니다. 헌터·에렌샤는 사용자 페르소나, 다른 봇은 페르소나와 능력치·세계관 자료를 함께 선택합니다. 봇의 실제 로어북 활성 설정을 변경하는 버튼은 아닙니다.
6. 시작 인물의 ID와 이름을 입력합니다. 기본은 사용자 한 명이며, 필요하면 여러 명을 추가할 수 있습니다.
7. **구축 시작**을 누르면 기존 구축용 API로 준비합니다. API가 설정되지 않았다면 **구축용 API 설정**에서 연결을 저장하고 돌아옵니다.
8. 생성한 초안을 보고 기술·효과를 편집하거나 말로 수정 요청합니다. **확인, 이대로 가동**을 눌러야 게임을 적용하고 전원을 켭니다.

준비 단계를 이동하거나 창을 닫으면 선택과 입력을 보관합니다. 구축 중 전원을 끄면 진행 중인 준비를 중단하며, 초안은 다시 이어볼 수 있습니다. 이미 서버에 전송된 API 요청의 과금 취소를 보장하지는 않습니다.

## 다른 채팅의 백업

새 채팅의 시작 안내에서 가져온 백업은 그 채팅에 새 저장으로 적용합니다. 원래 채팅의 상태는 바꾸지 않습니다. 인물·수치·기술·물품·진행 기록을 보존하지만 원래 채팅의 메시지나 과거 답변 카드 연결을 새 채팅에 복제하지 않습니다. 일반 저장·복구 화면의 같은 채팅 복원 절차는 유지합니다.

## 구현과 확인 범위

전원 확인을 MCP 목록·실행 전후·요청 지침·검사·출력 저장에 연결하고, 기존 구축·편집·백업 경로를 시작 안내에서 재사용했습니다. 도구 이름·MCP 연결 ID·기존 게임 식별자·판정 규칙·ON 상태의 카드 배치와 완료 절차는 바꾸지 않습니다.

소스 수정과 배포 파일 생성만 수행했습니다. 별도 최종 검사, 브라우저·모의 호스트·가상 전투, 실제 RisuAI·모바일·유료 API 호출은 하지 않았습니다. 설치한 호스트에서 첫 안내가 열리는 시점, 전원 변경 후 호스트의 MCP 목록 갱신, 실제 구축·백업 가동까지의 사용 흐름은 아직 확인하지 않았습니다.
