# NyoruRPG 0.30.9 · 스킬 편성과 몬스터 드랍

**플러그인만 업데이트. 모듈 v1은 그대로**

## 스킬 제한

초기 구축 또는 **플레이 설정 → 스킬 제한**에서 켭니다. 기본 OFF이며, ON이면 플레이어와 동료에게 기본 4칸을 적용합니다. 적과 소환수는 대상에서 제외합니다. 전투 기술을 사용하지 않는 로맨스 판타지·미연시에는 표시하지 않습니다.

각 룰북의 **능력·기술 / 숙련도·기술**에 스킬 편성이 나타납니다. 사용할 기술을 체크하고 **편성 저장**을 누르세요. 기본 공격·방어·회피도 각각 한 칸이며 패시브는 별도로 적용합니다. 기본 공격을 빼고 다른 기술을 넣을 수도 있습니다. 이동·대기·아이템과 일반 생활 행동은 슬롯을 쓰지 않습니다.

켜는 순간 기본 공격과 보유 방어·회피를 우선해 최대 4개를 편성합니다. 이후 새로운 기술을 배워도 현재 편성이 자동으로 바뀌지 않습니다. 새 기술의 자료가 준비되어도 편성하지 않았다면 보유 기술로 저장하고 사용 편성이 필요하다고 안내합니다. 기존 기술을 삭제하거나 자원·쿨다운을 초기화하지 않습니다.

**슬롯 수·성장 조건**에서 기본 칸 수와 증가 규칙을 바꿉니다. 그 인물에게 존재하는 레벨·경지·능력치·숙련도를 기준으로 선택합니다. 예를 들어 기본 4칸, 레벨 시작 기준 1, 증가 간격 10, 추가 1칸이면 Lv.11에 5칸, Lv.21에 6칸입니다. 여러 조건은 합산합니다. 레벨이 없는 룰북에 새 레벨을 만들지 않습니다.

성장으로 칸이 늘면 사용할 기술을 직접 선택합니다. 역량 감소로 칸이 줄면 저장한 편성의 앞쪽부터 사용하고 나머지 선택은 보관합니다. 편성·성장 조건 변경은 전투가 끝난 뒤 가능합니다. 토글 OFF는 보유 기술과 편성을 지우지 않습니다.

메인 AI의 행동 목록과 자동 전투·방어·회피에도 편성을 적용합니다. 사용 가능한 공격이 없으면 제외한 기본 공격을 몰래 사용하지 않습니다. 뉴뉴에게도 `스킬 편성`의 기본 칸·성장 조건·선택 기술 편집을 요청할 수 있습니다.

## 몬스터 물품·화폐 드랍

에렌샤는 기존 처치 경로에서 경험치만 지급하고 일반 몬스터의 드랍표를 보관하지 않았습니다. D100·얼터네이티브 헌터는 별도 전리품 회수 호출에 의존하던 부분을 연결했습니다. 이제 D100·얼헌·무림·에렌샤에서 저장된 몬스터 드랍표가 있으면 처치 시 확률·수량을 계산해 실제 소지품과 지갑에 지급합니다. 택티컬·지르코트의 기존 시체·소지품 회수 방식은 유지합니다.

- 물품마다 드랍 확률, 최소·최대 수량, 물품 자료를 보관합니다. 재료·소모품·장비 등을 지원합니다.
- 골드 등 화폐마다 드랍 확률과 최소·최대 지급액을 따로 설정합니다. 물품 판매 가격은 현금 지급액이 아닙니다.
- 같은 종류의 새 개체는 저장한 원형의 드랍표를 재사용하며, 각 개체의 당첨 여부는 별도로 계산합니다. 화염슬라임과 일반 슬라임은 구분합니다.
- 처치와 지급 기록은 같은 게임 상태에 저장합니다. 반복 조회·보완·전리품 회수로 같은 표를 다시 추첨하거나 지급하지 않습니다.
- 아무것도 나오지 않은 결과도 저장합니다. 모든 몬스터가 물품이나 골드를 반드시 주도록 강제하지 않습니다. 얼헌 리얼리티 모드의 추가 드랍 제한도 적용합니다.

예를 들어 슬라임의 표를 `점액 40% · 1~2개`, `골드 60% · 5~12 G`로 저장하면 두 항목을 독립적으로 추첨합니다. 이 수치는 설명용 예시이며 모든 슬라임에 일괄 적용하는 기본값이 아닙니다. 골드 지급을 원하지 않는 세계관에서는 화폐 목록을 비우면 됩니다.

**등록 인물 → 적·몬스터 기록 → 드랍 · 물품과 화폐 → 드랍 편집** 또는 현재 적의 상세 정보에서 편집합니다. 뉴뉴도 몬스터를 대상으로 드랍을 수정할 수 있습니다. 원형에 연결된 몬스터의 드랍 편집은 이후 새 개체의 표에도 반영하며, 다른 기존 개체의 보상 기록을 다시 처리하지 않습니다.

에렌샤의 구형 살아 있는 몬스터에 표가 없다면 처음 필요한 시점에 드랍 자료만 보완하고 이후 같은 종류에 재사용합니다. 새 인물을 준비할 때도 드랍을 함께 요청합니다. 명시적으로 비워 둔 표는 그대로 존중합니다. 과거에 이미 죽거나 정산한 몬스터의 보상을 일괄 소급 지급하지 않습니다.

처치 경험치와 경험치 공유는 기존 계산을 유지합니다. 드랍은 처치한 인물, 소환수라면 소환자에게 지급하며 경험치 공유 토글로 돈을 복제하거나 나누지 않습니다. 퀘스트·상자 보상과 적이 실제 들고 있던 소지품은 별도 지급원입니다. 처치 영수증에 나온 드랍은 이미 지급되었으므로 다시 획득 호출을 할 필요가 없습니다.

소스 수정과 로컬 배포 생성 범위입니다. 별도 최종 검사·실제 RisuAI·유료 API 실행은 하지 않았으며 GitHub 게시 보류를 유지합니다.
