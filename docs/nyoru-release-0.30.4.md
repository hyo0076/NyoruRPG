# NyoruRPG 0.30.4 · 되돌리기 복구 · 소환수 플레이

**플러그인만 업데이트. 모듈 v1은 그대로**

## 반복 리롤 뒤 되돌리기

선택한 사용자 입력과 그 이전 내용은 같지만 이후 답변을 리롤한 경우, 예전 화면이 보관하던 전체 채팅과 현재 채팅이 달라 `HISTORY_CHANGED`로 멈추던 조건을 수정했습니다. 되돌릴 사용자 입력과 그 입력까지의 문맥을 기준으로 복원합니다.

**저장·복구 → 답변 리롤·되돌리기**에서 사용자 입력과 답변 원문을 확인하고 **선택한 답변 이전으로 되돌리기**를 누르세요. 복원이 끝나면 몇 번째 메시지에 답하기 전 상태인지 표시됩니다. 이어서 Risu에서 해당 답변을 다시 생성하면 주사위와 게임 결과를 새로 계산합니다.

화면 재진입·새로 고침에서 원문을 갱신하고 선택한 메시지가 남아 있으면 선택을 유지합니다. 선택한 입력 자체나 이전 문맥을 편집했다면 최신 내용을 보고 다시 선택해야 합니다. 메시지가 삭제됐을 때 다른 시점을 임의로 고르지 않습니다. 되돌리기 중에는 버튼의 중복 실행을 막습니다.

게임 상태를 되돌리는 동작은 채팅 원문을 삭제하지 않습니다. **되돌리기 취소 · 현재 대화 상태로**를 누르면 현재 채팅에 대응하는 게임 저장을 다시 선택합니다. 출력 중이거나 복원 준비 도중 채팅이 바뀌는 경우에는 적용을 중지합니다. 저장된 이전 버전과 직접 편집의 보존 규칙은 유지합니다.

## 함께 배포하는 기능

- **소환수 플레이**: 인물 자료를 미리 등록하고 소환·해제할 때 재사용합니다. 유지 기준, 독립 성장, 경험치 공유 참여와 소환자 능력 보정을 설정합니다. [자세한 사용법](nyoru-release-0.30.3.md).
- **에렌샤 숙련도**: 목록을 한 줄로 표시하고 실제 탐험·이동·회피·방어 등의 행동과 성장할 숙련도를 연결합니다.
- **기술 대상**: 새 기술의 기본 허용 대상에 아군·적·자신·중립·소환수·물체를 포함합니다. 기존에 명시한 특수 제한은 유지합니다.
- **무림 구축**: 커스텀·로어북 경지 우선, 인물 경지 누락 보완과 경지표 편집 오류를 수정했습니다.

인물 간 자원 공유·성좌·스트리밍·GM·전략 룰북은 아직 설계 범위입니다.

## 확인 범위

소스 수정과 배포 파일 생성을 진행했습니다. 실제 RisuAI에서 반복 리롤을 실행하는 실사용 검증과 별도 최종 검사는 수행하지 않았습니다.
