# 룰북 이미지 배너

권장 크기: **1200 × 300px / 4:1**. 룰북 8개를 모두 같은 크기로 만듭니다.

- PNG·JPG·WebP 사용 가능. 현재 파일명은 PNG이지만 새 이미지 주소의 확장자는 달라도 됩니다.
- 데스크톱 본문에서 약 770 × 193px, 모바일에서 약 320 × 80px로 표시됩니다.
- 제목을 그림에 넣는다면 원본 기준 72px 이상을 권장합니다. 작은 설명문은 이미지 바깥의 본문을 사용하세요.
- 주요 글자·얼굴은 가장자리에서 60px 이상 떨어뜨립니다.
- 이미지 전체를 비율대로 축소합니다. 가운데만 잘라 표시하지 않습니다.
- 펼치기/접기와 룰북 이름은 HTML에도 표시되므로 그림에 버튼을 그릴 필요는 없습니다.

## 게시글에 적용

1. `NyoruRPG-소개글-HTML붙여넣기.txt`를 게시글의 HTML 편집 모드에 붙여 넣습니다.
2. 게시판에 새 배너 이미지를 업로드하고 해당 이미지 주소를 복사합니다.
3. HTML에서 `<!-- 룰북 배너 01 ... -->` 등 주석을 찾습니다.
4. 바로 아래 `img`의 `src` 주소만 새 이미지 주소로 바꿉니다. `width`, `height`, `style`, 접기 구조는 유지합니다.
5. 게시판이 자체 접기 기능만 허용하면, 룰북마다 접기 상자를 만들고 제목 영역에 배너를 넣은 뒤 해당 설명 본문을 붙여 넣습니다.

현재 붙여넣기 본문은 GitHub의 임시 배너 주소를 사용합니다. 로컬 HTML은 옆의 `배너/` 폴더를 사용합니다. 일부 게시판은 외부 이미지 주소나 HTML 태그를 제한하므로 게시판의 첨부 주소로 바꾸어 사용하세요. 실제 게시판 게시·렌더링 검수는 수행하지 않았습니다.

HTML의 `details`와 `summary`를 사용하므로 자바스크립트 없이 클릭·키보드로 열고 닫습니다. 효과 편집의 긴 설명도 항목별로 접었습니다.

소개글 원문은 `본문.md`, 룰북 내용은 `룰북.md`, 상세 효과 설명은 `효과-편집-상세.md`입니다. 수정 후 `build-post.cjs`로 HTML·붙여넣기 본문·Markdown 안내를 함께 생성합니다.
