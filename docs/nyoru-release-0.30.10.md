# NyoruRPG 0.30.10

**플러그인만 업데이트. 모듈 v1은 그대로**

## 인물 등록

무림 인물 준비의 `plan.identity.monsterType`과 공통 인물 준비의 같은 선택값에서, 입력하지 않은 값을 저장하려다 실패하던 경로를 수정했습니다. 놓치지마 검사와 등록 인물 화면의 수동 등록에 함께 적용합니다. 아군·NPC는 몬스터 종류를 입력할 필요가 없습니다.

뉴뉴에게 “팽 장주를 아군으로 등록해 줘. 취월객잔의 장주이며 과거 풍운도로 알려진 노고수야.”처럼 요청할 수 있습니다. **등록 제안**을 열어 이름·분류·설명을 확인한 뒤 **인물 등록**을 누르세요. 관련 로어북을 검색해 룰북의 능력치·기술·경지 등 필요한 자료를 준비하고 실제 저장합니다. 기존 인물과 일치하면 재사용합니다. 제안이 나온 것만으로 등록이 끝난 것은 아닙니다.

## 처치 누락 보완과 저장

`meta.monsterLoot`와 `meta.skillLoadouts`를 공통 저장 스키마에 연결했습니다. 이 필드가 있다는 이유로 `INVALID_SCHEMA`가 나던 처리를 수정했습니다.

놓치지마의 실패한 **처치 보완** 항목은 기존 적 ID와 처치 원문을 확인하고 해당 항목만 다시 적용하세요. 뉴뉴에서도 `scene_resolution` 제안으로 이미 끝난 처치, 전투 종료, 해당 구역 해결과 저장된 보상을 반영할 수 있습니다. 아직 끝나지 않은 장치까지 임의 해결하지 않습니다.

저장된 드랍표가 없다면 이미 저장된 시체 소지품·화폐는 회수하고, 미정인 추가 드랍은 따로 알립니다. 표에 없는 보상을 추측해 주지 않습니다. 이미 지급한 경험치·드랍·구역 보상은 같은 적·장면의 기록을 확인해 재지급하지 않습니다.

## 신규 채팅과 플레이 설정

미구축 채팅에서 아직 없는 게임의 `actors`를 읽던 공통 인물 선택 코드를 수정했습니다. 공통 메뉴 연결 순서를 앞당기고 플레이 설정은 현재 적용한 룰북으로 표시합니다. 미적용 룰북 선택이나 열어둔 기술 생성 화면 때문에 설정 화면이 가려지지 않도록 했습니다.

## 에렌샤 방어

방어 기술의 `power`는 이제 **고정 방어량**입니다. 기존에 저장한 기술 위력 값은 유지합니다. 예를 들어 위력 50은 이제 50%가 아니라 기본 방어량 50이며, 숙련도와 효과로 보정합니다.

- 들어오는 피해 10, 최종 방어량 10 → 10을 막고 피해 0.
- 들어오는 피해 30, 최종 방어량 10 → 10을 막고 피해 20.
- 들어오는 피해 10, 최종 방어량 50 → 실제로 막은 양은 10. 회복은 발생하지 않음.

치명타·공격 배율을 먼저 계산한 뒤 장비·기술 방어와 관통을 반영합니다. 기존 90% 상한은 제거했습니다. 준비한 방어의 유지 시간, 기술 비용·재사용 시간·숙련 성장, 회피 규칙은 유지합니다. **능력·기술 → 방어 기술 편집 → 방어량**에서 값을 바꿀 수 있습니다.

## 파괴 복구와 완전 수리

내구도 0인 장비의 **파괴 복구**는 기존 규칙대로 **0→1**만 회복합니다. 이제 도구 결과와 카드에 **파괴 복구 · 수리 필요**, 현재/최대 내구도와 남은 수리량을 표시합니다. 부분 수리와 완전 수리도 구분합니다.

“이 장비를 완전히 수리해 줘”라고 요청한 경우, 복구 후 같은 장비의 일반 수리를 이어 호출하도록 안내합니다. 예를 들어 0/100 장비는 복구로 1/100, 이후 일반 수리로 100/100이 됩니다. 기존 복구 비용·재료와 남은 수리 비용은 각각 적용됩니다. 복구만 요청했을 때는 추가 수리를 자동 결제하지 않습니다. 이미 저장된 내구도를 임의로 최대치로 바꾸지 않습니다.

## 이번 작업 범위

소스 수정과 로컬 배포 생성 범위입니다. 사용자 지시에 따라 별도 최종 검사, 브라우저·모의 호스트·실제 Risu 실행, 유료 API 호출은 수행하지 않았습니다. Android web 실사용은 미확인입니다. 앞서 요청한 GitHub 게시 보류를 유지합니다.
