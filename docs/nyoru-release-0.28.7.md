# 0.28.7 · 무림 로어북 경지 자동 구축

플러그인만 업데이트. 모듈 v1은 그대로

초기 구축에서 커스텀을 누르면 손편집 창이 먼저 열리던 흐름을 정리했습니다. **커스텀 · 로어북 자동 구축**을 누르면 자동 생성이 바로 선택됩니다.

새로 만드는 경지표의 외공·내공 문턱은 소수점 없는 정수로 반올림합니다. 49.34 → 49, 145.447 → 145입니다. 반올림으로 같은 문턱이 겹치면 다음 경지가 더 높도록 보완합니다. 성장 배율과 기존 저장값은 유지합니다. 이 변경도 0.28.7에 포함합니다.

1. 무림 선택 → 추가 요청 단계에서 **커스텀 · 로어북 자동 구축**을 누릅니다.
2. 자료 선택에서 경지 이름·순서가 담긴 로어북을 함께 고릅니다.
3. 구축을 시작하면 선택 자료와 추가 요청을 읽어 경지표를 만듭니다. 수치가 없으면 단계에 맞춰 높아지는 문턱을 보완합니다.
4. 구축 결과에서 경지 개수·이름·문턱을 확인하고 적용합니다. 필요하면 이때 수정할 수 있습니다.

**룰북 기본**은 범인~우화등선 23경지를 사용합니다. **커스텀**은 이 봇에 맞춘 경지표입니다. 직접 작성은 커스텀 아래 별도 선택이며, 이전에 작성한 표가 있으면 그 상태를 유지합니다. 자동 생성으로 바꾸려면 **로어북 자동 구축으로 전환**을 누르세요.

진행 중인 게임을 재구축할 때는 현재 경지표를 이어받습니다. 업데이트만으로 이미 저장된 경지를 다시 생성하거나 덮어쓰지 않습니다.
