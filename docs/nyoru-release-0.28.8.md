# 0.28.8 · 전투 상태 저장과 생성 효과 오류 수정

플러그인만 업데이트. 모듈 v1은 그대로

- D100·얼터네이티브 헌터·무림 전투의 `rangeRepositioned` 값을 저장 검사에서 거부하던 문제를 수정했습니다. 같은 전투 경로의 거리 좌표, 방어 준비, 시전 대기, 자동 전술 기록도 저장 정의에 연결했습니다.
- 보조 AI가 `type:status`로 작성했더라도 기절·출혈 등 알려진 상태 이름이 있으면 기존 효과 프리셋으로 연결합니다. 지속시간·확률·대상·적용 조건을 이어받습니다.
- 상태 이름이 없거나 서로 다른 효과를 지정한 자료는 임의로 적용하지 않고, 오류에 해당 효과 위치·원본 행·입력 예시를 포함합니다. 생성 지침에도 정확한 프리셋 작성 방법을 추가했습니다.
- 저장 형식 오류와 효과 자료 오류에는 해당 원인을 고쳐야 한다는 안내를 반환합니다. 오류 해결용 장면 초기화나 수정하지 않은 자료의 반복 호출을 해결책으로 안내하지 않습니다.

기존 세이브는 새 필드가 없어도 읽습니다. 저장된 경지·능력치·기술·소지품과 이전 판정은 유지하며, 과거 실패 행동이나 장면 초기화를 소급 취소하지 않습니다. 이번 수정 때문에 시스템을 새로 구축할 필요는 없습니다.
