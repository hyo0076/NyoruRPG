# NyoruRPG 0.30.6 · 성좌와 스트리밍

**플러그인만 업데이트. 모듈 v1은 그대로**

## 켜는 곳

모든 룰북의 **플레이 설정 → 성좌·스트리밍**에서 각각 켜고 설정을 저장합니다. 초기 구축의 **성좌·스트리밍 선택**에서도 고를 수 있습니다. 기본값은 OFF이며, 켠 메뉴만 등록 인물 위에 나타납니다. 기능을 꺼도 기존 신앙과 후원 장부는 남습니다.

## 성좌에게 도움받기

**성좌** 메뉴에서 인물과 성좌를 선택합니다. 성좌마다 접견 대사, 관심, 금기와 다섯 가지 도움이 있습니다.

| 기본 성좌 | 취향 | 도움의 방향 | 다섯 번째 도움 |
| --- | --- | --- | --- |
| 마지막 등불 | 구조와 보호 | 회복·정화·수호 | 함께 있는 생존 아군의 체력 회복과 수호 |
| 운명의 직조자 | 기지와 뜻밖의 해법 | 판정 보조·회피 | 아군 전체 명중·방어 가호 |
| 무너진 왕좌 | 파괴·정복·낮은 카르마 | 강력한 공격 | 한 번의 공격 피해 ×3와 명중 +30 |
| 웃는 가면 | 기만·재치·혼돈 | 회피·판정 보조 | 아군 전체에 오래 유지되는 명중·방어 가호 |

성좌의 부탁·퀘스트·명령을 등록하고 수락한 뒤, 실제로 완료하면 해당 성좌의 **신앙**을 얻습니다. 신앙은 인물·성좌별로 0~100입니다. 기본 도움 비용은 **10 / 20 / 35 / 60 / 100**이며, **도움 부탁** 버튼에서 실제 회복이나 가호를 적용하고 비용을 차감합니다. 완료 결과는 메인 AI의 다음 요청에 전달됩니다.

기본 신앙 보상은 부탁 하나에 최대 20, 성좌별 이야기 24시간에 최대 40입니다. 수락할 때 보상을 예약합니다. 신앙이 가득 찼다면 도움을 사용한 뒤 완료 보상을 받을 수 있습니다. 같은 부탁을 다시 완료해 신앙을 반복 지급하지 않습니다.

**이 성좌·다섯 도움 편집**에서 이름·대사·취향·테마와 각 도움의 효과·비용·행동 횟수·시간 제한·재사용 대기를 변경합니다. **+ 성좌**로 새 성좌도 만들 수 있습니다. 도움은 정확히 다섯 개를 유지합니다. 악성 취향도 자유롭게 설정합니다.

가호는 주사위 눈을 바꾸지 않고 실제 명중·피해·방어 계산에 반영됩니다. 같은 도움의 중복 사용은 지속 가호를 갱신하며, 가호를 합친 명중·방어는 각각 +50, 공격 피해 배율은 ×5까지입니다. 지속 보정은 받는 인물의 **완료 행동 횟수 또는 이야기 시간 제한 중 먼저 도달한 쪽**으로 종료됩니다. 조회·API 대기는 시간이 아닙니다.

택티컬은 HP를 새로 만들지 않고 부상 안정·출혈·의식·공격 위력으로 적용합니다. 지르코트에서는 기존 부위 HP도 사용합니다. 기적도 이미 사망한 인물이나 영구 상실을 되돌리지 않습니다. 사회 룰북은 공격 피해 대신 판정 가호를 사용하고, 능력 비교에는 표시 보정의 1/10을 적용합니다. 미연시에서 원래 성립 불가능한 제안은 가호로 뒤집지 않습니다. 능력치 훈련의 원본 수치는 가호로 올리지 않습니다.

## 방송과 시청자

**스트리밍**에서 방송 ON/OFF, 시청자 수, 충성심, 최대 단일 후원, 후원 랭킹, 시청자 취향을 확인합니다. “방송을 켜자/끄자”라는 채팅 입력도 메인 AI가 도구로 처리할 수 있습니다.

**방송·예산·도움 편집**에서 방송 콘셉트, 어떤 시청자인지, 채팅 분위기, 선호 플레이를 정합니다. 반응과 채팅의 실제 문장은 메인 AI가 씁니다. 별도의 반응 생성 API는 추가하지 않습니다.

실제로 시청자의 호응을 얻은 사건에서 **충성심**을 기록합니다. 충성심은 0~100이며, 도움을 부탁하면 정해진 양을 소비합니다. 기본 도움은 다음 판정 응원, 위험 경고, 원정 자금 지원입니다. 같은 화면에서 지원 효과와 비용을 편집할 수 있습니다.

후원은 실제 장면에서 발생한 사건을 기록합니다. 시청자 수가 많다는 이유만으로 자동으로 돈을 만들지 않습니다. 목표도 등록·수락·완료할 수 있으며, 완료 보상은 후원 잔액에 적립됩니다.

## 후원금 출금과 한도

후원금은 **미출금 후원금**에 쌓입니다. **전액 출금 · 세금 20%**를 누르면 그때 세금을 공제해 설정한 게임 지갑에 넣습니다. 예를 들어 100을 출금하면 80을 받습니다. 나눠 출금할 때 정수 단위 미만 세금은 다음 출금으로 이월해 세금 누락을 방지합니다. 서술 AI가 출금을 자동 실행하지 않습니다.

시작값은 인물별 **이야기 24시간에 총지원 예산 200, 사건당 최대 50, 충성심 회복 한도 20**입니다. 단위는 선택한 지갑 통화입니다. 원화와 골드 등의 규모가 다르므로 게임에 맞춰 직접 편집하거나 뉴뉴에게 요청하세요. 충성심은 한 사건에서 최대 +10까지만 회복합니다.

- 일반 후원은 남은 예산과 사건 한도 안의 실제 적립액을 반환합니다.
- 수락한 시청자 목표의 보상은 미리 예약합니다. 포기하면 예약을 풀고, 완료하면 한 번만 적립합니다.
- 물품 지원도 저장된 가격·강화 가치만큼 같은 예산을 씁니다. 가격이 없는 물품은 먼저 가격을 설정합니다.
- 무기에 붙은 파츠·장전탄을 보급으로 복제하지 않습니다. 빈 장비나 일반 물품을 원형으로 사용합니다. 지르코트에서는 배낭 수납 여유도 필요합니다.
- 방송을 다시 켜거나 후원자를 새로 등록해도 인물의 예산은 초기화되지 않습니다.

## 뉴뉴와 저장

**뉴뉴에게 설정 요청**을 눌러 성좌의 콘셉트·다섯 효과·방송 설정을 수정할 수 있습니다. 예: “무너진 왕좌를 검의 성좌로 바꾸고 마지막 도움은 강력한 일격으로 구성해 줘.” 제안을 열어 편집한 뒤 **변경 저장**으로 적용합니다.

신앙·충성심을 직접 보정하는 화면도 제공합니다. 실제 후원 정산·잔액·사건 장부는 임의 편집 항목에서 제외합니다. 신앙·충성심·효과·후원·예약·출금 기록은 같은 게임 상태에 저장되며 백업과 되돌리기에 함께 포함됩니다. 같은 룰북으로 구축을 보완할 때도 장부를 보존합니다.

도구에는 기존 `rpg_play`의 `observer`와 읽기 전용 `rpg_state`의 `observers`를 추가했습니다. 새 도구를 별도로 등록할 필요는 없습니다. 반복 호출에는 동일 사건 ID를 재사용하며, 이미 처리한 비용·후원·부탁 완료를 다시 실행하지 않습니다.

이번 버전은 로컬 배포입니다. GitHub에는 게시하지 않습니다. 별도 최종 검사와 실제 RisuAI 실행은 하지 않았습니다.
