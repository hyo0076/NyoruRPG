NyoruRPG 소개글 · 스크린샷 첨부 목록

01. 이야기 사이의 결과 카드
행동 문장과 주사위·피해·자원 변화가 함께 보이는 장면.

02. 채팅 전원과 시작 안내
새 채팅의 시작 버튼, 백업 가져오기와 새로 시작하기 선택.

03. 자료 선택과 추가 요청
페르소나·로어북 선택, 추가 요청, 닉네임과 시작 인물 입력.

04. 구축 초안과 테마
카드 테마 선택과 실제 구축 결과의 인물·기술·장비 편집 화면.

05. 전체 화면과 미니 상태창
공통 메뉴 순서, 인물 선택, 적의 기술·효과를 펼친 화면.

06. 전투 설정과 행동 게이지
세 전투 방식, 행동/지휘관 모드, 전투가 길어·적 체력 감소와 게이지 카드.

07. 기술 효과와 거리 편집
효과 추가, 조건·배율·자동 발동, 기술 사거리와 장비의 소지/착용 효과.

08. 탐험 지도와 남은 자원
현재 노드·갈 수 있는 길·방문 기록·남은 채집 또는 수색 자원.

09. 놓치지마 검사와 도움 알림
반영 결과, 미해결 목록, 입력 수정, 채팅 화면의 도움 버튼.

10. 뉴뉴의 질문과 편집 제안
자연어 요청, 제안 카드, 실제 편집창을 차례로 보여 주세요.

11. API 역할과 Vertex 설정
주소·키·JSON의 비밀 내용은 가리고, 용도별 선택과 기본 API 공유가 보이게 첨부.

12. 백업·되돌리기·저장소 관리
백업 버튼, 되돌릴 답변 선택, 삭제할 채팅과 자료 범위 확인.

13. 자매품 뇨루메모리
기억 목록과 인물 관계가 보이는 화면. 선택 첨부.
