# NyoruRPG 0.40.3

2026년 10월 13일. 이동력 버프만 붙고 실제로는 제자리에 남던 이동 공격을 별도 설정으로 연결했습니다.

**플러그인만 업데이트. 모듈 v1은 그대로**

## 백스텝 사격을 실제로 움직이게

이전의 `movement` 효과는 이동 가능한 거리를 늘릴 뿐, 기술 사용자의 위치를 바꾸지 않았습니다. 이제 기술에 **공격 전·후 이동 연계**를 저장합니다. 기존 공격 판정과 함께 한 행동으로 실행합니다.

| 원하는 기술 | 저장할 이동 | 판정 위치 |
|---|---|---|
| 백스텝 사격 | 공격 전 후퇴 | 실제 후퇴한 자리에서 사격 |
| 돌진 베기 | 공격 전 접근 | 접근한 자리에서 공격 |
| 치고 빠지기 | 공격 후 후퇴 | 공격을 판정한 뒤 후퇴 |
| 뛰어들어 베고 빠지기 | 공격 전 접근 + 공격 후 후퇴 | 접근한 자리에서 공격한 뒤 후퇴 |

뉴뉴에게 “백스텝 사격을 **공격 전에 실제로 1칸 후퇴한 뒤 사격**하도록 바꿔 줘. 기존 위력과 비용은 유지해 줘”라고 요청하고 제안에서 이동 연계를 확인해 저장할 수 있습니다. 미터 모드라면 칸 대신 m를 지정하세요. 직접 편집은 기술의 효과 화면 **이동 연계**에서 하며, 택티컬·지르코트는 기술 편집에 같은 항목이 있습니다. 이동 거리를 0으로 두면 해당 단계는 사용하지 않습니다.

기존 저장의 이동력 버프를 기술 이름만 보고 실제 이동으로 바꾸지는 않습니다. 예전에 만든 백스텝 사격도 **제안을 다시 받거나 직접 이동 연계를 저장해야** 적용됩니다. 더 이상 원하지 않는 이동력·회피 버프가 기존 기술에 들어 있다면 해당 효과도 명시적으로 삭제할 수 있습니다. 플러그인 업데이트만으로 기존 피해량·비용·효과를 임의 변경하지 않습니다.

## 실행 기준

- D100·얼터네이티브 헌터·무림·에렌샤·택티컬·지르코트의 전투에 연결했습니다. 각 룰북의 명중·피해·자원 규칙을 계속 사용합니다.
- 전후 이동 합계는 현재 한 행동의 이동력 이내입니다. 칸과 m를 섞지 않습니다. 이동을 붙였다는 이유로 추가 행동을 소비하지 않으며 연타마다 이동을 반복하지 않습니다. 택티컬 계열은 이동에 필요한 시간도 행동 시간에 반영합니다.
- 공격할 위치의 사거리와 이동 경로를 먼저 확인합니다. 비용 없는 미실행과, 이동을 시작한 뒤 함정 등으로 중단된 결과를 구분합니다. 후자의 실제 이동·소비 기록은 남습니다.
- 빗나가도 설정된 공격 후 이동은 실행합니다. 명중했을 때만 이동하는 조건이나 경로 중간에서 여러 번 사격하는 연속 이동은 이번 범위에 포함하지 않습니다.
- 시전 대기 중에는 움직이지 않고 실제 발동 때 이동합니다. 2D 지도 전투는 같은 저장 좌표가 바뀌며 별도의 지도 조작 버튼을 추가하지 않습니다.

뉴뉴의 이동 설정만 담은 부분 수정 제안이 기존 효과와 사거리를 지우는 경로도 고쳤습니다. 생성 지침은 이동력·회피·추가 행동 버프로 실제 후퇴를 대신하지 않도록 안내합니다. 실제 모델이 매번 올바른 제안을 만든다고 보장하는 변경은 아닙니다.

## 확인 범위

Code Review Graph의 설치된 CLI로 연결 범위를 확인하고, 저장·제안·편집·실행 경계의 자동 테스트에서 오류를 재현한 뒤 수정했습니다. 해당 테스트 15개가 통과했습니다. 여섯 전투 룰북의 이동, 연타, 자원·탄약, 사거리 거부, 시전, 2D 좌표·벽·함정, 제안의 기존 효과 보존, 편집 화면을 포함합니다.

실제 설치된 Risu, 휴대폰, 유료 AI 호출은 실행하지 않았습니다. 전체 플러그인의 모든 동작을 다시 검사했다는 의미는 아닙니다.
