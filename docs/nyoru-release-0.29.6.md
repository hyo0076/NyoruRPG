# NyoruRPG 0.29.6 · 무림·택티컬 카드 테마

**플러그인만 업데이트. 모듈 v1은 그대로**

**시스템 구축 → 이 채팅의 카드 테마 → 디자인**에서 무림 또는 택티컬을 선택하세요. 선택한 디자인은 해당 채팅에 저장됩니다. 기존 채팅은 현재 테마를 유지하며 새로 구축할 필요가 없습니다. 룰북과 카드 디자인은 별도로 선택합니다.

- **무림 · 먹빛 서첩**: 종이 질감, 먹 번짐과 마른 붓 자국, 겹친 산수와 낙관. 성공·실패·대성공·대실패의 색과 표식이 달라집니다.
- **택티컬 · 야전 단말기**: 사용감 있는 금속 모서리, 조준경 눈금과 정렬·빗나감·이중 링·경고 띠. 좁은 여백과 선명한 숫자를 사용합니다.

판정, 행동 게이지, 턴테이블과 획득·회복·거래·성장·퀘스트·탐험·효과·강화 결과에도 같은 테마가 적용됩니다. 택티컬의 획득은 보급 라벨, 회복은 의료 포장, 강화는 정비 기록 형태입니다. 실제 저장된 결과와 상세 내역을 표시합니다.

카드가 글자만 보이면 같은 화면의 **카드 호환 표시**를 사용할 수 있습니다. 스타일 처리 기능이 제한된 환경에서는 장식이 단순해질 수 있습니다.
