# NyoruRPG 0.40.6 · 전통 D&D · 부위 체력과 탄약

- 전통 D&D 룰북을 추가했습니다. 2024 개정 규칙과 SRD 5.2.1을 기준으로 플레이합니다.
- D&D의 주문 슬롯·직업별 사용 횟수·휴식·성장을 적용하며, 기존 플레이 토글은 사용하지 않습니다.

- 부위 체력을 켜면 상태 화면에 각 부위의 체력을 표시합니다. 채팅 상태창의 HP는 부위 체력의 합계입니다.
- 부위 체력은 독립적으로 설정하며, 최대 HP가 성장하면 각 부위의 최대 체력도 함께 증가합니다.
- 탄약은 무기에 종류를 연결하지 않고 소지품에서 골라 사용합니다. 이름으로 지정하지 않으면 위력이 가장 높은 탄약을 선택합니다.
- 장비의 발사 수·재장전 간격과 장비·탄약의 HP·MP·SP 소모를 편집할 수 있습니다.
- 지르코트는 기존 실물 탄창을 사용합니다.
- 뉴뉴의 편집 제안 표시와 퀘스트 등록 오류를 수정했습니다.
- 대화 연결 오류가 나도 저장을 확인하고 복구할 수 있도록 개선했습니다.

장비·탄약을 편집할 때 **착용·사용**에서 설정하세요.

**이런 식으로 사용할 수 있어요.**

- 훈련용 화살 30개를 준비하고, 활에 1회 사용 탄약 수를 1로 설정합니다. 재장전 간격은 0이면 됩니다.
- 여섯 발마다 재장전하는 총은 재장전 간격을 6으로 설정합니다.
- 마력을 담는 탄환에는 1발당 MP 소모를 붙일 수 있습니다. 탄약 없이 쏘는 마도 총이라면 장비의 탄약 수는 0으로 두고 MP 소모를 설정하세요.
- “이번에는 냉기 화살로 쏴 줘.”처럼 원하는 탄약을 채팅에서 지정할 수 있습니다. 자동 선택은 특수효과를 제외한 위력만 비교합니다.
