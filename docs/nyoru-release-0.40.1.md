# NyoruRPG 0.40.1

2026년 10월 13일. 답변 완료 뒤 직접 편집이 생성 중 오류로 막히는 경로를 수정했습니다.

**플러그인만 업데이트. 모듈 v1은 그대로**

## 수정 내용

완료 알림 시점에 호스트가 아직 출력 중이거나 답변 원문을 저장하기 전이면 이전 버전은 확정을 건너뛰었습니다. 이후 같은 사용자 입력의 임시 저장을 그대로 유지하고, 완료 알림 기능이 등록된 환경에서는 대체 확인도 생략하여 편집이 계속 막힐 수 있었습니다. 제보된 오류는 0.30.12의 `GENERATION_ACTIVE`이며 당시 호스트의 전체 이벤트 순서는 확보하지 못했습니다.

- 완료 알림에 연결된 생성·사용자 입력·답변 ID와 원문 해시를 보관합니다. 채팅 원문을 추가 복제하지 않습니다.
- 알림 직후 저장할 수 없으면 제한된 횟수로 같은 답변의 완료를 다시 확인합니다. 그 뒤에는 화면 열기·새로 고침·직접 편집 때 재확인합니다.
- 구버전의 열린 임시 저장도 호스트가 출력 종료를 명시하고 저장 원문이 두 번의 조회에서 일치하면 화면·편집 경로에서 확정할 수 있습니다. 출력 중 상태가 없다는 이유만으로 종료로 간주하지 않습니다.
- 완료 알림 등록 여부와 관계없이 다음 사용자 입력 앞에 저장된 이전 답변을 확인합니다.
- 장비 편집, 인물 등록과 규칙 편집에 같은 재확인 흐름을 연결했습니다. 강화 버튼의 오래된 임시 저장 여부 선차단도 제거하고 공통 편집 경로에서 확인합니다.

확정은 이미 계산된 도구 결과를 저장하는 작업입니다. 거래·아이템·돈·보상이나 판정을 다시 실행하지 않습니다. 원문 불일치·다른 생성·리롤·진행 중 출력은 계속 차단하며 `afterRequest`만으로 완료를 확정하지 않습니다.

## 적용

플러그인을 0.40.1로 업데이트하고 Risu를 새로 고침한 뒤 해당 채팅의 RPG 창을 다시 여세요. 기존 시스템 재구축이나 게임 저장 삭제는 필요하지 않습니다. 실제로 출력 중이면 끝난 뒤 편집하세요.

## 확인 범위

소스 수정과 배포 파일 생성을 진행했습니다. 사용자의 지시에 따라 추가 자동 테스트·브라우저·모의 호스트·실제 Risu 실행·유료 API 호출은 하지 않았습니다. 사용자 환경의 오류가 재현·해결되었다고 확정하는 기록은 아닙니다.
