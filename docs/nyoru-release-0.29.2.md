# NyoruRPG 0.29.2 · 간결형 전투 카드

**플러그인만 업데이트. 모듈 v1은 그대로**

## 전투 카드

- 승인한 간결형의 높이와 여백을 적용합니다. 행동 게이지와 턴테이블의 큰 제목, 현재 차례/행동 중이라는 반복 문구, 전투 카드의 아군·적 표시는 없앱니다. 현재 행동할 인물은 행 전체의 색과 접근성 속성으로 표시합니다.
- 이름 오른쪽에는 거리를 배치합니다. 게이지는 수치와 얇은 막대, 속도·남은 대기만 표시하며 전투 시간은 오른쪽 아래에 둡니다. 막대는 각 행의 남은 너비를 모두 사용합니다. 준비 완료·행동 불가는 해당 상황에서 계속 구분합니다.
- 턴테이블은 작은 라운드 표시와 순서·이름·거리·선공 합계를 보여 줍니다. 저장된 선공 주사위가 있으면 **선공 판정 상세**에서 확인합니다. 새 참가자가 어느 라운드에 합류하는지에 대한 기존 안내는 유지합니다.
- 기본·로맨스·판타지·사이버 테마의 전투 카드를 함께 적용합니다. 택티컬·지르코트의 거리와 시간은 원래 미터·초 단위입니다. 저장되지 않은 충전 속도를 추정해 표시하지 않습니다.

## 일반 결과 카드

주사위와 결과 제목의 크기를 줄이고 긴 이름·큰 숫자가 넘치지 않도록 줄바꿈을 허용합니다. 판정 카드의 **상세**를 눌러 기존 계산 근거를 펼칩니다. 피해·회복·잔여 HP·보호막·비용을 보존하고, 효과·거래·성장 내역은 항목과 값을 구분한 행으로 표시합니다. 내용이 없는 빈 결과 상자는 만들지 않습니다. 성공·실패 판정이 없는 단순 기록에는 실패 색상을 붙이지 않습니다.

기본 테마의 네모 상자, 과도하게 큰 결과 글자와 장식의 강도를 조정합니다. 각 테마의 기존 색상·주사위와 대성공/대실패 구분은 유지합니다. 채팅별 **카드 호환 표시**도 새 카드 배치를 사용하며 사용자 CSS는 보관합니다.

## 적용 범위

게임 수치·판정 결과·차례 계산·비용·세이브·MCP/IPC 식별자·주변 서술·카드 마커 위치를 바꾸지 않습니다. 과거 거래나 공격을 다시 실행하지 않고 저장된 결과로 화면만 만듭니다. 일반 모드와 호환 모드의 장식·반응형 표시 차이는 기존과 같습니다.

필요한 소스 읽기·수정과 로컬 배포 생성 범위입니다. 별도 최종 검사, 브라우저·모의 전투·호스트·실제 RisuAI·모바일·유료 API 실행은 생략합니다. 실제 설치 환경에서의 화면은 아직 확인하지 않았습니다. GitHub에는 새로 게시하지 않습니다.
