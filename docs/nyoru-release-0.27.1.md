# NyoruRPG 0.27.1 · 플레이 중 새 인물 로어북 검색

새 인물을 처음 등록할 때 **초기 구축에서 선택하지 않은 NPC 로어북도 검색**하도록 연결했습니다. 연결 모듈 v1과 기존 세이브는 그대로 쓰고 `NyoruRPG.js`를 교체합니다. 새 검색 기능을 쓰기 위해 시스템을 다시 구축할 필요는 없습니다.

## 사용 방법

초기 구축에서는 사용자 페르소나와 세계관·규칙·시작 인물에 필요한 자료를 선택합니다. 앞으로 등장할 모든 NPC 항목을 미리 선택할 필요는 없습니다. 플레이 중 새로운 인물이 등장하여 등록 도구가 호출되면 관련 로어북을 찾아 기존 인물 생성 요청에 더합니다.

검색은 공통 D100·얼터네이티브 헌터·로맨스 판타지·미연시·에렌샤·무림·택티컬의 신규 등록에 연결했습니다. 이미 등록된 인물의 현재 상태와 사용자 편집을 자동으로 덮어쓰지 않습니다. 등록은 장면 표시·공격·보상과 별개입니다.

## 검색 범위와 방식

- 현재 봇의 로어북, 현재 채팅 로어북, 현재 페르소나의 로어북, 현재 연결된 모듈의 로어북을 대상으로 합니다.
- 꺼 둔 항목·폴더·연결되지 않은 모듈·다른 봇/채팅과 NyoruRPG 자체 모듈 지침은 자동 검색 대상에서 제외합니다.
- 요청한 이름·본명·닉네임·별칭을 제목·키워드·본문의 명시적 이름과 비교합니다. 설명의 소속·역할은 후보 순서에 참고합니다.
- 조건부 로어북도 켜진 항목이면 검색하지만, 리수의 키워드 발동·변수·매크로를 실행하지 않습니다. 로어북 원문을 참고 자료로 전달합니다.
- 구축 때 명시적으로 선택한 자료는 그대로 유지합니다. 따라서 과거에 모든 자료를 골랐다면 그 선택까지 자동으로 줄이지는 않습니다.
- 추가 검색 항목은 관련도 순으로 최대 8개·총 9만 자입니다. 큰 항목은 이름 주변과 도입부를 최대 1만 8천 자까지 발췌하며 발췌·제외 여부를 함께 전달합니다. 기존 선택 자료에는 이 추가 검색 제한을 적용하지 않습니다.

검색만을 위한 추가 AI 요청은 없습니다. 실제 인물 생성에는 기존 보조 AI가 사용되므로 생성 대기는 남습니다. 한 호출에서 여러 새 인물이 필요한 경우 접근 가능한 자료 목록을 공유하며, 준비를 이어갈 때에는 보관한 검색 자료와 생성 응답을 재사용합니다.

검색은 이름·별칭 중심입니다. 이름이 전혀 다른 음역이나 원문에 연결되지 않은 별칭까지 알아내는 의미 검색은 아닙니다. 찾지 못한 인물은 호출에 담긴 설명과 제공된 자료로 준비합니다. 누락된 고유 설정을 확인했다고 주장하지 않도록 지침을 넣었습니다. 중요한 원문이 검색되지 않으면 등록 설명에 원문 이름을 함께 전달하거나 해당 자료를 구축 자료로 선택할 수 있습니다.

동명이인이나 다른 버전이 여러 후보로 남을 때에는 생성 AI가 구분 근거를 확인하도록 했습니다. 구분할 수 없다고 반환하면 `ACTOR_LORE_AMBIGUOUS` 오류로 보관합니다. 그때 등록 입력의 `description`에 소속·직업·본명·등장 상황을 보완합니다. 이 지침의 실제 모델 준수는 아직 테스트하지 않았습니다.

## 얼헌·에렌샤의 기존 인물

- **얼터네이티브 헌터:** 수치화된 내장 인물을 구축 때 미리 등록하는 방식입니다. 시작 인물 외에는 비활성으로 두며 등장 시 저장된 인물을 사용합니다. 이 자료와 사용자가 편집한 현재값을 다시 생성하지 않습니다.
- **에렌샤:** 내장 인물 원문을 첫 등장 때 불러와 게임 자료를 만드는 방식입니다. 내장 인물 경로를 유지하고, 내장 자료에 없는 새 인물은 관련 로어북을 검색합니다.

## 확인 자료

호스트 진단의 `actorLoreSearch`에 요청 인물, 기존 선택 수, 검색한 자료 ID·제목, 자동 추가 수, 발췌·제외 정보를 기록합니다. 진단에는 검색 로어북 본문을 복사하지 않습니다. 원문 읽기 과정의 경고도 남깁니다.

이번 작업은 소스 수정과 로컬 배포 생성까지입니다. 사용자 지시에 따라 별도 최종 검사·가상 전투·브라우저·실제 RisuAI·유료 API를 실행하지 않았습니다. GitHub에 게시하지 않았습니다. 실제 봇의 로어북 형식·조건부 내용·동명이인 구분은 실사용 확인이 남아 있습니다.

택티컬 기능은 [택티컬 첫 구현 안내](nyoru-release-0.27.0.md)를 참고하세요.
