# NyoruRPG 0.28.0 · 지르코트 전용 룰북

사용자 첨부 `프로젝트지르코트_export.json`의 프로젝트:지르코트 1.8 설정을 바탕으로 여덟 번째 독립 룰북을 추가했습니다. 기존 택티컬의 전투를 재사용하면서 지르코트의 지역, 부위별 HP, 생존, 수색과 소지품을 따로 저장합니다.

**진행 방식은 봇과 메인 AI가 정합니다.** 이 룰북은 출격·귀환 순서, 목표, 탈출 시한, 보스 등장, 의무 전투, 답변 길이를 정하지 않습니다. 실제로 선언한 행동과 경과한 시간의 결과를 계산합니다.

0.28.1부터 허기·갈증·위생·피로는 별도의 생존 모드로 켜고 끌 수 있습니다. 새 게임은 기본 OFF이며, 이 버전의 기존 저장은 이전 ON 동작과 수치를 이어받습니다. [생존 모드 안내](nyoru-release-0.28.1.md).

## 시작하기

1. 플러그인을 동봉한 `NyoruRPG.js`로 교체합니다. 기존 연결 모듈 v1은 그대로 사용합니다.
2. 새 채팅의 시작 안내 또는 시스템 구축에서 **지르코트**를 선택합니다.
3. 원본의 21개 지역 중 시작 지역을 고릅니다. 해당 지역에 필요한 준비물과 기본 환경 수치를 보여줍니다.
4. 난이도, 지역 환경 영향, 시작 장비, 전투 방식 등 초기 옵션을 고릅니다. 자료·페르소나와 시작 인물을 선택하고 생성한 초안을 확인·편집한 뒤 적용합니다.

시작 장비는 선택한 자료 따르기 / 소총·배낭·응급물품 기본 무장 / 소지품·Zp 없음 중 선택합니다. 기본 무장은 6,500 Zp, 자동소총과 방호구, 수납 장비, 탄약·응급품·식수·식량을 가진 편집 가능한 출발점입니다. 자료 따르기는 원래 인물의 장비를 우선합니다.

같은 지르코트 세이브에 재구축할 때 기존 위치·HP·피폭·아이템·편집값을 새 시작값으로 초기화하지 않습니다. 기존 진행의 난이도·환경은 생존 계산 설정에서, 지역·시간은 시간·위치 편집에서 수정합니다. 기존 다른 룰북의 세이브를 자동으로 지르코트로 바꾸지 않습니다.

## 지역·준비물·이동

- 아트로크, 그라스다 등 원본 21개 지역의 설명·연결 경로·권장 준비물을 제공합니다.
- 육로·해로·항로·기송관을 구분합니다. 연결이 있다고 운항·이용 허가까지 생기는 것은 아닙니다. 고장 난 철도도 자동 복구하지 않습니다.
- 지역별 방사선·더위·추위, 경로별 소요 시간·가격·이용 조건을 편집할 수 있습니다. 원문에 확정되지 않은 시간·비용은 게임 기본값입니다.
- 지역 이동은 플레이어와 실제 동행자로 지정한 인물만 옮깁니다. 등록만 한 NPC가 자동으로 따라오지 않습니다.
- 실제 장소 탐험은 기존 탐험 토글을 따릅니다. 꺼도 지역·시간 기록, 전투·거래·시신 전리품 처리는 사용할 수 있습니다.

지역 선택 자체는 보스를 생성하거나 전투를 시작하지 않습니다. 센트라·아리아·로폰베리·엔타테브·트루브 사기타는 관련 원본 설명을 준비 자료로 제공하며, 실제 등장 때 만든 동일 인물의 상태를 이어 씁니다. 상세 설명의 거주지를 참고 자료로 사용하되 실제 등장 위치를 그곳으로 강제하지 않습니다. 원문 이동 목록의 자기 자신 연결은 제외했습니다.

## 부위 HP와 피폭

| 부위 | 기본 HP |
|---|---:|
| 머리 | 35 |
| 흉부 | 85 |
| 복부 | 70 |
| 왼팔·오른팔 | 각 60 |
| 왼다리·오른다리 | 각 65 |

머리·흉부 HP가 0이면 사망합니다. 사지·복부가 0이면 추가 피해를 다른 부위로 분산합니다. 관통·방호·출혈·골절과 부상에 따른 조작·이동 불이익을 함께 반영합니다. 신체 수치는 인물 편집으로 변경할 수 있습니다. 일반 택티컬은 계속 HP 없는 부상 규칙을 사용합니다.

방사선은 **피폭 지수, 표면 오염, 누적 피폭 기록**을 구분합니다. 실제 게임 시간이 흐를 때 현재 지역·지점의 방사선과 착용 장비 차폐를 계산합니다. API 응답 대기, 화면 열기, 상태 조회는 시간을 진행하지 않습니다.

- 차폐율 `0.25`는 25%입니다. 여러 장비는 남은 노출 비율에 곱해 적용하고, 내구도가 줄면 차폐 성능도 감소합니다.
- 지역을 벗어나거나 쉬어도 이미 쌓인 피폭은 자동 초기화하지 않습니다. 기본 자연 감소는 0입니다.
- 오염 제거와 누적된 피폭 완화는 별도 의료 효과입니다. 차폐된 은신처에서도 기존 표면 오염은 남습니다.
- 높은 피폭, 식수·식량 고갈, 극심한 피로는 부위 HP에 영향을 줍니다.
- 붕대, HP 치료, 골절 고정, 수술, 오염 제거, 피폭 완화 등을 구분합니다. 수술은 교전 밖에서 기능을 잃은 사지·복부를 최대 HP가 줄어든 상태로 복구합니다. 사망·영구 신체 손실을 일반 치료로 되돌리지는 않습니다.

모든 방사선·피해·치료 수치는 실제 선량·의학 계산이 아닌 **편집 가능한 게임 수치**입니다. 기본 식량 감소 3/시간, 수분 감소 5/시간, 피로 증가 2/시간, 휴식 시 피로 감소 12/시간을 사용합니다. 지역 환경과 차폐가 추가로 작용합니다.

## 탄창·수색·수납

- 분리된 탄창마다 실제 탄약 목록을 저장합니다. 같은 구경도 피해·관통·무게가 다를 수 있습니다.
- 발사하면 그 탄창의 실제 탄약을 소모합니다. 탄창 교환은 기존 탄창의 남은 탄약을 보존하며, 빈 탄창 채우기는 소유한 낱발 탄약을 사용합니다.
- 탄창 분리 버튼을 제공합니다. 무기 판매는 장착과 파츠·탄창을 분리한 뒤 처리합니다. 무기 양도·시신 회수는 연결된 파츠와 탄창을 함께 옮깁니다.
- 발사 중에는 약 5발 단위로 잔탄을 표시하고 실제 확인·재장전 뒤에는 정확한 수량을 보여줍니다. 상태 조회만으로 탄약 확인 행동을 대신하지 않습니다.
- 지역 지점의 수색은 한 번 굴린 결과와 남은 전리품을 저장합니다. 같은 지점을 다시 확인해도 재굴림·재생성하지 않습니다. 물품은 회수 행동 때 소지품으로 옮깁니다.
- 시신에서는 실제 사망한 인물이 갖고 있던 장비·탄약을 회수합니다. 별도의 복제 보상을 만들지 않습니다.
- 주머니·전술 조끼·배낭·착용·창고·바닥을 구분합니다. 수납 용량과 휴대 무게를 계산하며 창고 물품은 휴대 무게·사용 가능 물품에서 제외합니다.
- 창고는 은신처 안에서 접근하고, 바닥 물품은 내려놓은 지역·지점에서 회수합니다. 다른 지역 물품을 즉시 사용하는 방식은 지원하지 않습니다.

## 상인·세력·은신처

상인을 처음 만났을 때 저장한 유한 재고, 취급 품목, 보유 Zp, 구매·판매 계수, 지역 수요, 신뢰·세력 평판으로 거래합니다. 새 상품이 무조건 재고에 생기지는 않습니다. 물물교환도 가능하며, 흥정은 요청한 경우만 판정합니다. 거래 후 실제 수량과 Zp를 함께 저장합니다.

은신처 입장·퇴장·이전·창고 확장을 지원합니다. 기본 창고는 200 L, 확장 비용은 현재 단계 × 5,000 Zp, 확장량은 100 L입니다. 은신처에 들어갔다고 자동 치료·귀환·물품 이동을 처리하지 않습니다.

실제 사건은 세력 평판과 기존 카르마·목격자 관계에 기록합니다. 이야기 전개와 등장 인물의 동기는 봇이 담당하고, 저장된 결과를 바탕으로 이어 갑니다.

## 편집·뉴뉴·검사·저장

전체 화면에 생존·지역·은신처·상인 항목을 추가했습니다. 부위 HP, 생존·피폭, 환경·경로, 수납·탄창·탄약, 상인·재고·평판을 직접 편집하거나 뉴뉴에게 제안받을 수 있습니다. 신규 상인·세력도 편집 화면에서 추가합니다. 구축 초안과 실제 게임 편집을 구분합니다.

미니보드·결과 카드·상태 조회는 같은 저장 상태를 읽습니다. 놓치지마 검사에는 지르코트의 부위 HP·피폭·유한 전리품 규칙을 전달하고, 이미 계산한 시간·탄약·판정을 다시 처리하지 않도록 연결했습니다. 감소 확인은 기존 보완 후보 저장 절차를 사용합니다. 백업은 별도 지르코트 데이터를 포함하며 저장 식별자와 MCP·IPC 연결 이름은 그대로입니다.

## 구현 범위와 아직 확인하지 않은 부분

- 이번 작업은 소스 수정과 로컬 배포 생성입니다. 빌드에 포함된 구문·모듈 포장 절차만 수행하며 별도 테스트, 가상 전투, 브라우저·모의 호스트·실제 RisuAI·유료 API 실행은 하지 않았습니다.
- GitHub에는 게시하지 않습니다. 설치 후 실제 모델의 선택·호출과 장시간 플레이는 아직 확인하지 않았습니다.
- 무기별 장전·파츠·엄폐·게이지는 택티컬 공통 계산을 사용합니다. 원본 봇의 Lua, 이미지, HTML 화면, 진행 스크립트를 실행하거나 통째로 복제하지 않습니다.
- 보스 고유 능력은 현재 지원되는 기술·장비 필드로 표현합니다. 탄환 튕기기·특수 사이버웨어 등 원본의 모든 고유 기믹에 별도 실행기를 구현한 것은 아닙니다.
- 난이도 0~4는 첫 구현에서 수색 난이도와 적대 교전의 명중 보정에 적용합니다. 평화로움은 무적·사망 방지나 이야기상 적 등장 차단이 아닙니다. 난이도만으로 실제 등장 인물이나 진행 순서를 생성하지 않습니다.
- 이동 시간·환경 수치·치료량·상점 계수는 게임 기본값입니다. 수송 수단 확보, 상인의 특수 재고, 보스의 실제 등장 같은 이야기 사실은 메인 AI의 명시적 도구 요청과 자료에 의존합니다.

원본: 에벨레 제작 `프로젝트:지르코트` 1.8, 사용자가 제공한 내보내기 파일. 자료와 구현의 출처는 `THIRD_PARTY.md`에 기록했습니다.
