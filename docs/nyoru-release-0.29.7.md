# NyoruRPG 0.29.7 · 로어북 참조와 선택 기능 편집

**플러그인만 업데이트. 모듈 v1은 그대로**

초기 구축의 **선택 기능 세부값 · 적용 전 편집**에서 인물·장비·기술·관계·상인·정기 비용을 열어 수정합니다. **초안에 변경 저장**으로 보관하고, 구축 결과를 최종 적용하면 게임에 반영됩니다. 전원이 아직 꺼진 구축 단계에서도 편집창과 뉴뉴로 이동할 수 있게 수정했습니다.

**뉴뉴도 로어북을 읽습니다.** 예를 들어 “꺼진 사티 로어북을 읽고 현재 기술과 다른 부분을 수정 제안해 줘”처럼 요청하세요. 답변의 **참조한 로어북**을 펼치면 사용한 항목과 꺼짐·발췌 여부를 확인할 수 있습니다. 제안은 기존처럼 편집창을 열어 저장합니다.

- 현재 봇·채팅·페르소나·연결된 활성 모듈의 로어북은 초기 구축에서 선택하지 않은 항목과 꺼진 항목도 검색합니다. 로어북을 읽기 위해 활성화 상태를 바꾸지 않습니다.
- 이름·본명·닉네임·별칭을 먼저 검색합니다. 특정 인물을 찾지 못하면 기존 기본 API로 제목·키워드·원문 일부의 의미를 대조해 후보를 고르고, 선택된 항목의 실제 원문을 생성·답변에 전달합니다. 별도 임베딩 API는 사용하지 않습니다.
- 의미 검색은 필요한 경우 추가 API 요청 한 번을 사용합니다. 후보 목록은 최대 240개·40,000자, 자동 참조는 최대 8개·90,000자로 제한합니다. 긴 항목은 인물 관련 발췌이며 생략 여부를 표시합니다. 검색이 실패하거나 원문이 없으면 읽었다고 안내하지 않도록 했습니다.
- 에렌샤의 내장 인물도 현재 로어북을 먼저 찾습니다. 이미 저장한 인물과 사용자 편집을 자동 재구축하지는 않습니다.
- 초기 **봇 설정 해석·추가 요청**은 구축할 첫 인물의 요청으로 구분하고 새 NPC 생성에 전역 지침으로 넘기지 않습니다. 다른 인물에게 페르소나를 그대로 복사하지 않도록 자료와 지침을 분리했습니다.

**미터 거리·사거리**를 켠 경우 선택 기능의 장비·기술 **미터 사거리**와 인물 **행동당 이동(m)**을 사용합니다. 기본 네 거리값은 보관하며 미터 전투에 그대로 대입하지 않습니다. 도구 안내·조회·편집·오류·기술 표시를 이 단위에 맞췄습니다. 미터 사거리의 `ranges`를 기존 네 거리의 `accuracy` 배열처럼 표시해 발생하던 `skill().join` 오류도 수정했습니다.

같은 조우의 적은 판정 카드와 행동 게이지·턴테이블에서 동일한 번호로 구분합니다. 장면의 저장 개체 ID는 바뀌지 않으며, 조우 기록에는 쓰러진 적도 포함해 남은 적의 번호를 유지합니다.

**시스템 구축 → 이 채팅의 카드 테마 → 간결한 정보**를 켜면 주요 결과를 먼저 표시합니다. 거리 보정·내구도·숙련도는 판정 상세로, 게이지의 속도·대기는 별도 펼침으로 옮깁니다. 정보나 계산을 삭제하지 않습니다. 빗나감·회피·실제 피해와 미실행을 구분하고 전투 카드의 모서리를 각 테마에 맞췄습니다. 카드 간결/호환 설정도 백업·복구로 이어갑니다.

첨부된 에렌샤 백업·채팅·호스트 진단과 관련 소스를 읽고 수정한 로컬 배포입니다. 실제 설치된 RisuAI, 모바일 화면, 모델의 의미 검색 정확도와 수정 제안 성공률은 실행 확인하지 않았습니다. 별도 최종 검사·브라우저·모의 호스트·유료 API 호출과 GitHub 게시를 하지 않았습니다.
