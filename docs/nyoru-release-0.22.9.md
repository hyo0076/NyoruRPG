# NyoruRPG 0.22.9

기존 연결 모듈 v1은 그대로 사용하고 플러그인만 교체한 뒤 Risu를 새로 고침합니다. 저장 식별자와 기존 수치·편집·카드 위치는 유지하며 시스템을 재구축할 필요가 없습니다.

## 전투 진행

현재 상태(에렌샤는 아바타, 무림은 강호의 나)의 **전투 방식**에서 설정합니다. 기본은 모두 OFF입니다.

- **전투가 길어**: 기존 규칙으로 최대 6라운드 분량을 한 호출에 계산합니다. 실제 주사위·피해·비용·상태 만료·숙련 성장을 기록하고 짧게 묘사하도록 전달합니다. 자동 선택 반복은 120단계를 기준으로 제한하며(한 기술의 타격·연계는 끝까지 처리), 전투가 남으면 다음 호출로 이어갑니다. 2~3라운드 안의 승리를 보장하거나 수치를 강화하지 않습니다.
- **적 체력 감소**: 전투를 시작하거나 새 적이 합류할 때 적 편의 현재·최대 HP를 절반으로 적용합니다. 기본 HP는 보존하고 전투 종료 후 생명 비율에 맞춰 기본 최대치로 돌아갑니다. 반올림으로 HP가 1 미만이 되지는 않습니다.
- 지휘관 모드·행동 모드·위임하지 않은 사용자 행동·미결 반응이 우선입니다. 상위 RP에서 사용자 행동을 위임한 경우 메인 AI는 같은 답변 안에서 다음 act를 호출할 수 있습니다. 기술 조건이나 자원이 부족하면 사용 가능한 다른 공격을 선택하며, 새 기술을 임의로 만들지는 않습니다.

공통 d100·얼터네이티브 헌터·에렌샤·공통 전투를 쓰는 무림에 연결합니다. 로맨스 판타지와 미연시의 사회 규칙은 유지합니다.

## 인물과 화면

사용자 아바타의 ID를 따로 기억합니다. 온라인 게임 속 다른 이용자는 다른 아바타이며 채팅 사용자의 상태창 수치로 사용하지 않습니다. 기존 main 사용자가 명확한 에렌샤 저장에서는 잘못 player로 등록된 다른 이용자의 종류만 ally로 정리하며 레벨·HP·기술·장비는 보존합니다. main이 없고 여러 사용자가 설정된 저장은 첫 인물을 임의로 고르지 않습니다.

등록 자료와 현재 장면의 표시 명단은 별개입니다. 에렌샤의 **등록 인물**, 공통·헌터·무림의 현재 상태에서 표시 명단을 조절합니다. 사용자와 전투 참가자는 항상 표시되며 행동에 실제 참여한 인물은 표시 명단에 들어갑니다. 에렌샤 기존 저장의 등록 인물은 자동으로 전원 표시하지 않습니다.

전체 화면과 미니보드에서 현재 효과를 먼저 보여주고 적의 기술·효과를 펼쳐 볼 수 있습니다. 미니보드의 기술에는 남은 재사용 대기와 사용 횟수, 장비에는 효과·내구도, 소모품에는 회복 효과가 표시됩니다. 적용되지 않는 0 위력·0 방어는 생략합니다.

## 퀘스트와 놓치지마 검사

퀘스트 수락 시 보상 정보를 함께 저장합니다. 명시된 수치와 사용자 편집이 우선이며 수치가 전혀 없을 때만 보조 AI가 퀘스트에 맞춰 한 번 보완합니다. 보상 미기록은 0 보상과 구분하며 아직 진행 중인 퀘스트의 미기록 보상만 보충할 수 있습니다. 보상 물품도 효과를 준비해 저장하고 완료 시 한 번 지급합니다. 완료한 퀘스트는 현재 목록에서 빼고 완료 기록에 보관합니다. 수습·초보 직업도 숙련 조건을 충족하면 첫 전직 퀘스트를 준비할 수 있습니다.

검사 계획은 선행 작업 관계를 기록합니다. 전직 조건 미충족 때문에 별개의 인물 등록까지 중단하지 않습니다. 실패한 판정에 대한 성공 보상은 보류합니다. 보고서는 제안 문구와 실제 실행 결과를 구분하고, 실제 처리·기존 기록·미해결 건수를 보여줍니다. 서술이 주장한 레벨을 맞추려고 저장된 주사위·성장·사용자 편집을 덮어쓰지는 않습니다.

## 호출 지연과 확인 범위

일반 대화가 현재 저장본에 이어지는 경우 전체 과거 버전 목록을 읽지 않습니다. 검증된 불변 저장본은 메모리에서 재사용하며 다른 채팅·이전 분기·재생성 구분과 저장 확인은 유지합니다. 호스트 진단에 단계별 시간, 느린 저장소 읽기·쓰기, 도구 반환 전에 출력이 관측됐는지를 함께 남깁니다. 이는 모델의 실제 수신이나 특정 계층의 시간 제한을 확정하는 신호가 아닙니다.

첨부 파일과 실행 경로를 읽고 수정했으며 배포를 생성했습니다. 별도 최종 검사·가상 전투·모의 호스트·실제 RisuAI·모바일·유료 API는 실행하지 않았습니다. 외부 콜백 시간 초과가 모두 해결됐다고 확인한 상태는 아닙니다. 0.22.8의 과거 검사 결과는 이번 버전의 실행 검증이 아닙니다.
