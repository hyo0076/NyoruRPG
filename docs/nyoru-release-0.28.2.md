# NyoruRPG 0.28.2 · 공통 UI와 사용 흐름

로컬 테스트용 플러그인입니다. GitHub 게시와 실제 RisuAI·모바일·API 실행은 하지 않았습니다. 연결 모듈 v1은 그대로 사용합니다.

## 공통 위치

플레이 메뉴는 현재 상태 → 능력·기술 → 장비·소지품 → 탐험과 룰북 고유 기능 → 등록 인물 순서입니다. 로맨스 판타지·미연시는 지원하지 않는 탐험을 표시하지 않습니다. 등록 인물은 모든 룰북에서 플레이 그룹의 마지막에 있습니다.

준비 그룹의 플레이 설정에서 전투 방식, 지휘관·행동 모드, 전투가 길어, 적 체력 감소, 탐험과 룰북별 선택 옵션을 관리합니다. 각 룰북이 실제로 지원하는 항목만 표시합니다. 상태 화면에 흩어져 있던 설정을 옮겼으며 위쪽 버튼과 미니보드에서도 같은 설정 화면으로 갑니다. 로판·미연시는 기존 관계·판정 규칙 안내를 여기에 표시합니다.

등록 인물의 추가 방식은 이름·분류·설명 입력으로 통일합니다. 지원하는 룰북에서는 본명·닉네임·별칭·개체 ID를 추가로 입력합니다. 새 인물만 기존 로어 검색·준비 경로로 만들며 같은 인물은 저장값을 재사용합니다. 등록 후 현재 장면 표시는 기본 해제입니다. 현재 표시 목록과 등록 자료를 구분하며 사용자·전투 참가자는 숨기지 않습니다. 헌터의 미등장 내장 자료는 등록 자료 사용 버튼으로 불러올 수 있습니다. 편집에는 각 룰북의 기존 필드와 저장 검증을 사용합니다.

장비·소지품 안의 장비/소지품 탭으로 장비·파츠와 탄약·소모품·재료를 나눕니다. 지르코트의 배낭·조끼·차폐 장비는 장비에, 낱발 탄약과 탄창은 소지품에 들어갑니다. 로판·미연시는 장착 슬롯을 새로 만들지 않으며 소지품을 기본으로 표시합니다.

## 지르코트 정리

- 생존·피폭의 중복 메뉴를 없애고 현재 상태에서 확인합니다. 생존 모드와 계산 설정은 플레이 설정으로 옮깁니다.
- 지역 목록 메뉴를 없앴지만 지역·경로·환경 자료와 초기 구축의 시작 지역 선택은 보존합니다. 현재 장소라는 별도 이름은 탐험으로 통일합니다.
- 은신처 메뉴를 없앴습니다. 창고는 소지품 맨 아래에서 넣고 뺍니다. 별도의 은신처 생성·방문·확장 호출을 요구하지 않습니다. 장착·부착 중인 물품은 먼저 해제하고 교전 밖에서 이용합니다. 기존 수납·용량·아이템 연결은 유지합니다.
- 카르마와 상인·세력·재고 관리는 각각 켤 수 있습니다. 명시적인 선택값이 없는 기존 저장과 새 저장 모두 기본 OFF입니다. 꺼져 있는 동안 기존 수치와 기록을 지우거나 소급 처리하지 않습니다.
- 카르마 OFF는 사건 처리와 항복한 대상 사망 시 자동 감소·동료 관계 반응을 막습니다. ON이면 현재 상태에서 카르마를 확인·편집합니다. 윤리 사건 기록을 별도 일상 메뉴로 표시하지 않습니다.
- 상인·세력·재고 OFF는 상인 전체 재고 생성·세력 기록용 도구와 지침을 제외합니다. 일반 거래는 저장 가격과 실제 물품 수량으로 처리하며 처음 구매하는 물품 자체의 준비는 필요할 수 있습니다. ON이면 기존 상인 재고·가격·평판 기능과 해당 관리 화면이 나타납니다.

## 소스에서 확인하고 수정한 범위

| 룰북 | 설정 위치 | 등록 인물 | 장비·소지품 | 고유 화면 |
|---|---|---|---|---|
| D100 | 상태 하단 → 플레이 설정 | 공통 목록·추가·기존 인물 편집 | 장비/소지품 분리 | 탐험 유지 |
| 얼터네이티브 헌터 | 상태 하단 → 플레이 설정 | 내장 인물 보존, 공통 등록 화면 | 장비/소지품 분리 | 탐험 유지 |
| 로맨스 판타지 | 플레이 설정에 규칙 안내 | 공통 등록·기존 사회 인물 편집 | 소지품 기본, 장착 기능은 추가하지 않음 | 관계·설계 유지 |
| 미연시 | 상태의 규칙 안내 → 플레이 설정 | 공통 등록·기존 사회 인물 편집 | 소지품 기본 | 능력 화면 분리, 관계·데이트 유지 |
| 에렌샤 | 상태 상단 → 플레이 설정 | 공통 등록과 본명·닉네임 입력 | 장비/소지품 분리 | 퀘스트·탐험 유지 |
| 무림 | 상태 상단 → 플레이 설정 | 공통 등록과 기존 무림 편집 | 장비/소지품 분리 | 비전·가르침·탐험 유지 |
| 택티컬 | 상태의 별도 편집 → 플레이 설정 | 공통 등록과 기존 택티컬 편집 | 장비·파츠와 탄약·물품 분리 | 미터 전장·부상 규칙 유지 |
| 지르코트 | 분산 설정 → 플레이 설정 | 공통 등록과 기존 지르코트 편집 | 같은 분류, 소지품 아래 창고 | 중복 메뉴 정리, 선택 관리 기능 유지 |

인물 선택창·패널 제목·버튼과 목록 간격에도 공통 스타일을 연결했습니다. 기존 세이브 ID, 인물 ID, 사용자 편집값, MCP/IPC 연결, 주사위·카드 배치와 전투 계산을 UI 통일을 이유로 교체하지 않습니다.

이는 소스의 렌더·입력·저장 경로를 읽고 수정한 범위입니다. 설치된 RisuAI에서 버튼을 눌러 저장하고 다시 여는 동작, 모바일 실물 배치, 실제 모델의 선택 기능 준수와 호출 시간은 확인하지 않았습니다. 별도 최종 정적 검수·브라우저·가상 전투·모의 호스트·유료 API 실행을 추가하지 않았습니다.
