# NyoruRPG 0.29.1 · 카드 표시 호환

플러그인만 업데이트. 모듈 v1은 그대로

## 글자만 보일 때

1. 플러그인을 교체하고 Risu를 새로 고침합니다.
2. 해당 채팅의 NyoruRPG **시스템 구축 → 이 채팅의 카드 테마**에서 **카드 호환 표시 · 카드가 글자만 나올 때**를 켭니다. 시스템을 다시 구축할 필요는 없습니다.
3. 채팅을 다시 열거나 새로 고침합니다. 저장된 이전 판정 카드에도 같은 설정을 사용합니다.

호환 표시는 처음에는 꺼져 있습니다. 켜면 기본 제공 테마의 색상·글자·배치를 카드 요소에 직접 적용합니다. 일부 장식과 좁은 화면의 배치, 사용자 CSS의 우선순위는 일반 표시와 달라질 수 있습니다. 끄면 원래 스타일 방식으로 돌아갑니다. 봇의 전체 서술이나 선택창에는 이 처리를 적용하지 않습니다.

## 제보와 소스에서 확인한 범위

- 제보 환경은 로컬 Risu, NyoruRPG 0.28.11, 로맨스 카드 테마입니다. 정확한 Risu 빌드와 그 환경의 최종 표시 DOM은 확인하지 않았습니다.
- `[NyoruRPG:9]`가 실제 저장 판정 내용으로 바뀌고 접기·게이지 요소도 보입니다. 제보 화면은 결과 누락보다 카드 스타일이 적용되지 않은 양상입니다.
- 첨부된 봇 코드의 강한 초기화 규칙은 `#ott-select` 내부에 한정됩니다. NyoruRPG 선택자나 전역 초기화는 없었습니다. 이 코드만으로 봇을 원인으로 단정할 수 없으며 실제 카드가 그 선택창 안에 들어가는지, 별도 정규식이 있는지는 확인되지 않았습니다.
- 플러그인은 기본 배치와 테마의 컨테이너·SVG 장식을 한 스타일 블록으로 전달했습니다. [Risu의 표시 처리 소스](https://github.com/kwaroran/Risuai/blob/main/src/ts/parser/parser.svelte.ts)는 스타일을 별도로 해석하며 해석 실패 시 스타일 내용을 비울 수 있습니다. 이것은 제보 환경의 직접적인 실패 원인이 확정됐다는 뜻은 아닙니다.
- 수정본은 기본 배치·장식·반응형 규칙을 독립 스타일 블록으로 전달하되 순서를 유지합니다. 보존한 사용자 CSS는 뒤에 별도 블록으로 적용합니다. 행동 게이지 루트 선택자의 테마 범위도 수정했습니다.
- 호환 표시에서만 저장 결과 조각을 DOM으로 읽어 기본 제공 테마를 직접 적용합니다. 주변 서술 전체를 파싱하지 않고 원래 카드 참조·캐시·저장된 주사위·원문을 변경하지 않습니다. 호스트 화면 접근이나 추가 권한은 필요하지 않습니다.

## 배포와 실사용

이 파일은 로컬 배포 안내입니다. 0.29.0의 룰북별 선택 기능을 포함하며 모듈 v1과 기존 세이브·연결 식별자를 유지합니다. 필요한 소스 수정과 배포 생성을 수행합니다. 별도 최종 검사, 브라우저·모의 호스트·실제 Risu 실행, 유료 API는 사용자 지시에 따라 수행하지 않습니다. 제보 환경에서의 실제 표시 결과는 아직 확인되지 않았습니다. GitHub에는 새로 게시하지 않습니다.
