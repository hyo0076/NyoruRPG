# NyoruRPG 0.29.0 · 선택 기능 사용법

플러그인만 업데이트. 모듈 v1은 그대로

## 켜는 곳

- 새 게임: 초기 구축의 **선택 기능**에서 사용할 항목을 고릅니다.
- 진행 중인 게임: **플레이 설정 → 선택 기능**에서 변경합니다. 전투가 진행 중이면 전투를 끝낸 뒤 변경합니다.
- 처음 추가된 기능은 모두 OFF입니다. 켜지 않은 항목은 추가 계산·도구 안내를 사용하지 않습니다.
- 기능을 꺼도 입력한 수치·설정·진행 기록은 남습니다. 원래 룰북에 있던 내구도·수리·강화 등은 그대로 사용할 수 있습니다.

기능을 켜는 것과 장비별 수치를 설정하는 것은 별개입니다. 인물·장비·기술의 기본 자료를 만든 뒤 필요한 선택 기능 세부값을 확인하세요. 기존 장비 이름만 보고 무게·탄약·파츠를 전부 생성하지는 않습니다.

## 세부값을 편집하는 곳

| 설정 대상 | 위치 |
| --- | --- |
| 인물의 운반량·이동 거리·부위 체력·생활·관계·소환 정보 | 현재 상태 → 인물 선택 기능 편집 |
| 무기·탄약·파츠·소모품의 추가 수치 | 장비·소지품 → 해당 물품의 세부 설정 |
| 기술의 미터 사거리·연계·소환 대상 | 능력·기술 → 해당 기술의 사거리·연계 설정 |
| 비전·퀘스트·관계·상인·정기 비용·장소 | 해당 기능을 켜면 나타나는 카테고리 |
| 게임 적용 전 세부값 | 구축 결과 → 선택 기능 세부값 · 적용 전 편집 |

구축 결과의 **뉴뉴에게 선택 기능 설정 요청**은 초안의 인물·기술·소지품을 전달합니다. 제안 카드를 열어 값을 확인하고 저장하면 초안에 보관됩니다. 실제 게임 변경은 최종 적용 때 이루어집니다. 진행 중인 게임에서는 뉴뉴에게 현재 인물과 물품 이름, 원하는 값을 말해 같은 항목을 편집할 수 있습니다.

## 파츠와 장전 예시

파츠를 쓸 무기에 계열과 슬롯을 설정합니다. 예를 들어 무기 계열을 `rifle`, 슬롯을 `optic`, 허용 파츠 종류를 `scope`로 정합니다. 보유한 조준경에는 슬롯 `optic`, 종류 `scope`, 호환 계열 `rifle`과 명중 보정 등을 입력합니다. **파츠 부착**에서 실제 보유 물품을 골라 붙이고 분리합니다. 같은 슬롯의 중복 부착과 다른 장비에 이미 붙은 파츠의 이중 사용은 허용하지 않습니다.

장전 기능은 무기에 **탄종·장전 용량·현재 장전량·발사당 소모량·필요한 장전 행동 수**를 설정합니다. 탄약 물품은 탄약 분류로 등록하고 같은 탄종을 지정합니다.

- 30발 탄창을 쓰는 소총: 용량 30, 발사당 1, 장전 행동 1.
- 한 발 쏜 뒤 두 번의 장전 행동이 필요한 화기: 용량 1, 발사당 1, 장전 행동 2.
- 화살을 매번 꺼내 쏘는 활: 용량 0, 발사당 1. 호환 화살의 보유 수량에서 소비합니다.
- 매번 장전해야 하는 노포: 용량 1, 발사당 1, 원하는 장전 행동 수.

장전형 무기는 개별 물품으로 보관합니다. 이 확장은 무기별 장전량과 여분 탄약을 계산하는 방식입니다. 지르코트의 실물 탄창 물품·교환 규칙은 기존 지르코트 기능으로 유지합니다. 장전이 필요한 무기의 탄약을 새 선택 기능으로 계산할 때 기존 소모와 이중 차감하지 않도록 연결했습니다.

무게의 기본 물품 값은 0이므로 실제 사용할 물품 무게를 입력하세요. 인물의 운반 한도를 넘으면 이동과 행동 게이지 속도에 부담이 반영됩니다.

## 거리와 신체

미터 거리 기능을 켜면 장비·기술의 선택 기능 편집에서 **최대 미터 사거리·거리별 명중 보정·절대 거리값**을 정합니다. 인물에는 한 행동에 이동할 거리를 설정합니다. 기존 네 단계 거리 수치를 그대로 미터로 읽지 않으며, 선택 기능의 미터 자료를 따로 사용합니다.

최대 사거리는 무기와 사용 기술 중 높은 쪽입니다. 절대 거리값이 켜져 있으면 해당 값을 사용하고, 양쪽 모두 켜졌다면 기술이 우선합니다. 파츠의 사거리 증감은 절대 거리값을 바꾸지 않습니다. 처음 제공되는 미터 기본값은 세계관에 맞게 편집하세요.

신체 기능은 머리·몸통·복부·양팔·양다리의 체력, 부위 조준 보정, 피해 배율, 출혈과 상실 여부를 기록합니다. 기존 전체 HP도 함께 사용합니다. 머리·몸통이 고갈되면 치명상으로 처리하며 실제 HP 판정에 연결됩니다. 팔·다리 부상은 명중과 이동에도 영향을 줍니다.

치료 물품에는 치료량과 지혈 여부를 설정하고 대상·부위를 골라 사용합니다. 일반 치료로 상실한 부위를 복원하지 않습니다. 출혈 수치는 전투 중에는 자기 차례가 끝날 때, 교전 밖에서는 경과 시간당 피해로 사용합니다. 실제 대기시간과 API 지연 때문에 출혈이 진행되지는 않습니다.

## 생활·수련·비전·소환

허기·갈증·피로는 높을수록 소모된 상태, 위생은 높을수록 깨끗한 상태입니다. 인물별 시간당 변화량과 음식·식수·위생용품·피로 회복량을 편집합니다. 해당 소모품을 사용하거나 시간과 함께 휴식·씻기를 처리합니다. 생활 기능은 실제 기록한 게임 시간을 기준으로 하며, 그 자체로 임의의 생활 사건을 만들지 않습니다.

D100·헌터의 숙련 수련은 보유 기술과 시간을 고르고, 지정한 자원을 소비해 기존 기술 숙련 경험치를 올립니다. 시간당 성장·자원 비용·판정 문턱은 인물의 선택 기능에서 편집합니다. 무림·에렌샤의 원래 수련과 숙련 계산은 유지합니다.

비전은 등록된 기술들을 장으로 연결하고 해금에 필요한 숙련량을 정합니다. 사용할 연계 순서는 해금한 장에서 선택합니다. 입문 3회·비급 4회·절기 6회·신공 10회는 첫 기술을 포함한 사용 횟수입니다. 후속 기술도 자기 명중·비용·탄약·사용 조건을 적용하며 빗나감이나 실행 불가 이후는 중단합니다. 무림은 기존 비전 화면과 수련을 사용합니다.

소환수는 등록한 인물에 주인·상시 적용 여부·호출 비용을 설정합니다. 호출·해제 또는 기술에 연결한 소환 대상으로 사용합니다. 죽은 인물을 소환 호출로 부활시키지 않습니다. 선택 확장을 끄면 확장이 관리한 소환 연결을 해제하되 인물과 성장 자료는 보존합니다.

## 관계·경제·퀘스트·장소

관계는 실제 사건의 호감도·신뢰·평판·카르마 수치를 기록합니다. 수치만 보고 플러그인이 배신·이탈·새 갈등을 만들어 내지 않습니다.

상인에는 이름·세력·화폐·매입/판매 배율·보유 재고와 가격을 설정합니다. 물품은 이미 등록한 정의를 연결합니다. 실제 구매·판매에서 돈과 재고를 함께 계산하며, 착용하거나 파츠가 붙은 물품은 먼저 해제합니다. 정기 비용은 인물·화폐·금액·주기·다음 청구 시점을 정합니다. 시간이 지나면 소지금 범위에서 납부하고 부족한 금액은 미납으로 기록합니다.

퀘스트는 설명·진행 상황·확정된 보상을 저장합니다. 완료 처리할 때 보상을 한 번 지급하고 종료 목록으로 옮깁니다. 보상 미정과 보상 0을 구분하며, 무림에는 레벨 경험치를 지급하지 않습니다. 보상 물품과 상인 재고는 등록한 원본 물품을 소비하거나 판매한 뒤에도 참조할 수 있도록 정의를 보관합니다.

로맨스 판타지·미연시의 **장소**에는 이름·설명·세계관 사실·연결 장소와 방문 여부를 저장합니다. 현재 장소 변경도 실제 요청된 이동 기록입니다. 이 기능이 탐험 사건·전투·보상·이동 경로를 자동으로 생성하지는 않습니다.

택티컬·지르코트의 **장비 개량**은 무기 조정·방호 보강입니다. 실제 비용과 성공 판정을 거쳐 성공 시 개량 단계와 장비 가격이 올라가며, 사용 시 위력·방호에 반영됩니다. 원래 파츠·탄창·내구도는 유지합니다.

## 저장과 실행 범위

추가 자료는 채팅별 게임 백업에 함께 저장합니다. 같은 사건의 재시도와 퀘스트 보상은 저장한 처리 기록으로 중복 적용을 막습니다. 새로운 사건은 별도의 사건 ID를 사용합니다. 설정 변경이나 목록 조회 자체는 주사위·시간·비용을 발생시키지 않습니다.

이번 작업은 소스 수정과 로컬 배포 파일 생성 범위입니다. 별도 최종 검사·모의 전투/호스트·실제 RisuAI·모바일 화면·모델/API 실행은 수행하지 않았습니다. 새 기능 조합의 실사용은 아직 확인되지 않았으며, 0.29.0은 GitHub에 게시하지 않았습니다.
