# 0.28.6 · 구축 능력치 효과 오류 수정

플러그인만 업데이트. 모듈 v1은 그대로

시스템 구축 중 `효과 1의 종류를 해석할 수 없습니다: stat` 오류로 멈추는 경로를 수정했습니다. 보조 AI가 `stat`으로 작성한 능력치 효과를 엔진의 `raw` 형식으로 변환하고 대상 능력치·수치·배율·적용 조건을 이어받습니다. 공통 장비·기술 변환 경로에 적용하며 무림은 무림 스탯을 사용합니다.

대상이 없거나 서로 다른 능력치를 지정한 입력은 전체 능력치 효과로 바꾸지 않습니다. 어떤 장비의 어느 효과를 수정해야 하는지 오류 상세에 표시합니다. 새 구축 지침에도 올바른 능력치 효과 형식을 추가했습니다.

플러그인을 교체한 뒤 같은 채팅의 실패한 구축에서 **다시 시도**를 누르세요. 추가 요청을 바꾸지 않으면 보관된 인물 준비 자료를 재사용합니다. 기존 세이브·초안·커스텀 경지나 모듈을 삭제할 필요는 없습니다.
