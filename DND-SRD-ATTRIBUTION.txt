NyoruRPG provides a Korean interface and a software implementation of selected rules. The bundled reference preserves the English SRD text; names and world descriptions supplied by players are separate from those rules.

NyoruRPG adapts the SRD mechanical tables and reference text into software data, a compressed reference index, and Korean interface labels.
