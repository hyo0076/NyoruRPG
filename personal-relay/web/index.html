NYORU · 0.1.1

개인 MCP 중계기

AI가 도구를 고르면, 연결된 플러그인에서 실행해 결과를 돌려줍니다.

1. 사용할 플러그인에서 연결

플러그인의 중계기 설정에 이 주소와 실행창의 Publisher key를 넣고 연결하세요.

중계기 연동을 지원하는 플러그인·HTML에서 등록해야 합니다. 기본 주소에는 /mcp를 붙이지 않습니다.

2. 이 화면에서 도구 확인

실행창의 Consumer key를 넣으면 연결된 도구와 프로바이더에 넣을 주소가 나옵니다.

키는 이 페이지를 닫으면 사라집니다.

아직 연결된 도구 목록을 조회하지 않았습니다.

3. 프로바이더에 연결

Provider Manager의 프록시 추가에 입력하세요.

이름
Nyoru Relay
프록시 URL
인증 토큰
위에서 입력한 Consumer key
  1. 사용할 모델의 네트워크에서 커스텀: Nyoru Relay를 선택합니다.
  2. 같은 모델의 도구 사용 → 사용 안 함을 선택합니다. 중계기가 도구를 전달합니다.
  3. 채팅에서 답변을 생성합니다.

OpenAI 호환 · Chat 형식으로 사용하세요. API 주소·키·모델은 기존 값을 사용합니다. 답변은 도구 처리가 끝나면 한 번에 표시됩니다.

연결된 모든 그룹 사용

Provider Manager의 MCP 서버 추가에 아래 값을 입력하세요.

URL
Transport
streamable-http
Auth
Bearer
인증값
방금 입력한 Consumer key 값만 붙여넣기
Timeout ms
600000

저장한 뒤 도구 목록을 불러오고 사용할 모델에서 해당 그룹을 켜 주세요.

등록된 모든 도구를 하나의 주소로 연결하기

연결 중인 모든 그룹을 사용하려면 전용 주소 대신 이 주소를 넣으세요.

전체 주소와 개별 그룹 주소를 동시에 켜면 도구가 중복됩니다.
